## 业务记忆维护要求

- 服务器运营平台相关对话中，每次形成会影响后续对接、业务流程、数据模型、权限、安全、交付方式或验收标准的重要结论时，必须在本轮结束前同步更新本文件，方便其他`AI`对话直接获取最新事实。

- 涉及生产环境验证时，可以记录允许执行的测试范围和禁止事项，但不得持久化生产凭据。
