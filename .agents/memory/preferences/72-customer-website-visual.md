## 用户中心与官网视觉长期规则

- 本轮客户 SSL 菜单排障允许修改宿主插件发现接口的身份识别及对应测试：已登录客户和有效安全协助会话必须按原有权限取得客户插件表面，匿名访问、无效身份、插件隔离及既有权限语义不得放宽。用户随后确认一并修正客户页面授权判断：普通客户不得因没有后台员工角色而被误拒绝，不给客户补后台角色或管理权限；证书业务仍由原拥有方接口校验真实客户身份和数据归属，不放宽不透明插件隔离。
- 后台和用户中心的表格在浅色模式下固定使用灰色表头（`vxe-table--header`），普通数据行、空态、搜索区、工具栏和分页使用白色；页面外层原有冷灰背景保持不变。本次确认覆盖此前“表头也白色”的结论。表格必须继续使用真实的`useVbenVxeGrid`封装，不能只把原生表格改成同名组件或仿制样式；保留选中、悬停、焦点、禁用和业务状态的必要反馈，暗色模式继续使用可读的对应主题面板色。
- 后台和用户中心的业务表格分页必须使用 Vben 官方完整分页条，展示准确总条数、每页条数选择、数字页码及翻页按钮；不得用手写“上一页／下一页”两个文字按钮代替。总数必须来自当前筛选及当前用户可见范围的真实集合，禁止使用当前页长度、已加载数量或虚构上限冒充总数；禁止为凑页码把全部业务数据一次拉到浏览器。
- `web-customer`固定采用阿里云、腾讯云一类专业企业云控制台风格：白色顶栏、白色侧栏、冷灰页面底色、白色直角卡片、清晰细边框和蓝色主操作色；客户门户的基础圆角为`0`，禁止渐变大横幅、玻璃拟态、悬浮胶囊按钮、夸张阴影和大面积装饰色。头像、单选框、开关、进度环等依赖圆形表达状态的语义组件可以保持圆形。管理后台也使用白色顶栏和白色侧栏，但客户中心与管理后台继续保持独立主题作用域。
- 客户门户视觉覆盖必须限制在`web-customer`文档根作用域内，不能改变`web-antd`后台、宿主 Vben 通用组件或动态插件的全局视觉。动态插件样式继续限制在自身根节点内。
- 客户门户首页优先展示普通客户能理解的常用入口和办理流程，不显示“模块将接入”“阶段开发中”等研发占位文案；菜单必须按客户任务归类，图标应与业务语义一致，同一能力不得在多个顶级分组重复出现。
- 客户门户首页必须展示真实逐币种账户余额、待付款、进行中服务、近期到期、待处理工单和常用入口；没有余额账户时仍显示`CNY ¥0.00`作为界面空状态，但不得因此创建虚假账本。余额卡提供充值和财务明细入口；没有 API 管理业务时不得照搬竞品的 API 信息区。
- 客户门户菜单固定合并为普通客户能理解的任务入口：“平台认证”合并个人与企业认证，“我的合同”页面内合并合同与经办人，“推广与佣金”合并推荐与佣金；“账户资料”从侧栏移除并放入右上角头像菜单。客户分组默认全部展开且不可收放，自定义外部菜单始终排在内置菜单之后。
- 后台提供独立的客户中心外部菜单管理：每条菜单保存中文名称、英文名称、语义图标、排序和一个`http/https`外部地址；使用有界列表和安装实例级配置。客户点击时必须使用普通`<a target="_blank" rel="noopener noreferrer">`打开，不能把外部页面伪装成站内页面，也不能向外部地址附带令牌、客户号、租户号或其他敏感参数。
- 后台菜单只展示商家日常运营会实际操作的业务能力。租户管理、开发中心、任务调度、字典管理和参数设置默认隐藏；员工业务权限归入“权限管理”，不再单列“业务访问”。迁移检查归入“系统配置”，不得成为独立一级菜单。
- 后台新增唯一“系统配置”入口，以页签或分类导航集中管理 AI 模型、官网品牌、工单规则、服务器操作安全、合规供应商、通知渠道、支付方式、自动化连接器、迁移检查和其他安装级配置。各插件仍拥有自己的接口、权限、秘密和状态，聚合页只通过已声明的页面表面或版本化配置能力装配，不得跨插件查表或把所有配置复制进一张万能表。配置页必须使用紧凑的 Vben 标准表单、直角普通 Card、小字号和受控间距，不能使用大标题、大圆角、大留白或双层页面壳。
- 自动化连接器只要能在商品或服务器接口类型中被选择，就必须在系统配置或对应供应商接口分组提供完整的新建、编辑、连通性检查、启用/停用与可理解的缺项提示；不能出现“可选择但没有任何配置入口”的半成品状态。支付方式同样按已安装动态支付插件发现，至少覆盖支付宝、微信支付、易支付和银联支付的配置、验证与开关；没有真实账号时保持未验证和不可启用，不得用本地假成功冒充联调。
- 运营工作台和经营统计只能展示来自真实业务表和有界聚合接口的指标、趋势、异常、最近事项和可跳转处理入口；零数据必须明确显示零或空状态，不得写死演示数字。营销等内容很长的综合页面必须用清晰页签分组，切换时按需加载，避免一个页面纵向无限堆叠。
- 日志、短信和统计能力按业务用途组织。日志至少让商家能查看关键操作、登录、安全、接口、通知和自动任务结果，默认有界分页并支持时间、人员、业务类型和结果筛选；短信统一使用通知拥有方的模板、通道、发送记录和失败原因，不另建重复真相。菜单名称和页面文案必须是普通运营人员能理解的中文或英文，不能显示内部协议名、原始字段或插件实现术语。
- 默认官网固定采用阿里云、腾讯云一类专业云服务官网风格：冷白底色、深蓝导航、清晰网格、直角内容区与按钮、蓝色主操作和克制的品牌色；允许首页存在服务价值说明，但不得使用渐变、玻璃拟态、超大圆角、夸张阴影、低对比度背景或挤压真实商品与内容的巨型营销横幅。官网与用户中心可以共享视觉语言，但必须继续保持独立源码、构建、端口、路由、`SSR/SEO`和主题作用域。
- 官网的首页、商品目录与详情、新闻、公告、知识库、下载、帮助、页头、页脚、中文、英文、桌面和移动端都必须使用同一套视觉令牌；改样式不得改变公开接口、购物车交接、登录跳转、内容语义或结构化数据。
- 管理后台的“分析页”固定承担真实经营统计、趋势和异常概览；“工作台”固定承担按业务分组的快捷入口和待办入口，两者不得再复用同一个页面。“运营工作台”不再作为独立菜单展示。没有可见子项的一级菜单必须隐藏。
- “系统配置”和“插件管理”固定归入“系统设置”。从系统配置进入具体配置时必须在当前页面打开大尺寸 Vben`Drawer`，不得跳转到散落的独立配置页；抽屉内容必须有受控高度和内部滚动，底部操作始终可见。
- 系统配置只展示一个普通运营人员能理解的“自动化接口”入口，并在大抽屉内用“服务器接口”和“其他产品接口”页签区分。服务器上游实例只由`idc-resource`维护一套权威配置，其他产品自动化只能引用它，不得重复保存服务器地址、账号或密钥。
- 服务器自动化接口需要提供详情；“API 产品数量（已激活／总量）”按本系统通过该接口开通的服务器实例统计，不是上游商品种类数；“已设置”表示本系统使用该接口对接的商品数量。接口详情必须有界读取上游商品并允许管理员主动选择导入，自动填写连接器、接口实例及其声明的产品配置。导入只生成未上架草稿，管理员核对后手动发布；定价可选“按上游价格加价”或“自行填写最终售价”，系统绝不自动上架。
- 用户确认接口统计按当前绑定这条接口的服务器计算，已终止实例仍计入总台数；已激活按服务权益判断，不能把关机视为未激活。“已设置”只计算当前使用这条接口的商品，同一商品不因历史版本重复计算，也不因曾经使用该接口而永久计数。
- 上游商品导入必须先选择本地分类；商品名称默认使用上游名称，公开地址标识自动生成且可在商品管理中修改。“按上游价格加价”填写加价百分比，填写`10`表示上游成本增加百分之十，不是原价的百分之十；金额按对应币种的最小货币单位四舍五入。导入仍只生成草稿，不自动发布。
- 上游未明确提供配置字段映射时，允许导入未上架草稿，但必须列出无法识别或尚未补齐的配置，管理员补齐且通过既有商品完整性校验后才能发布。不得按名称猜填`CPU`、内存等字段，不得把起步价或缺少配置附加费的基础价当成整机完整价格。
- 公告管理使用冷灰页面底色和白色内容模块，新增入口始终可见；富文本编辑使用无页面遮罩的大尺寸抽屉，正文区域内部滚动，保存按钮始终固定可见。工单工作台外层`Card`正文内边距固定为零。
- 管理后台和客户中心的 Switch 滑块必须保持圆形语义，不能被全局直角视觉规则改成空白方块。
- 客户中心桌面侧栏固定为约`204px`的窄栏，并在运行期持续保持未折叠；一级分组只作为不可点击的弱化小标题，二级菜单直接常驻展示。响应式抽屉的开关不得反向写入桌面折叠偏好。
- 本地验收环境必须为所有可见业务列表提供幂等、可重复装载的多行演示数据，覆盖各页面支持的主要状态、可选字段、长短文本、日期和金额边界；演示数据只用于测试准备，不得进入生产初始化、伪造外部供应商成功或包含真实个人信息与秘密。
- 客户中心移动端侧栏必须使用默认关闭、由客户主动开关的临时抽屉；桌面内容必须始终避让固定侧栏，任何断点、刷新或页面切换都不得让正文被菜单遮挡。
- 后台“安全协助”必须进入与客户本人一致的客户中心布局和完整业务视图，保持十五分钟且交接令牌只能使用一次；协助后的查询和写操作能力与目标客户本人一致，不再额外隐藏或禁止付款、退款、密码与密钥、服务器控制台、重装系统、更换`IP`、终止服务及其他客户可执行功能，但仍必须经过这些功能自身已有的余额、实名、订单状态、二次确认、敏感操作校验和供应商能力门禁。所有操作同时记录真实员工和目标客户身份。
- “菜单管理”默认隐藏；“员工业务权限”统一改为普通运营人员能理解的“员工权限”，并归入权限管理。后台必须提供可实际维护组织部门的“部门管理”，不得只保留底层组织能力或空菜单。
- 系统配置抽屉必须按被点击的配置目标装配内容，不能因仍处于聚合页路由而回退到工单或其他默认页面。“其他产品接口”不得创建或展示服务器接口字段；服务器接口只在同一自动化抽屉的服务器页签由资源拥有方维护。
- 本地演示数据必须同时满足生产业务编号、外键、所有权和路由约束；不得用只适合截图的`demo_*`编号或悬空渠道、资源池关系让真实列表和操作接口整体不可用。单条历史异常记录也不得把整个只读列表拖成通用“服务暂时不可用”，安全降级时必须隐藏危险动作并说明具体异常。
