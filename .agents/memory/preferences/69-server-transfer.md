## 服务器附属操作、变配与转移长期规则

- 后台员工代客户创建快照、备份或流量包时，免费额度内可以直接创建；需要收费时只能生成客户待付款账单，由客户自行付款后执行，后台不得直接扣客户余额。
- 服务器分类由后台维护固定分类目录，允许新增、改名和停用；每台服务器只能单选一个仍启用的分类，批量分类只能从现有启用分类中选择，不能在批量操作里临时输入自由分类。分类停用后保留历史服务器上的原分类事实，但不能再分配给新服务器。
- 服务器升级按当前周期剩余时间折算差价，客户付款后立即生效；降级不退当前周期费用，只在下次续费时生效。磁盘缩容始终禁止自动执行，只能走人工迁移路径。
- 服务所有权转移由转出方填写接收方已注册邮箱。无论邮箱是否存在都返回相同受理提示；接收方须在`web-customer`内于 24 小时内确认。商家使用一个全局开关控制是否允许转移，双方确认后不再逐单等待后台审批。
- 存在任何未付的服务器续费或增购账单、进行中退款、进行中或结果未知的服务器操作、待签或签署中的强制合同时禁止转移；这些账单不随服务器转给接收方，必须由原客户先付款、取消或由后台明确处理完毕。历史账单、支付、退款、合同、发票和工单继续归原客户保留；接收方只取得转移完成后的服务操作、续费、通知和新业务记录。
- 服务器转移只带走已经付款、仍在有效期内且明确只属于该服务器的快照和备份权益；不属于该服务器、已经失效或仍待付款的附属权益不得转移。服务器及随附权益的自动续费在转移完成后统一关闭，接收方需要时自行重新开启，禁止把原客户的自动扣款授权带给接收方。
