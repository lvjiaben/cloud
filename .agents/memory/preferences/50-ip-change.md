## 客户自助换 IP 长期规则

- 商家按币种发布一套安装实例级换 IP 规则：是否开放、一个滚动周期内每台服务器的免费次数、滚动周期天数、每台服务器每天最多申请次数、超出免费次数后的单次含税最终价，以及允许使用的最大库存快照年龄。没有已发布且启用的适用币种规则时，客户入口失败关闭，不能猜价或直接发送 Provider 写请求。
- 客户不能手填新 IP、IP 池或上游参数。系统从资源拥有方最后一份仍然新鲜的当前 IP 目录取得现有 IP 数量，换址后数量保持不变，并把该数量精确映射为魔方 KVM 已冻结的`ip_num`参数；当前目录为空、过期、数量越界或 Provider 未声明换 IP 能力时不允许申请。
- 每次申请先按 PostgreSQL 权威时间校验滚动周期免费次数和每日频率，再由`idc-resource`按服务已经绑定的渠道、资源池和新鲜完整库存快照串行预留相同数量的 IP。报价固定十五分钟有效；免费申请直接进入`ready`，收费申请必须先等待统一`financially_settled`，结清前绝不创建 Provider 写任务。
- 明确失败且有证据证明未换址时释放库存预留；成功后消耗预留，并从新的新鲜 IP 目录计算旧地址集合和新地址集合的用途隔离摘要写入审计，不在普通审计和日志保存地址原文。上游结果未知时继续保留库存预留和服务级互斥，只允许权威查询或人工接管，禁止自动重放或提前释放。
