## 企业认证页面与浏览器状态长期规则

- 客户中心固定只显示一个“平台认证”菜单和页面，页面先展示并办理个人实名认证；个人实名通过后，同页显示企业认证申请、审核状态、补材料和资料变更入口。底层可继续使用`/account/identity`和`/account/enterprise-verification`子路由或组件承载各自状态机，但不得在客户菜单中拆成两个认证入口；管理审核固定属于`idc-compliance`动态页面，不得把客户认证做进`web-antd`管理工作台或宿主既有页面。
- `web-customer`只允许在`sessionStorage`保存随机命令重试键。企业法定名称、登记标识、代表人或经办人身份、文件名、文件字节、材料号、客户号和私有访问信息不得进入`localStorage`或`sessionStorage`；草稿刷新只依赖服务端本人当前状态。
- 企业当前状态最多返回八条本人最新案件的安全材料元数据，仅含不透明材料号、类型、顺序、真实媒体类型、大小和状态；文件名、对象引用、摘要、密钥、内容和下载地址禁止返回。
- 已认证企业在`web-customer`发起法定资料变更时只提交`legal_name`和/或`legal_identifier`类别、封闭原因和当前投影版本，不提交替换值；新的企业认证同意必须发生在变更申请之后，旧认证投影在新案件最终批准前继续展示并生效。
- 后台原件操作固定为“签发后立即消费”的单次下载，不向页面返回永久链接；浏览器只创建短生命周期 Blob 地址并在触发下载后立即撤销。管理列表保持无精确总数的服务端游标翻页。
