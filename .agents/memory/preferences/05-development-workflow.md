## 开发流程要求

- 所有代码相关开发必须遵循`LinaPro`五步流程：探索需求、生成`OpenSpec`提案、实现代码、启动服务并验证、归档变更。
- 处理已有功能的`Bug`、遗漏、体验问题时，必须走`lina-feedback`分诊。
- 完成实现或反馈修复后，必须执行`lina-review`。
- 操作前必须读取`AGENTS.md`、命中的`.agents/rules/*.md`、当前`openspec/changes`和相关现有代码。
- 多个`AI`对话并行开发时，任何操作前必须先查看`OpenSpec`当前改动记录，避免覆盖其他对话的工作。
