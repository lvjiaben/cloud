## Provider 未知结果与保护模式长期规则

- Provider 写入尝试次数与后续只读观察次数必须分栏持久化。任务或资源查询失败只能增加观察退避，绝不能恢复写入资格、增加写入尝试或授权重放外部写操作。
- 任务与资源观察使用 PostgreSQL 权威时间、有界指数退避和按任务稳定确定的抖动；状态从已受理推进到运行等更强事实、或进入任一终态时重置观察退避。
- Provider 熔断或保护窗口必须停止新的自动写入，同时保留精确任务详情和精确资源详情的只读对账；供应商容量观测、列表、发现等非必要流量不能借“只读”绕过保护窗口。
- 人工接管必须使用独立且语义精确的管理权限、目标数据范围校验和同事务业务审计；禁止借用供应商容量刷新、渠道配置或通用写权限，也禁止提供无证据的强制成功入口。
