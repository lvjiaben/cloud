## Provider 安全组长期规则

- 智简魔方公有云安全组首版适配只允许当前服务器的绑定和解绑；共享安全组删除、规则删除、批量和`force`等危险操作不得通过通用服务器能力开放。
- 绑定前必须从当前实例读取上游用户、实例类型和当前安全组，要求当前未绑定，并在该用户同类型安全组集合中唯一核对目标编号；替换已有绑定必须先显式解绑。解绑必须以当前实例真实绑定关系为准，不相信调用方提交旧安全组编号。
- 安全组写入只能发送一次。真实任务号可以证明已受理；同步普通成功、空响应、`401`或传输歧义必须回读实例`security`字段，精确达到目标关系才可判定成功，否则保持未知并等待拥有方处理。
