# 客户业务、代理销售与开放 API

用户于`2026-10-10`确认，以下决定替换原企业渠道限定、委托终端客户及协助报价审批流程的冲突条款。

## 入口与用途

- 一级菜单为“客户业务”，子菜单包含客户管理、代理销售与开放`API`。
- 协助下单在客户管理中操作，详见[协助下单规则](32-assisted-orders.md)。
- 代理销售同时支持销售员工与推广代理的归属、佣金、业绩、结算，以及拿货代理的等级、客户专属商品价格和折扣。
- 页面面向普通运营人员，支持搜索选择真实客户、员工和商品，不要求手输内部编号；提供实际操作及可理解的说明，不能只有统计和刷新。

## 代理定价

- 用户于`2026-10-12`确认：商品编辑内为各商品设置代理等级价，商品表格不放独立代理价格按钮；商品管理页提供“定制价格”，选择具体客户与商品进行独立价格的新增、查看、修改和删除。代理销售不再集中管理商品价格。
- 定制价格优先级最高，覆盖代理等级价：普通价为100、等级价为80、客户定制价为50时，该客户网页与`API`均按50报价。

- 用户于`2026-10-12`再次确认：各代理等级在“代理销售 → 代理等级”设置总收费百分比。未设置商品独立代理价时，含配置的税前商品金额按该等级百分比收费；安装费另算，不叠加活动或优惠券。未配置总百分比保持原行为，设置100%仍属于代理规则。
- 用户于`2026-10-12`确认商品管理按文件管理页面的标准搜索栅格、列表工具栏及表格样式展示。
- 用户于`2026-10-12`确认简化等级操作：编辑与“代理价格”同排展示，默认百分比入口显示为“代理价格”，使用小弹窗和简短说明，移除清除和重新读取按钮；留空确认撤销设置，冲突后关闭重开获取最新版本。
- 优先级为客户定制商品价、商品独立代理等级价或折扣、等级总百分比、普通价。网页与`API`共用同一客户价格，不建立互相冲突的价格体系。
- 商品独立等级价和客户定制价限定商品、币种及计费周期；等级总百分比覆盖没有单独规则的商品周期。固定价或百分比作用于每件商品含配置的税前金额，安装费按原规则单独计算。
- 代理固定价高于当前配置普通价时仍按固定价出售，不能拒绝、静默降为普通价或只允许减价。
- 使用代理价格时不再叠加优惠券或活动优惠；历史已生成报价、订单保留价格及规则快照。
- 代理自购不计给自己的推广佣金，其他有效销售员工或推广归属仍按实收计佣。

## 佣金

- 后台配置按实收金额比例或每单固定金额计佣，以及成熟等待天数；退款按比例冲回。
- 佣金逐币种核算，与消费余额隔离。成熟后由有权限管理员登记线下打款及凭证，不自动转入客户余额，不自动向外部支付。
- 已线下打款佣金发生退款时记录为待扣回，优先抵扣该收款人后续同币种佣金；未抵完前禁止继续登记打款，原打款证据不改写。
- 归属及计佣证据可追溯，重复实收或退款事件不得重复计佣或冲回。

## 独立销售业绩

- 用户于`2026-10-11`确认采用推荐口径：管理员设置的推广归属优先于旧推广链接；按到账时归属保存不可变快照，后续修改归属不改写历史。
- 逐币种统计已付款订单数、实收、退款和净实收，不换币汇总；没有佣金规则也必须记录和统计业绩，不能以佣金基数代替完整业绩。
- 按月份筛选到账事实，退款展示该批到账订单截至查询时的累计实际退款，用于核对原订单净实收，不按退款发生月份切断。
- 管理员明确清空推荐人表示取消推广归属，不恢复旧推广链接；只有从未手动设置推荐归属的客户才沿用有效推广链接。
- 新购已付款订单去重计数，续费独立展示已付款续费笔数；合法零元订单计笔数、实收为零且不计佣金。

## 开放 API

- 管理员选择客户并勾选允许接口，生成绑定客户的`AppID/AppSecret`。秘密只在创建或轮换时显示一次，后台不重复回显。
- 用户于`2026-10-12`确认：未实名客户允许创建开放`API`授权；创建时检查客户已激活且具有有效登录绑定，实际交易仍按商品规则校验实名，不以生成凭据替代交易门禁。
- 对方使用本站地址及凭据连接；提供真实可用接口文档、示例、权限解释、停用及轮换入口。
- 本站所有订单、扣款和服务归`AppID`绑定客户。对方终端客户由对方系统管理，本站不重复注册，不开放新委托模式。
- 客户商品报价复用代理价格。新购与续费自动扣绑定客户的同币种余额；不足整笔拒绝，不生成欠款订单、不留下续费操作、不换币、不使用授信兜底。
- 余额扣减、订单、账单、库存及业务操作在核心拥有方内完成原子提交；幂等重试不重复扣款，权限撤销、越权对象和错误凭据必须拒绝。
- 同款系统之间对接使用公开协议，不建立特权内部通道。魔方系统仅作为业务原理参考，本轮不据此宣称新增魔方兼容性。
- 下游导入上游商品在本站销售，本站客户付款后自动通过上游开放接口拿货并进入正式开通流程；不能仅提供管理员手动采购。
- 用户于`2026-10-11`确认导入范围为系统全部可销售商品，参考魔方上下游的业务原理与操作体验，不限服务器。各商品保留冻结契约声明的交付、持续管理及续费语义，不能把全部商品都当成单一长期服务器服务。
- 核心拥有客户、价格、订单、资金及服务；渠道拥有凭据、接口授权、请求证据和连接设置，禁止跨插件直接查表。

- 已获后台开放接口授权的客户，用户中心自动显示“开放平台”，提供本站接入地址、AppID、授权接口、接入文档、重置密钥及该客户所有调用记录的分页查询。客户不能自行增加接口权限或延长有效期；密钥只在创建／重置当次展示，历史密钥不回显。未授权客户不显示入口，后端始终按当前客户隔离。

## 客户管理简化（2026-10-12）

- 后台入口及提交按钮均叫“添加”，只提供一个添加入口，邮箱和手机至少填一项，也可以同时填写；初始密码随机生成，成功后仅当前操作展示供管理员交付。不发送激活邀请，不填写原因、界面语言或初始密码，创建后即可正常登录，不强制首次改密；仅填手机时用手机号登录，两项都填时用邮箱登录，手机号同时保留为联系方式。
- 重置密码仅确认后随机生成并更新，成功后展示新密码；不填写原因或临时密码，不在日志、审计、持久化业务数据中保存明文。
- 客户列表“账号”分两行显示已有手机和邮箱，不展示标签数量。“查看详情”替代“查看360”。
- 客户详情固定宽度，编号蓝色下划线且可复制，账户状态使用彩色标签，提供封禁／解封。删除运营足迹页签，备注和操作记录在当前详情查看，分组与标签提供明确添加和移除入口。

- 模拟登录点击即进入用户中心，不弹窗、不填写原因或工单；保留员工权限、客户范围、15分钟有效期、单次交接和操作记录。
- 客户详情提供“实名通过”和“清空实名”，仅确认、不填表。通过直接赋予当前客户类型的已认证状态，明确为后台人工通过，不伪造证件或供应商结果、不改变客户类型。清空清除个人和企业当前实名资料及认证状态，保留历史认证材料、订单、合同和操作记录；旧案件完成不得恢复已清除资料。
- 客户标签统一为输入名称按回车添加，已输入并保存的标签可从下拉直接选择。详情和批量窗口不提供独立标签新建或编辑表单；同名复用，批量操作不填写原因，自动保留操作记录。
