## 本地合规网关供应商主体长期规则

- 腾讯子企业和诺诺纳税主体原文只能来自供应商授权在服务端完成后产生的一次性授权结果；商家不能在后台手工输入、指定或切换供应商主体编号，客户请求、浏览器请求和普通业务接口同样不得提交、读取或切换主体原文。软件提供方不得替购买方提供或覆盖主体。
- 本地网关使用一个独立私有且带版本的供应商主体密钥环文件；文件中分别保存密码学上互不派生的主体`AES-256-GCM`密钥族、主体查重`HMAC-SHA-256`密钥族和身份操作幂等`HMAC-SHA-256`密钥族，不与进程通信密钥环或其他业务密钥共用材料。
- 三套密钥族分别带活动版本和保留版本。新加密、新查重摘要和新身份操作使用各自活动版本；旧版本只用于解密历史、跨保留版本查重或幂等恢复。旧版本只能在完成数据迁移或幂等留存窗口核验后撤销，密钥销毁是独立的最终生命周期动作，不能由主体或实例撤销顺带执行。
- 密文认证附加数据必须绑定安装实例、主体绑定号、供应商、密文格式版本和加密密钥版本；查重摘要必须绑定供应商和供应商专用规范化器输出。核心服务只接受供应商专用规范化器产生的值，不能自行猜测去空格、大小写或 Unicode 规则；腾讯规范化器和业务路由在`10.8`按官方公开契约实现并经测试后静态注册，仍由购买方运行时账号能力门禁控制；诺诺的精确外部契约未确认前不注册生产规范化器，也不开生产路由。
- 每个活动实例对每个供应商最多一个活动主体；同一供应商主体在当前安装数据库可见范围内同时最多绑定一个活动实例。互不共享数据库的独立安装之间不建立中央查重注册表，跨独立安装的主体唯一性由商家与供应商的合同和授权关系承担。
- 更换主体必须先以封闭原因撤销旧绑定，再执行独立的新绑定或重新开通动作；撤销与重新开通不能合并为一步。重新开通必须重新完成完整登录和同一精确权限校验，允许由同一名已授权商家员工执行，但不能复用撤销动作的授权结果。
- 主体撤销原因只允许`subject_replaced`、`supplier_authorization_revoked`、`security_compromise`或`instance_revoked`；重新开通原因只允许`replacement_approved`、`supplier_reauthorized`或`security_recovered`，禁止自由文本原因。
- 实例撤销必须在一个本地数据库事务中撤销该实例全部活动主体并阻止新主体操作。加密历史和仍需保留的密钥版本继续服从本地留存与法律保全；实例撤销不能删除历史或销毁密钥。
- 主体明文不得进入普通数据库、接口、日志、审计、错误、用量记录或`AI`。供应商适配器只能通过同步回调取得当前活动实例的精确主体，回调返回或异常后必须清零明文缓冲。
- 保存供应商凭据、首次绑定主体、撤销主体和重新开通主体固定为四个独立操作，不能用一次请求或一次授权结果顺带完成其他操作。任一操作失败时保留可重试状态，供应商适配器继续关闭，不能带着半完成配置启动。
- 插件只能把服务端收到的一次性供应商授权结果通过本机受保护通信交给本地网关；由本地网关识别、规范化、加密并保存当前活动主体。插件数据库、普通管理接口和普通业务接口不得接触主体原文。
- 后台只允许显示主体状态、操作时间和本地生成的不透明编号，不显示完整或掩码形式的供应商主体编号。
- 本地网关必须为首次绑定、撤销和重新开通提供三个地址与签名范围互相独立的本机接口，只允许插件服务端调用，浏览器和终端客户不能直连。缺少有效本机签名、范围错配、请求重放或内容变化时均失败关闭。
- 供应商配置固定拆为查看、保存凭据、首次绑定、撤销和重新开通五项精确后台权限；除查看外，四个写操作都要求最近五分钟完整登录。开始首次绑定或重新开通时，插件签发绑定当前用户、商家、会话、供应商、操作类型和不可变目标摘要的五分钟单次操作凭证；供应商授权结果只能在服务端消费该凭证，过期、重放或目标变化必须重新开始授权。
- 凭据状态、主体状态和最后一次操作结果必须分别记录与返回，不能用一个综合状态让“凭据已保存”冒充“主体已绑定”。失败必须明确为可重试，且在主体未活动、购买方运行时能力检查未通过、供应商仍受外部证据门禁或任一配置步骤未完成时适配器保持关闭。
- 任务`10.6.c.3`只交付后端管理接口、插件到本地网关的安全接线和自动化测试，不新增临时管理页面；腾讯、诺诺开通向导和用户可见页面分别留在任务`10.8`、`10.11`和`10.12`实现。
- 任务`10.6.c.2`只实现本地网关内部服务和数据库契约，不发布`HTTP`路由。后续`10.6.c.3`只实现插件与本地网关之间的安全接线、状态处理和测试；腾讯真实识别器由`10.8`按官方公开契约实现并受购买方运行时能力门禁控制，诺诺真实识别器在其官方接口证据完成前不得启用，识别能力缺失时必须失败关闭。客户接口和普通业务接口始终不得自由绑定、撤销、读取或切换主体原文。
