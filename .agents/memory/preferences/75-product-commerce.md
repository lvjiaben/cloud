# 商品业务与插件交付

## 2026-10-16确认

- 商品销售分类最多二级。新增和编辑均只能选择一级分类作为上级；已有子分类的一级分类不能移到另一分类下面形成三级。保留已有商品引用，不擅自删除历史分类。

## 2026-10-14确认

- 商品后台参考魔方的简单操作流程，分类树和商品在同页管理，支持分类维护、复制商品与完整编辑。已有父子分类保留，不破坏历史引用。
- 复制商品保留价格、配置和交付设置，生成不可销售草稿；保留库存限制开关，但新商品可售库存从零开始，由管理员重新填写，不复制原库存数量。
- 上述复制设置替代主题`24-resource-coordinator.md`早期“不复制交付绑定”的决定。配置指通用冻结插件声明与类型化值，不恢复旧服务器配置组、规格项、兼容关系或资源池路由；不复制成本、订单及服务历史。接口绑定必须重新核对员工权限与插件接受新业务状态。
- 数量配置支持按数量单价累加和按区间整档收费两种方式，每个配置项独立选择，不混用两种算法。上游允许零数量时可以选择零，该配置项的价格和一次性费用均为零。
- 平台可销售任何商品。服务器、域名分发、域名开通、挂机宝、CDN、宝塔等通过各自真实插件提供配置与交付；不得用固定类型枚举限制销售能力。
- 无真实插件时先人工交付：客户付款后管理员实际完成并填写结果，接入真实插件后再自动化。
- 上游读取字段、选项和限制；后台可以调整展示名称、排序、可售范围与售价，不能超出上游允许规格。
- 试用到期先暂停并提醒客户转正式套餐，付款后恢复；不自动扣余额，不直接删除数据。资格累计规则沿用`40-trial.md`。
- 配置升级按当前周期剩余时间补差价，付款后调用实际接口升级；暂不开放周期内降配退款，不允许缩小磁盘。
- 参考：魔方云对接文档`https://www.idcsmart.com/wiki_list/862.html`；插件市场`https://my.idcsmart.com/shop/shop_app.html?appType=server`。资料仅作参考，不构成第三方写入授权。

## 2026-10-15确认

- 复制商品只复制普通价、代理等级价和配置价，不复制客户定制价；客户专属约定留在原商品。
- 试用转正式由客户选择商品支持的正式计费周期，采用当前价格；正式期限从付款时间与原到期时间中较晚的时间起算。
- 试用转正式只收所选正式周期的商品费和配置费，不重复收取已经开通过的安装费。
- 试用时长从实际开通成功开始计算，等待开通的时间不占用试用时长；暂停后恢复不重新开始计算试用期限。
- 魔方云快照、备份和`NAT`的“不开通、指定数量、不限量”分开配置和计价。接口值`0`表示不限量时不得当作不购买免费；只有真正不开通才不收该配置项费用。仍须遵守上游允许范围。
- 只有确实支持暂停、恢复的自动开通商品可以开启试用；其他商品不显示试用设置，已有不符合条件的试用配置必须阻止发布并说明原因。
- 试用转正式时，原商品已停售，或新版配置无法原样保留当前服务时，暂停自动转正式并提示联系管理员协助迁移；不得自动替换配置或先收取无法交付的套餐费用。
- 云速`SSL`暂缺官方产品能力文档；无法确认域名类型支持范围和最大数量的套餐，禁止新的自动发布，保留人工交付。不能从产品名称、验证方式或本地输入上限推断供应商能力；历史证书继续使用原冻结配置管理。
- 配置升级补差采用“升级后当前周期价格减去本周期实际商品及配置费用，再乘剩余时间比例”；例如本周期实付80元、升级后当前周期价120元、剩余半周期，补20元。税费另外计算，安装费不重复收取；差价为负时拒绝自动升级。
- 商品停售后，新购、老客户续费和试用转正式全部禁止；续费报价、确认及实际付款前均需重新检查，不能用停售前的报价绕过。已完成付款的历史事实及其必要交付不能倒退或丢弃。
- 附加商品由管理员在主商品中勾选可购买范围；客户只能为自己的一台有效服务购买，按附加商品独立价格和周期收费。只有插件明确支持面向目标服务交付时才自动执行，否则进入人工交付队列并由管理员填写结果；不把普通商品当作配置升级，不默认随主服务到期补差。
- 魔方云以已提供的官方对接文档为接口依据，不把额外的“供应商套餐规格接口”作为实施前提。地区、节点、镜像等使用文档支持的查询结果；CPU、内存、磁盘等可传配置由管理员启用并设置可售范围和价格，按文档完成单位及参数映射。没有查询依据的本地范围不得宣称为已向上游核实的可用库存或套餐。
