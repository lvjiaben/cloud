# 插件管理与开发规范

## 2026-10-25确认

- 新建内置插件替代原后台插件管理入口；不解除宿主禁止修改边界。
- 只展示动态托管插件；搜索仅标识、名称。默认按支付、短信、服务器、云产品、官网、用户中心、系统功能展示Tab。
- 分类及插件归属可配置并继续扩展，不把七类写死为产品类型或安装许可。魔方云、魔方财务、宝塔归服务器，SSL归云产品，迁移归系统功能。
- 名称和标识合并一列，上名称、下标识；保留版本号、状态、业务、运行时状态、安装时间；行操作仅安装、更新、卸载，不提供详情、管理或整行详情跳转。
- 每类插件遵守对应公开业务契约和开发规范，规范不符不得安装；统一文档和可执行校验保持一致，不能以分类、名称或说明文件存在替代契约校验。
- 用户要求一并检查当前所有插件的开发规范和文档，修复缺漏及可证明的不一致。另一个对话并行开发时保留其改动，不改写其业务实现、共享构建工作区或运行配置，不重启共享实例。

## 2026-10-28操作简化确认

- 安装、重装后自动启用并开放新业务，不沿用卸载前的停止状态。安装和卸载仅在行按钮使用一次简短确认，不再打开动作弹窗、展示长说明或要求勾选授权恢复。
- 缺少业务授权时自动通过公开接口完成校验后继续，不让用户处理技术性中间步骤。停用和卸载仍自动停止销售，权限、开发规范、依赖及真实业务影响由服务端执行；不修改宿主或私有授权数据。
- 上传新包后自动安装和启用，不再二次弹窗确认安装。交互以简单、直接、一次操作完成为准。
