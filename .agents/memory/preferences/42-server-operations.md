## 服务器日常操作长期规则

- 客户只能操作当前登录客户主体名下的服务器；后台员工必须同时具备对应服务器操作的独立精确权限和目标数据范围，普通列表或详情权限不能代替写权限。
- 同一服务器存在未结束的互斥任务时，禁止再次提交冲突操作，并向用户显示当前任务和可安全执行的后续选择。系统不额外设置固定时间冷却，主要以权威任务是否结束为准。
- 服务权益处于“有效”或“宽限期”时都可以使用仍符合运行状态和供应商能力的日常操作。服务器运行中允许关机、重启、重置密码、控制台和重装；服务器已关机时允许开机、重置密码和重装。服务已暂停、终止中、运行状态不明或已有未结束任务时禁止新建日常操作；控制台不对已关机服务器开放。
- 普通开机可以直接提交；普通关机和普通重启必须先确认。强制关机、强制重启、重装、重置密码、换`IP`和变配必须使用明确说明影响的二次确认。
- 高风险服务器操作默认要求客户在当前有效登录会话中查看本次操作的明确影响并再次点击确认，但不要求重新输入账号密码，也不检查最近几分钟是否完成过完整登录；该确认必须绑定当前客户、当前会话、服务器、动作、参数和请求号，短期有效且只能使用一次。商家可以在后台明确关闭这项额外确认；关闭后仍必须执行正常权限、客户所有权、数据范围、服务状态、任务互斥和审计校验，确认框不能扩大权限。
- 重置密码由客户输入并确认新密码，明文只在受限秘密回调中短暂使用，不在页面、普通接口、任务参数、日志或审计中回显。重装生成的新凭据只允许通过一次性安全交付查看一次；控制台只使用短期票据。
- 客户重装服务器时必须从该服务器所属资源渠道最后一个完整镜像快照中选择系统镜像；页面同时提供登录端口、是否格式化数据盘和系统盘大小三个高级选项，默认收起且默认全部不改，由客户主动填写或开启后才传给供应商。镜像必须显示分组、名称、操作系统类型、架构和启动方式；明确可用的镜像才可选择，状态未知或不可用的镜像只能展示为不可选，不能猜测可用。
- 重装成功后，客户在服务器详情中主动点击“查看新密码（仅一次）”，再次确认后才领取并显示；关闭展示后永久不能再次查看，系统不得自动弹出密码，也不得在历史记录、日志、审计、普通接口或页面缓存中保留明文。
- 开机、关机、重启和重置密码不收费。换`IP`和变配是否收费由商家已经发布的业务规则决定；需要收费时必须先完成权威报价和财务结清，免费规则不得伪造财务结算。
- Provider 明确失败且任务已经安全结束后，用户可以重新发起新操作。超时、断线、无任务号或任何结果不确定状态都禁止重放写请求，只能先执行只读任务/资源核对，持续不能确认时进入有证据的后台人工接管。
- 魔方接口和参数继续以已冻结的`3.9.14 beta`管理员`v1`契约及现有适配器实现为准，通用服务器操作层不得改写端点、参数、任务号语义、秘密处理或未知结果规则。
