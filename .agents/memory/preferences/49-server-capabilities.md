## 服务器附属能力长期规则

- 客户可以在`web-customer`操作自己服务器实际支持的快照、备份、安全组、实例级端口转发和虚拟介质；后台员工只能通过对应插件`frontend/`页面，在具备动作专用权限和目标数据范围时为客户代操作。Provider 未声明支持、目录过期或当前状态不允许时，页面必须隐藏动作或明确引导提交工单，不能伪造可用。
- 安全组绑定/解绑、实例级端口转发创建/删除和虚拟介质挂载/卸载首版不收取本地费用，但仍必须经过所有权、能力、状态、任务互斥、影响确认和审计校验。快照、备份和流量包由商家发布的规则决定免费额度与收费价格：免费额度内可以直接创建业务操作，需要收费时必须先形成权威报价并完成统一`financially_settled`门禁；未发布适用规则时禁止客户下单，不能猜价或按上游返回值临时收费。
- `8.7`只展示服务器当前`IP`和磁盘事实，不开放换`IP`、增加磁盘、删除磁盘或磁盘扩容。客户换`IP`由`8.8`完成，磁盘和其他配置收费变更由`8.9`的统一变配与报价链完成，禁止通过附属能力页面绕过财务结算和数据删除影响确认。
- 运行中或已关机的服务器都允许执行当前能力支持的快照/备份创建与删除、安全组、端口转发和虚拟介质操作；快照或备份恢复只能在服务器已经关机时提交。流量包在运行中、已关机或因流量原因暂停时都允许购买，购买成功不得自动开机或自动解除暂停。
- 快照与备份分别由商家发布“每台服务器免费份数 + 超出后每份固定周期价格”，不按实际上游容量临时计价；免费份数分别按单台服务器当前仍存在的快照或备份计算，不能在客户、商品或整个安装实例之间共用。
- 商家分别为快照和备份配置按天、按月或按年的付费周期；每个超出免费份数后创建的付费快照或备份都有自己的到期时间并自动续费。每次续费按续费时商家已经发布并冻结到本次账单的新价格执行，续费提醒和账单必须在扣款前显示本次金额；价格变更不得覆盖历史已结算周期。商家以后减少免费份数时，已经按免费资格成功创建并绑定的旧对象继续免费，不追溯收费；新创建对象才按新额度判断。删除后立即释放该服务器的一份免费占用或停止该付费对象后续续费，但已经开始的当前计费周期不按剩余时间退款。
- 只有创建快照或备份会占用免费份数或产生收费；恢复和删除不收费。流量包采用商家发布的固定容量套餐和对应一次性总价，不再让客户自由填写`GB`并乘单价。没有适用的已发布规则时客户下单入口必须关闭，后台不得猜价。
- 商家后台填写的快照、备份和流量包价格就是客户最终支付价，已经包含适用税费；结账和账单不得在该金额之上再次加税，账单税务拆分只能在最终支付价内部完成。
- 用户于`2026-09-04`确认流量包采用固定容量套餐，按商品指定可用套餐，有效期跟随对应上游流量重置周期并在购买前明确提示；不提供本地独立有效期或永久有效承诺。后台配置和客户购买仍遵循统一 Vben 组件规范，付费购买必须在本地账单真实结清后向原服务器增加一次流量，不得误开新服务器；付款通知重复送达不得重复加流量。商家配置入口与付款后执行断链由活跃变更`FB-114`追踪。
- 用户确认上游没有可靠重置日期时仍允许购买流量套餐，但购买前必须明确展示“有效期按上游重置规则执行，暂未提供具体到期时间”。禁止将目录缓存过期时间、报价到期时间或服务器到期时间作为流量包到期时间，也不得猜测月初、购买日或固定三十天重置。
- 用户确认流量包可由商家逐个设置“不限量”或“限量”库存；已销售套餐允许下架，历史订单、购买记录与已冻结的容量和价格必须保留，不提供删除销售历史的操作。库存只表示商家可销售份数，不使用上游容量观测替代。
- 用户确认限量流量包在生成待付款账单时占用一份库存，订单取消或超时关闭完成后释放；已付款的保留占用，不能在付款后再抢库存导致超卖。付款关闭结果不明确时不得提前释放。
- 用户确认后台限量库存填写“总可售份数”，已占用与剩余自动计算；剩余为总量减已占用且最低为零。调低总量不改变已下单、已付款及历史记录，不能借修改库存撤销既有购买。
- 付费快照或备份自动续费扣款失败时，系统不得自动删除客户数据；必须保留待付款账单，暂停该对象的恢复等使用操作，同时通知客户以及所有拥有“附属资源续费处理权限”的后台人员，并生成同权限可见的待处理事项。客户充值后系统可以再次从同币种余额扣款，也可以直接支付待付款账单；付款成功后自动恢复对象使用并从付款成功当天重新计算一个完整的新周期，不追收暂停期间的周期费用。暂停期间客户仍可查看和删除对象，后台有权人员可以人工处理，任何路径都不得自动删除数据。
- 所有附属能力写操作都先展示明确影响并进行普通二次确认；恢复快照或备份还必须输入页面显示的唯一服务器编号，不使用可能重名或随语言变化的商品名称。Provider 返回结果不明确时，同一服务器后续写操作保持锁定并提示联系商家，系统不得自动重试本次上游写入。
