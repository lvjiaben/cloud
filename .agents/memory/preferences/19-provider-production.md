## 智简魔方生产验证边界

- 官方魔方云文档入口为`https://docs.idcsmart.com/docs/魔方云`；若官方没有完整对接文档，可以结合用户合法持有的魔方财务源码静态分析接口契约。
- 智简魔方公有云管理后台自身提供版本化`v1`生成式接口文档。其调用以登录换取短期访问令牌、通过`access-token`请求头鉴权，并以任务编号配合任务查询表达开通、暂停、恢复、重装、调整`IP`和删除等异步生命周期；新系统适配器必须显式保存上游任务映射、轮询状态、幂等键、超时、重试和人工接管状态。
- `2026-08-06`已对用户授权的已安装魔方云实例完成只读契约冻结：实例版本为`3.9.14 beta`，生成式文档包含`570`个`v1`接口章节；登录响应是 JSON 字符串令牌，正常过期时间一天，任务状态为未开始、执行中、成功、失败、强制结束和已取消。该结论不代表已执行生产写入。
- 该版本管理员`v1`可分页提供区域、节点、镜像、存储、IP 分组、资源包配额、用户、实例和任务，并为多数生命周期动作返回`taskid`；调整实例`IP`数量未声明任务编号，必须查询实例确认。任务取消当前只支持迁移和磁盘迁移，不能展示为通用取消能力。
- 该版本管理员`v1`未提供上游资源成本、渠道余额、资源到期或续期契约。适配器必须显式声明`unsupported`，系统使用商家后台维护的本地成本和本地服务期限，不得把资源包配额、应用商店余额或本地期限伪造成上游事实。
- 魔方云部分只读响应也会夹带区域/节点密码、SSH 密钥、Windows 密钥、存储认证、root/VNC/面板密码和内部路径；适配器必须在网络边界执行字段白名单投影，禁止原始响应整包进入数据库、任务、日志、审计和证据，确需交付的系统凭据只能转换为受限秘密引用。
- 当前冻结的魔方云`3.9.14 beta`开通契约要求资源拥有方在发起`Provision`前生成高强度系统密码、加密保存并写入宿主`secretcap`动态句柄；操作的`SecretBinding`名称固定为`password`，适配器只能一次性读取并以上游`rootpass`字段提交。开通响应中的`rootpassword`、`password`、`osuser`等字段一律丢弃，不得作为交付凭据。只有任务与资源均成功核对后，资源拥有方才能按一次性秘密交付策略展示本地加密凭据；结果为`unknown`时禁止展示并进入对账或人工处理。`QueryResource`通过`GET /v1/clouds/:id`读取全量详情，但只投影白名单状态和`IP`数量，原始敏感字段在投影后立即清除。重装响应中已明确验证的系统用户、密码和端口仍只能经拥有方加密写入后一次性展示。
- 当前用户授权实例的直接地址未通过受信任证书链校验，只允许继续做不落凭据的只读契约研究；正式适配器禁止提供跳过证书校验开关，生产开通或生命周期写测试必须等可验证的`HTTPS`域名和证书就绪。
- 智简魔方旧对接源码中的关闭`TLS`校验、宽松重定向、弱签名回调和在查询串或回调中携带敏感信息等做法只能作为风险样本，禁止照搬；正式适配器必须启用证书和主机名校验、目标域名白名单、敏感字段脱敏、短期一次性访问票据，并在任何写请求超时后先查询对账再决定是否重试。
- 用户允许在其线上智简魔方公有云系统中创建隔离的测试用户和测试实例，用于验证自己新建资源的开通及后续生命周期。
- 严禁修改、暂停、重装、续费、变配、删除或以其他方式测试任何已有用户和已有实例。
- 所有生产写入测试必须使用可识别的专用测试标识，先完成查询和接口契约核对，再创建最小成本资源；必须记录新建对象标识、调用结果和费用影响。
- 删除或终止动作只能作用于本次测试明确创建并再次核对标识的资源，禁止使用模糊查询结果、批量选择或名称猜测确定目标。
- 生产凭据只在用户明确授权的当前测试任务中使用，不得写入仓库、规则文档、日志、截图、测试代码或最终汇报。
