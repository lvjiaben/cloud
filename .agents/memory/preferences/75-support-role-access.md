# 工单角色与组织授权

## 用户确认：2026-10-10

- 取消独立员工权限功能，角色直接授权，不保留另一套员工资格。岗位只表示任职信息，不授予操作权限。
- 工单部门关联组织部门，成员随直属组织归属；客服和主管通过角色精确权限区分。
- 用户、角色、部门和岗位统一放在权限管理一级菜单，取消分开的组织管理入口；用户、角色、部门、岗位和菜单管理五个页面右下角显示圆形悬浮按钮，内部使用放大的单独问号图标，不再给图标套圈；背景随当前主题变化，通过阴影和悬停效果体现悬浮感，点击展开白话使用帮助，解释用途和步骤，其他页面不显示。
- 严格不修改宿主，详见[宿主边界](74-host-boundary.md)。现有公开接口不能查询目标员工有效角色权限，不能以复制资格、读取私表、伪造身份绕过。
- 用户确认采用部门队列和自行领取，移除自动分单及指定个人转派；转派必须清空处理人，目标部门员工凭实时角色和归属自行领取。
- 升级和低评分只标记需要跟进并保留历史；不再发送员工内部定向通知。重新打开一律返回原部门待领取。客户正常消息通知保留。
- 上述确认替代工单路由、重开、升级、内部通知旧条款中的自动分单、独立资格、指定个人或保留原处理人规则；其它权限、SLA、原因和审计边界继续有效。
