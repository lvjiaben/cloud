## Provider NAT 长期规则

- 智简魔方公有云 NAT 首版适配只开放当前服务器的实例级端口转发创建和删除；共享 NAT 网关、NAT 建站、批量与`force`等危险或跨资源动作不得混入通用服务器能力。
- NAT 创建必须明确外部端口、内部端口、受限名称和`tcp/udp/tcp_udp`协议，不允许上游自动分配外部端口；写前读取一次有界实例 NAT 列表并拒绝端口协议重叠。删除必须在同一列表中唯一核对转发编号归属当前实例。
- NAT 写入只能发送一次。真实任务号可以证明已受理；同步普通成功、空响应、`401`或传输歧义必须只读回查实例 NAT 列表，创建精确唯一出现或删除编号消失才可判定成功，否则保持未知并等待拥有方处理。
