## Provider 任务人工接管长期规则

- 人工接管只代表商家后台人员承担后续线下处理责任，不代表任务成功、失败或取消，也不允许借此重试、重放或直接调用 Provider。
- 只有`accepted`、`running`和`result_unknown`任务允许接管；必须使用独立精确权限、精确任务数据范围、最后读取的乐观版本、一个稳定受控原因，以及一至十六条已经属于该任务的不可变脱敏证据。
- 接管请求禁止自由文本、结果状态、重试标记和上游操作参数。任务状态关闭、输入秘密绑定撤销、观测领取清空、不可变责任记录与业务审计必须在同一 PostgreSQL 事务完成，任何一步失败都整体回滚。
