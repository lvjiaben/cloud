# 同系统连接器

[English](README.md) | 简体中文

`idc-peer`使用另一套同款系统的开放`API`连接上游，凭据绑定上游的一个客户。它不会在上游创建本站终端客户。

## 对接流程

在上游“开放 API”为客户创建应用并开放目录、报价、下单、服务及续费接口，在本站资源接口中填写上游地址和凭据。`AppID/AppSecret`只由`idc-resource`保密出站边界注入，动态插件看不到明文。

导入使用完整的公开销售契约，保留配置规则、公开候选、计费周期、税和价格。动态候选仍由上游实时校验。采购前重新取得匹配冻结币种和周期的有效计费令牌，再冻结客户实际拿货价并扣同币种余额；余额不足不生成欠款订单。

## 交付和失败恢复

采购以原请求号恢复响应未知的结果，不能更换请求号重复扣款。一次性交付不创建虚构的长期服务；多服务交付保留每项上游服务编号。

续费匹配原上游服务编号、币种、计费周期及到期时间，向上游提交续费后按原请求号查询结果。不会仅延长本站时间。配置文件经核心持有的订单文件证据和资源保密出站流式上传；动态插件不接触文件对象路径或凭据。

上游已上传、尚未下单消费的文件令牌有效期为7天。正常重试复用原令牌；如果长期停机或中断超过有效期，采购会明确失败并转人工跟进，不会更换请求号重复扣款。恢复前应先核对上游原请求的订单结果。

正式使用前应完成当前版本的双实例验收。单元测试通过不等于真实双实例交付通过。

## 验证

连接验证和能力发现使用已认证上游能力响应的`observedAt`。续费任务使用已认证交付及续费查询的观察时间。缺少或非法观察时间时明确拒绝；动态 WASM 连接器不自行生成本地墙钟时间。

在本目录运行`GOWORK=off go test ./backend/... -count=1`，验证托管清单、原子下单协议、余额拒绝、响应丢失后的只读恢复和服务归属检查。该测试不替代真实双实例联调。
