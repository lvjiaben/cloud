# 本地合规网关安装与生命周期

本目录随每套 LinaPro 完整程序交付。软件提供方自营实例与购买方实例使用相同的程序组件；每个安装方在自己的环境运行网关并持有自己的数据库、秘密、供应商账号、回调、监控和备份。

## 安装与启动

## 进程密钥轮换与撤销

先执行`-out <新文件绝对路径> -rotate <当前文件绝对路径>`生成替换文件；轮换禁止传入`-installation-id-out`，现有安装标识必须保持不变。随后原子更新本地两个进程的密钥环文件引用并重启；旧密钥在受控重叠期内只允许验签。确认旧进程签发的请求均已结束后，使用`-revoke <旧密钥 ID>`再生成一份替换文件，原子部署并重启两个进程，最后按安装方的秘密留存策略归档或销毁旧文件。命令拒绝原地覆盖，避免轮换中断损坏当前有效密钥环。

## 供应商主体密钥轮换

使用`bin/idc-compliance-local-gateway-supplier-keyring -out <新文件绝对路径> -rotate <当前文件绝对路径> -family <密钥族>`一次只轮换`subject_encryption`、`subject_lookup`或`identity_operation`中的一套密钥。新写使用新活动版本，旧版本继续用于历史解密、查重或幂等恢复。轮换后先原子更新文件引用并重启网关；启动检查会为当前活动主体补齐保留版本查重摘要。当前工具故意不提供旧版本撤销或销毁命令：必须先由后续留存执行服务证明密文迁移、查重迁移或幂等留存窗口已经结束，密钥销毁还需要独立终态审批，不能靠手工改文件绕过。

## 监控

只把存活、就绪、进程退出、重启次数、CPU、内存、文件描述符、数据库连接、有界本地查询与用量采集积压、固定查询与采集失败分类和人工接管积压送入当前安装方的监控系统。监控、日志和支持包不得包含数据库 DSN、密钥、供应商凭据、外部流程号、租约原文、客户材料、回调原文、供应商自由文本错误或业务证据原文。

## 备份与恢复

备份由当前安装方负责，至少覆盖本地网关数据库、安装标识、进程密钥环、供应商主体密钥环、回调证据密钥环、配置版本、用途隔离秘密、供应商授权元数据、不可变证据和审计。秘密备份必须独立加密并与数据备份分开授权。恢复同一实例时必须随数据库和秘密恢复原安装标识及对应密钥环；把克隆副本作为新商家实例前必须重新生成安装标识和三类密钥环。随后以只读方式校验迁移清单、证据完整性和供应商授权状态；在核验完成前禁止供应商写操作。

## 停止与卸载

停止时先停新业务、排空或封闭进行中任务，再终止进程。默认卸载只移除二进制和服务定义，保留数据库、秘密、证据与审计；任何数据清除必须经过法律保全、法定留存、未完成任务、供应商撤权和证据导出检查，禁止安装器静默删除业务数据。

## 独立运行边界

本组件不得连接软件提供方的中央业务网关、中央结算、平台销售注册或平台操作者服务。商业授权只约束软件使用权、版本和升级权益，不参与供应商主体、业务签名、回调路由、用量或结算。


电子签适配器、公开回调与合同路由已经退役；诺诺供应商能力在独立接口证据验证前继续关闭。旧业务证据保留，不恢复旧电子签处理。
