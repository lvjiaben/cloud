# idc-compliance

`idc-compliance`是 IDC 合规工作流的内建源码插件。

[English](README.md) | 简体中文

## 能力范围

本插件负责实名认证案件、企业审核、电子合同流程、电子发票和合规证据。

## 依赖

本插件只使用`idc-core`公开的`idccap`、`managementcap`和`secretcap`契约，不依赖核心实现包。

## 交付

`v0.1.8`以`source + builtin`交付，并使用`platform_only`、`supports_multi_tenant: false`和`global`治理。

## 本地网关交付边界

每套 LinaPro 安装必须完整获得并自行运行合规网关进程、数据库迁移、配置、供应商凭据、回调、监控和恢复能力。软件提供方自营实例与所有购买方实例使用相同的完整程序，购买方合规业务流量不得经过软件提供方运营的业务网关。

`manifest/delivery/local-compliance-gateway.yaml`把本地网关声明为每套产品安装包的必需组件，发布工具生成包含二进制、配置模板、数据库迁移和双语生命周期说明的目标平台组件包。`central-gateway`仍是纠偏期间的历史源码目录名，不代表中央部署；物理重命名将在中央身份和结算代码删除后完成，以避免把旧中央模型误当作需要兼容的公共契约。

当前目录中基于已废止“平台中央代理”假设产生的销售记录注册、远程实例身份、跨客户路由、平台操作者权威以及软件提供方与购买方之间的预付或后付结算不再是有效产品需求，不得继续扩展。幂等、防重放、熔断、回调收敛、主动查询和证据保护等通用能力只有在收敛到安装商家本地所有权边界后才可保留。继续实现前必须先阅读 OpenSpec 完整独立交付纠偏记录。

## 数据边界

合规数据底座独占管理认证案件、企业加密材料元数据、合同快照与文件、供应商中立的税务发票、带不可变分配轨迹的红字任务和只追加的外部证据。`idc-core`只保存业务门禁投影和不透明关联编号。

数据库不保存人脸图片或视频、证件原件、合同正文、发票原件、第三方凭据及供应商原始报文。允许留存的文件只记录私有加密对象引用与`SHA-256`完整性摘要；身份与发票号码的精确查询使用带密钥摘要，禁止使用无盐公开哈希。法律记录不使用软删除；数据库触发器禁止修改归档合同和税务发票的内容与归属元数据并拒绝物理删除，同时允许显式推进留存与法律保全治理。外部证据严格只追加。

## 阿里云实人认证边界

阿里云金融级实人认证适配器使用固定的官方端点和协议契约。凭据只通过回调作用域内的缓冲区传入，通过`secretcap`保存，服务不会返回凭据。配置替换采用失败关闭的两阶段状态变更和幂等围栏，进程中断时不会把尚未提交的凭据暴露为可用配置。

适配器不请求也不保存人脸图片或视频。浏览器跳转结果不能作为认证成功依据，只有服务端签名查询结果可以推进认证状态。供应商配置仅允许获得授权的安装实例管理员操作，安装本系统的 IDC 商家自行提供并承担其供应商账号费用。

HTTP 控制器、后台配置向导、客户认证流程、恢复调度器、状态字典和插件自有端到端资产已经在商家插件内完成装配。它们使用安装本系统的商家自己的供应商账号，只与当前安装环境的本地网关共享必要凭据或运行状态。
