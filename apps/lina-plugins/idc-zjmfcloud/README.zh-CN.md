# idc-zjmfcloud

`idc-zjmfcloud`是用于智简魔方云商品配置和服务器操作的托管动态连接器，服务器操作由`idc-resource`统一管理。

[English](README.md) | 简体中文

## 交付方式

`v0.3.15`只以`dynamic + managed`方式交付，不再保留源码插件注册、内置分发或旧兼容路径。在仓库根目录执行下面的命令可构建可安装的 WASM 产物：

```bash
go run ./hack/tools/linactl build dir=apps/lina-plugins/idc-zjmfcloud
```

产物声明由`idc-core`拥有的`product-fulfillment@v1`扩展点，供宿主渲染商品配置和客户购买配置，并把服务器契约冻结到已经发布的商品版本。清单中的`configuration.candidates`、`provision`和`query`只作为授权和冻结证据，客体会拒绝从商品拥有方上下文直接执行它们。候选加载、真实开通和后续服务器操作都使用`idc-resource`拥有的`resource-provider@v1`扩展点。资源插件负责把选中的`pfi_*`接口解析到资源渠道、创建持久任务并绑定生成的服务器密码，然后再调用本连接器。

## 结构化配置

`endpoint`、`username`和`password`只在资源渠道页面管理，不能复制到商品自动化配置。地区、线路、处理器、内存、操作系统、系统盘、数据盘和带宽是本连接器声明的服务器专用字段，不进入通用商品模型。地区、线路和操作系统选项通过有版本的`configuration.candidates`方法加载。可选的`Relationships`将节点明确返回的`area_id`保留为有界、无秘密的父子选项关系，复用同一次节点响应，不按地区增加请求，也不凭名称推断。标识缺失时不声明关系，不能把缺失解释为任意组合有效。目录传输本身尚不代表后台或官网已经启用联动筛选。

商品可选配主机名和密码生成规则。纯值方法`product.configuration.validate`在表单评估、保存及发布时检查组合限制，不接收供应商凭据或出站上下文。资源拥有方按冻结规则生成重试稳定的主机名，并在已有秘密消费边界内生成密码；未配置规则的商品保持原有生成方式。

开通参数支持资源拥有方传入的备份、快照、NAT转发与共享建站配额：不开通映射为`-1`、不限量映射为`0`、指定数量保留正整数。重复或互相矛盾的配额拒绝开通；旧任务没有该配额时不增加默认参数。这仅描述参数转换，购买选项、上游允许范围与对应价格仍须完成配置后才能销售。

## 受控供应商边界

候选加载、服务器开通、查询和后续操作只接受`idc-resource`签发的`resource-provider@v1`上下文，并使用一次性的`confidentialoutbound.execute`服务。候选加载登录后只读取`/areas`、`/nodes`和`/image`，只返回有数量限制的中英文名称和值。资源插件没有绑定生成的服务器密码时，开通会在任何供应商请求发生前失败。供应商地址、账号密码、服务器密码明文、请求头、登录令牌和原始机密错误不会进入客体请求、客体响应、插件页面、日志或证据数据。最终供应商调用仍通过持久异步任务执行，并由资源插件控制。

## 前端页面入口

托管产物在`customer.products`受控位置发布客户页面，不再声明独立后台页面；后台服务器操作由资源拥有方的产品管理抽屉承载。客户页面运行在宿主治理的隔离容器内，继承宿主主题和语言，同步标题和高度，不读取宿主存储、Cookie或访问令牌。数据访问和生命周期操作继续由资源业务拥有方及宿主页面桥控制。

## 旧协议校验代码

`backend/internal/provider/zjmfcloud`包含托管 WASM 客体实际使用的协议投影和能力校验测试。它不会注册成源码插件。托管版本契约测试会复用其中的能力声明，避免动态清单和已经验证过的服务器动作矩阵悄悄产生偏差。

生产写入验证仍需要可信的 HTTPS 供应商入口，并且只能操作专门创建的隔离测试对象，严禁使用已有客户资源做破坏性验证。

## 页面桥契约

后台服务器管理收拢到对应客户产品的管理抽屉，连接器不再声明独立后台页面。服务器详情、附属资源和任务记录继续通过资源拥有方校验精确权限与产品归属。客户页沿用资源拥有方的客户服务器契约和操作门禁。

构建先执行插件自己的锁定依赖安装、类型检查和双入口页面构建，再装配WASM。安装或升级后还需启用插件；真实供应商功能另需配置资源渠道。

接口地址填写供应商后台根地址，例如`https://host/W5SHNaHntv/`。连接器声明`apiPathPrefix: /v1`，由资源拥有方为登录和业务请求统一追加一次；运营人员不填写登录路由或接口版本后缀。

商品配置支持节点选择优先级、流量重置周期及可编辑的磁盘性能档位，格式为`读取MB/s,写入MB/s,读取IOPS,写入IOPS`。保存前通过一次纯校验批量核对全部档位，交付时映射为原生接口字段，不重复换算速度单位。客户选择的GiB内存明确覆盖MiB商品参数，编辑器不再把两者显示为重复规格。`format_data_disk`仍只用于重装操作，默认关闭。

隔离客体完整校验返回结构，不以自己的墙钟判断观测事实。仅在本地校验副本中中和观测时间，返回字节保持原样，由资源拥有方填写实际接收时间。上游明确拒绝仍保留失败分类，不因隔离时钟为纪元时间而退化为无法确认。

## 商家自定义开通参数

直接开通支持显式填写非秘密接口参数，名称与标量内容随订单冻结并进入连接器实际表单；未绑定的客户资料不发送上游。认证信息、上游客户身份和已付款单位数量继续由所属服务控制，供应商是否接受自定义参数以真实响应为准。上游转售商品配置继续只读。

托管版本`v0.3.20`要求`idc-resource >=0.1.73`。扩展客户机连接字段仅由精确资源详情查询请求，电源操作的前置核对继续使用普通身份与状态白名单，详情读取与排队动作不互相借用字段权限。本地`TLS`测试贯穿真实托管桥及资源机密处理器，未执行真实供应商写入。
