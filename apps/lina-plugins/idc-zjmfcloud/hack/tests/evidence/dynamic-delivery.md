# 动态页面交付验证

日期：2026-10-09。发布清单：`v0.2.6`，资源拥有方最低版本：`idc-resource v0.1.26`。

## 根因与交付

源码已同步；原清单声明后台和客户页面，但缺少插件自身 HTML 入口及构建配置，导致动态产物没有可访问页面。现在锁定依赖、类型检查、Vite 双入口和 WASM 资产校验构成完整构建链。

后台桥能力`zjmfcloud-servers.admin.v1`只允许读取资源拥有方的固定魔方云服务器投影。列表每页最多100条，准确总数和详情使用相同固定连接器及单商户范围；每次请求验证当前员工和`idc:admin:resource:server-batch:view`权限。DTO没有凭据或动作引用。客户页仍经客户自己的资源目录和动作门禁。

## 已验证

- 插件完整构建及资产装配通过，前端4项单测通过。
- `TC003-dynamic-page-delivery.ts`在Chromium运行真实编译页面和Vben隔离运行时：后台表格、准确分页、只读详情、客户列表与详情通过；客户文案不显示内部服务器编号。
- 浏览器桥响应使用fixture，测试断言固定能力、GET方法和资源拥有方路径；不冒充真实供应商证据。
- 资源拥有方授权前置、拒绝时不访问存储、固定连接器查询、有界分页、不存在或不属于该连接器的详情拒绝，以及API翻译覆盖测试通过；Go lint为0 issues。
