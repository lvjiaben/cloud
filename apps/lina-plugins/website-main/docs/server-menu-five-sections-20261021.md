# 两级服务器菜单与选购五区修正

## 最新确认与根因

本次按`lina-feedback`的`openspec-existing`路径修正`migrate-xiaobai-website`的实现缺口。用户已确认本方四个商品分类就是一级分组，各分类内真实服务器名称就是二级入口。原实现把二级限定成后台子分类，并将所有同类服务器排列在右侧型号区，导致现有四个根分类无法形成用户要求的菜单。

一级标题整行只展开收起，单开且允许全部关闭；二级服务器进入对应商品卡，立即购买进入该服务器配置。商品列表与配置共用侧栏及浏览器历史。右侧型号只显示当前服务器；公开分类、商品身份、规格、库存、价格和报价继续来自本方接口，没有新增分类或修改后台商品。

## 本次范围

- `frontend/public/lina/product-sidebar.js`：按分类按需读取服务器，每页十二项，保留后续游标、重复项去重、失败重试及当前商品；不为所有分组并发查询。
- `frontend/public/lina/commerce-heading.js`、`catalog-page.js`：顶部返回、区域标题和商品说明，二级入口展示对应商品卡；既有商品卡结构及最低配置月价保留。
- `frontend/public/lina/catalog-page.css`、`site.js`：菜单间距与选中样式、型号背景、配置表单和系统卡片排布、固定费用栏、人民币符号及费用明细；健康状态下隐藏多余刷新按钮与空摘要，失败时恢复重读入口。
- 配置详情尚未返回时不使用空分类或旧商品重绘服务器菜单，修复非首分组商品直达时错误展开第一组的问题。
- 原站结构和原有本地静态样式继续作为视觉基础；本方独有规格及后台文案造成的内容差异保留，不将本次结果描述为逐像素完全一致。
