# 公共资料动态同步

根因是旧页面仅首次调用`loadBrand()`，没有切回或停留期间检查；联系方式变空时跳过更新，保留了旧值。直接重复调用原导航渲染还会重建节点，丢失展开和焦点。本批按`lina-feedback`归入既有迁移变更，不新增配置或后端接口。

## 字段链路

后台`portal-brand.vue`从六个公共字段组装保存输入，`siteconfiguration.Save`保存`Common`，管理端`Get`和公开`Public`读取同份设置；公开控制器按下表投影。实际后台只读网站名称为本地联调名称、其余五项为空，与公开响应中的名称及省略空字段一致。没有改动实际配置，也没有据只读检查宣称已执行真实保存验收。

| 后台字段 | 公开字段 | 页面使用 |
| --- | --- | --- |
| `siteName` | `siteName` | 头部及品牌文字；无网站标题时标题回退 |
| `siteTitle` | `seoTitle` | 非详情元数据页面的浏览器标题 |
| `companyName` | `footer` | 页脚公司名称，空值隐藏 |
| `contactPhone` | `contactPhone` | 全站页脚和联系页电话，空值清除链接及旧文字 |
| `contactEmail` | `contactEmail` | 全站页脚和联系页邮箱，空值清除链接及旧文字 |
| `description` | `seoDescription` | 非详情元数据页面的简介元标签，空值清除 |
| 头部／底部导航 | `navigation`／`footerNavigation` | 名称、顺序、层级及目标 |

六项均有现有映射。`description`是网站简介元数据，没有新增公司介绍正文契约；内容详情继续保留文章自己的元数据。原`Logo`和二十五内容字段不恢复，也不消费其历史值。商品、新闻、价格及库存由各自接口负责，本批不将其加入公共资料轮询。

## 同步行为

重新进入、窗口切回、恢复可见及页面缓存恢复时读取既有公开品牌接口；可见期间每次请求结束后三十秒再检查，隐藏时取消计时。请求单飞，期间多个触发合并为一次后续检查。首次失败显示既有重试入口；成功过后暂时失败保留最近成功资料。

固定轮播、方案及伙伴不随资料刷新。头部导航相同树不重建；展开或聚焦导航时延后应用变化，退出交互后使用最近一次树，不强行抢焦点。页脚导航相同树保留节点。公共资料仍使用原`cache:no-store`请求，不靠重新打包更新值。

`TC059`使用隔离合成管理页及存储模型验证保存、重读、公开投影和浏览器展示，并覆盖清空、隐藏、失败、并发、导航焦点和固定轮播；合成链路不等于真实后台端到端验收。真实发布仍依赖配套`idc-portal >=0.1.14`，正式入口未升级前不得声称实时同步已修复。
