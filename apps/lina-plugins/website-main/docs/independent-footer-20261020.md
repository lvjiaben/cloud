# 官网独立页脚资料

用户确认使用独立“官网配置”页面背后的既有接口，不共享用户中心配置。页脚按参考结构展示本方公司、版权、电话、邮箱、QQ、地址和两个二维码；不复制参考公司的真实资料。

## 字段和链路

管理端仍使用 `GET/PUT /x/idc-portal/api/v1/admin/site/configuration`，在 `common` 新增：

| 字段 | 展示 |
| --- | --- |
| `footerLogoUrl` | 页脚 Logo，仅此位置；不恢复旧 `logoUrl` |
| `copyright` | 完整版权文字，不自动编造起始年份或权属 |
| `businessQq` | 商务 QQ，数字校验与安全联系链接 |
| `companyAddress` | 公司地址，纯文字 |
| `enterpriseWechatQrCodeUrl` | 企业微信二维码图片 |
| `wechatOfficialQrCodeUrl` | 微信公众号二维码图片 |

公开品牌接口投影同名字段，前端沿用现有资料刷新。空值隐藏并清理旧文字、图片和链接。图片地址允许本地绝对路径及 HTTP/HTTPS，拒绝危险协议、凭据和控制字符。管理员需要填写本方实际资料；测试图片和模拟文本不写入正式配置。

已有公司、电话、邮箱和导航链路保留；并合入独立公共备案四字段与对应页脚消费，历史模板备案不再直接消费。四个首页内容字段仅恢复管理声明，本轮不改变已确认的商品轮播，不能将表单保存通过称为首页消费生效。
