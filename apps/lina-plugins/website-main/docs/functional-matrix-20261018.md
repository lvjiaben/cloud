## 订单成功后的用户中心错误提示

截图`temp/20261018/1792303184796-isolated-current-source-unpaid-order.png`显示订单和账单已创建、状态待付款、总额`CNY 6.00`，同时出现“网络异常”和“订单没有提交成功”。只读定位到`customer-default/frontend/customer/src/views/account/commerce/index.vue:315`附近：`submitCheckout`先成功执行`checkoutQuote`并设置`createdOrderNo`，随后在同一个`try`中调用`preparePayment`；付款准备被测试保护层拒绝后，落入同一`catch`而显示下单失败。

最小建议是由用户中心拥有方分别处理下单和付款准备错误，保留已创建订单状态；本轮不修改该页面，不放行付款准备。首次用例因把预期保护拒绝当失败而失败，修正断言后通过，未隐藏首次失败。

本轮隔离环境保留两份未付款订单，分别为`ORD_61bed2221adf8fa520531d72433a755e`和`ORD_49a33b8e782358692723d7de485abaff`及对应账单；没有付款或删除审计对象。当前源码跨客户订单归属拒绝未复验，不能借历史`TC012`关闭此缺口。
