# 商品配置页收敛修复

## 根因与修复范围

本轮按`lina-feedback`的`direct-fix`处理已确认选购体验的实现缺口，不新增商品、计价或订单契约。

- 手机付款周期沿用桌面横排表单，标签至少占用`116px`，剩余列再扣除内边距与按钮边距，导致按钮高达`130～162px`。配置表单的内容列现在允许收缩，窄屏标签与内容上下排列，周期组不再重复添加内边距。
- 同分类型号原来另建大边框与标题，现在复用原表单行结构，显示“产品型号”；分类、型号、可售状态与报价仍读取本方接口。温馨提示移动到型号区之后，旧配置入口及面板切换均适用。
- 普通网关注入的`customerUrl`为空，之前仅首页独立补过地址，配置页购物车与登录入口不可用。新增共用部署配置读取，现有网关注入优先；仅缺少地址时读取公开`lina/runtime-config.json`。源码默认空对象，实际本地部署设置为用户指定的`http://127.0.0.1:6032`，不把本机地址写入通用业务逻辑。
