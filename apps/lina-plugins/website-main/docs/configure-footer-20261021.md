# 购买配置页公共页脚与重复报价反馈

## 范围与根因

本轮按`lina-feedback`的`openspec-existing`修复`migrate-xiaobai-website`。商品目录切换购买配置时只交换右侧面板，外壳仍携带公共页脚。实际普通部署目录保留旧报价成功说明，旧`configure.html`还保留独立`data-selected-price`节点。源码、普通目录及生效冻结包并非相同版本内容，不能只改源码或全量覆盖其他窗口的修改。

本轮源码仅修改`frontend/public/lina/site.css`和`site.js`：配置状态统一隐藏公共页脚；每次进入配置时清除独立价格节点；成功报价清空状态说明，失败与加载提示保留。没有商品编号分支，所有商品共用。首页页脚与其他页面既有显隐策略不变。目录公共页脚在同期普通资源中已由既有非首页规则隐藏，本轮保留该规则，不擅自恢复。

## 范围审查

按`lina-review`审查本次源码两处资源、TC094、偏好72、本变更相关规范及任务记录，未将其他工作区改动纳入。触发E2E质量审查：有修前复现、实际业务报价、旧/新入口、无商品白名单、必要失败恢复及截图证据，测试不创建订单或依赖前项残留。实际资源`node --check`、冻结WASM编译及OpenSpec严格校验通过。无后端、权限、缓存、数据库、DI或i18n契约变化，未发现本轮范围阻塞问题。

初版测试假定目录页脚必须恢复显示，但同期既有非首页隐藏规则与该假定不符，导致等待超时；已收窄为本轮授权的购买页隐藏、返回与后退状态，以及首页保留，不通过改写其他页面行为满足测试。

独立已观察问题：390px旧入口的付款周期按钮既有列宽导致长金额竖向换行；功能断言通过，但不宣称手机整体布局已修复。该问题与本轮两项显示修复无关，保留为独立后续反馈，未扩大本轮修改范围。
