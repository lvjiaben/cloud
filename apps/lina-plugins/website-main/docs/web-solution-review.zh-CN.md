| 相关产品 | 既有`GET /x/idc-core/api/v1/public/catalog/products?limit=3` | 有界查询，不逐商品请求详情；空态与错误重试分开 |

| 选择配置 | 既有`/configure.html?product=<publicSlug>` | 沿用已有配置、报价、购买交接 |
