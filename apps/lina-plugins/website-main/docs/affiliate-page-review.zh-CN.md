# 联盟推广介绍页验收记录

仅修改`website-main`。页面为`/aff.html`，生态合作的“推广返利”进入介绍页，推广按钮统一使用已配置客户中心的`/account/referrals`。客户中心登录守卫负责登录和返回目标；配置缺失时入口禁用并说明原因。

已读`customer-default`账户路由、`views/account/sales-channel/index.vue`、`api/idc/customer-sales-channel.ts`及登录守卫。现有页面登录后加载本人推广概览、佣金概览和结算记录。
