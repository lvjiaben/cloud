# 分类独立购买提示交付

用户确认顶部购买说明、底部温馨提示在商品分类维护，每个分类独立配置。本次沿既有`migrate-xiaobai-website`实施，未修改宿主源码，未提交或推送。

## 行为

`idc-core`的分类新增、编辑、管理重读及公开目录支持`purchaseNotice`和`usageNotice`。每项为可空纯文本，最多两千字符；沿用分类权限、乐观版本保护及事务审计。迁移`131-category-storefront-notices.sql`仅增加插件自有表的两个空默认列，公开读取批量投影，不按商品额外查询。

官网商品目录沿参考结构展示登录条、灰色购买说明、商品卡及红色温馨提示。名称、规格说明、库存、价格仍读取本方公开接口。说明保留换行，标签字符仅作为文本；分类互不继承，全部商品隐藏提示，指定商品入口按商品所属分类展示，清空后隐藏对应区域。
