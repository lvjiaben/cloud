# 商品分类与配置页附件续接

## 本次范围

商品列表沿用原卡片结构，以本方分类作为左栏一级标题，同类展示多个商品。库存和月起价消费本方公开接口；缺少权威价格时显示配置后报价，不复制原站商品数据。

配置页沿用`allocation-card`结构，补充同分类型号切换、表单内付款周期和底部单件报价摘要。同类商品按准确`categoryNo`有界分页读取，禁售型号无购买链接；读取失败独立重试，不阻断当前规格选择。修改规格立即清除旧报价。底部金额明确为单件、服务端返回的计费周期报价，不推算结算总额。

修改范围为`frontend/public/lina/catalog-page.js`、`site.js`、`site.css`、`configure.html`、`scripts/migrate.mjs`及对应`TC037`、`TC066`和页面对象。未修改宿主、后端、权限、数据库或运行期`DI`；未执行全站生成、安装、发布或服务启停。
