# 分类手风琴与连续选购

## 根因与修复

按`lina-feedback`的`openspec-existing`路径修正`migrate-xiaobai-website`。原分类按钮独立控制`hidden`，可以同时展开多组；商品卡及型号使用`configure.html`普通导航，列表进入配置会重新加载文档。地址路径相同不保证页面免刷新，验收以实际文档请求次数为准。

分类分组改为整行按钮，根分组互斥展开并可全部收起，选择二级分类才更新目录。子菜单使用一百八十毫秒高度动画，箭头三百毫秒旋转，减少动态时立即切换。当前分类选中态与分组展开态独立，菜单内部滚动。缺失父节点和异常环路继续保留有效公开分类。

新增`commerce-navigation.js`复用导航、侧栏与页面外壳，只切换右侧目录和配置视图。统一`products.html`路径，通过`action=configureproduct`和`product`参数确定配置；旧`configure.html`入口用浏览器历史替换为相同选购路径。两个视图片段按需读取一次，后续复用已构建节点；分类投影在当前页面内复用，配置、评估和报价继续调用本方公开接口，不缓存价格作为购买依据。视图切换废弃旧请求结果、清理延迟报价，并按商品更新加车不确定记录，提交期间禁止内部切换。
