# 配置页分类导航续接

## 根因与修复

配置页保留原左侧分类容器，但启动流程只加载商品详情和配置，从未装配分类。`frontend/public/lina/site.js`通过既有公开`GET /catalog/products?limit=1`复用响应中的分类，独立请求一次，不逐商品读取。分类和商品详情无论先后返回，均按商品真实`categoryNo`高亮。分类失败只显示单独重试，不清空有效配置或阻断报价。
