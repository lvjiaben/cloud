# 开放 API

[English](README.md) | 简体中文

`idc-channel`是内置源码插件，负责客户绑定的`AppID/AppSecret`、接口权限和请求证据。客户、商品价格、订单、资金及服务由`idc-core`公开能力管理。

## 管理操作

在“客户业务 → 开放 API”选择真实客户，勾选允许接口并生成凭据。密钥只显示一次；可轮换、撤销或停用应用。原生`Vue`页面提供操作说明和接口示例。使用`HTTP Basic`认证，用户名为`AppID`，密码为`AppSecret`；正式连接使用`HTTPS`。

## 购买与归属

1. 查询目录，读取商品配置，通过远程配置校验取得有效选择，再读取对应币种的计费周期。
2. 提交`POST /channel/quotes`，冻结绑定客户的实际价格；代理专属价和等级价与网页购买共用同一规则。
3. 使用返回的`quoteNo`提交`POST /channel/orders`。订单、账单、库存及同币种余额扣款原子提交；余额不足整笔拒绝。
4. 用订单号或原请求号查询订单，并筛选订单对应服务。响应未知时先查询，不能换请求号盲目重试。

所有订单、扣款和服务归凭据绑定客户，不创建对方终端客户，不换币，不授信。重试必须保持同一请求号及内容。续费通过服务操作接口提交并查询持久化操作结果。

配置中需要文件时，先调用`POST /channel/catalog/products/{publicSlug}/file-uploads`取得上传令牌，再以原始文件内容调用`PUT /channel/file-uploads/{uploadToken}/content`，把返回的文件令牌填入对应配置字段。文件只属于应用绑定客户的有效账户；不能使用其他客户、其他配置字段或已被其他订单使用的文件令牌。文件通过大小、类型和安全策略检查后才能报价下单。

`GET /channel/orders/{orderNo}/deliveries`返回一次性交付及其对应的全部服务，服务带币种和计费周期。续费提交响应丢失时，调用`GET /channel/services/{serviceNo}/renewals/by-request/{requestId}`按原请求号恢复，避免重复续费扣款。

## 接口边界

接口前缀为`/x/idc-channel/api/v1`。游标目录每页最多`24`条；编号分页目录`/channel/catalog/products`每页最多`100`条。商品快照与配置接口只包含公开字段和不透明选择值；周期预览为普通价，实际代理价以冻结报价为准。

配置校验、计费周期和导入候选均使用`GET`。`values`是经 URL 编码的`JSON`数组字符串，最多128项、32768字节；不传表示尚未选择。交付和续费恢复接口的时间字段为 Unix 毫秒数字，没有对应时间时为`null`。

已认证的能力、订单交付和续费恢复响应同时返回`observedAt`，由源码 HTTP 运行时提供 Unix 毫秒时间。动态连接器将此响应观察时间用于连接验证、能力发现和续费状态；缺少观察时间时明确拒绝，不依赖沙箱本地时钟。

服务列表按`orderNo`筛选，以最后一条`serviceNo`作为`afterServiceNo`读取下一页。操作状态通过`GET /channel/services/{serviceNo}/operations/{operationNo}`查询。`GET /channel/orders/by-request/{requestId}`只查询本应用已提交订单并等待同请求的并发事务结束。

本插件依赖`idc-core/backend/cap/channelcommercecap`，不直接读取其他插件私有表。未取得证据的魔方、`WHMCS`兼容能力保持关闭；同款系统自动导入和付款拿货仍需`idc-peer`及正式映射装配，不由本插件基础接口单独构成完整交付。

## 客户中心开放平台

已获管理员授权的客户在用户中心自动显示“开放平台”。客户可查看接入地址、`AppID`、权限、来源限制、有效期和接口文档；重置密钥仅显示一次，并立即撤销旧密钥，不能改变管理员策略。已停用应用保留历史，不能自行恢复。

调用记录从此功能上线后开始保留，按当前客户分页查询，包含成功及可验证凭据归属的失败调用。错误密钥无法安全归属，因此不写入其他客户记录；日志不保存请求内容、查询参数、密钥或秘密输出。源码插件通过公开路由就绪事件和菜单状态接口适配自身已声明入口，不修改宿主。
