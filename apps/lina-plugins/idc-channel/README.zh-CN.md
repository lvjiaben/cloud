# idc-channel

`idc-channel`是 IDC 下游渠道集成的内建源码插件。

[English](README.md) | 简体中文

## 能力范围

本插件负责下游访问令牌、商品发布、请求证据、兼容适配和`Webhook`投递；订单、资金和服务真相仍归核心插件所有。

## 依赖

本插件只依赖`idc-core`公开的`idccap`契约。

## 交付

`v0.1.0`以`source + builtin`交付，并使用`platform_only`、`supports_multi_tenant: false`和`global`治理。

## 已交付接口

后台页面通过版本固定的 HTML 入口进入无同源权限的插件沙箱，数据请求统一走页面桥；插件不会接收宿主登录令牌。

插件已提供挂载在`/x/idc-channel/api/v1/channel/...`下的接口：

- 一次性创建和撤销访问令牌，数据库只保存令牌的`SHA-256`摘要；
- 只返回商品版本、币种、价格和库存的脱敏目录；
- 支持幂等下单和订单查询，保留归属模式与币种；
- 返回兼容能力矩阵。LinaPro通用API已启用，智简魔方财务、V10和WHMCS在取得正式契约证据前明确保持禁用。

下单后订单先进入`pending_identity`，必须通过宿主实名和财务门禁后才能触发履约。幂等编号会绑定完整下单内容，使用同一编号提交不同商品或币种会被拒绝。
