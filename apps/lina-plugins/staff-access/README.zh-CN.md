# LinaPro 员工业务资格插件

`staff-access` 是一个仅在平台范围运行的源码插件，统一管理“某个员工能否承担某项业务”的资格和范围。它不替代宿主的登录、角色权限和数据权限。

其他插件通过 `backend/cap/staffaccesscap` 检查目标员工是否可见、是否启用，以及是否拥有某项全局或部门级业务资格。超级管理员不受业务资格限制。每次新增、停用或恢复资格都要求最近完成过完整登录，并留下不可修改的审计记录。资格可以不设期限，也可以填写生效时间和到期时间；每次判断都以数据库时间重新检查，尚未生效或已经到期时直接拒绝，不依赖定时任务或缓存刷新。

管理页面由插件自己的前端独立构建，再通过标准插件页面机制挂载，不需要修改宿主前端源码。
