# DCIM 服务器连接器

`idc-dcim` 是一个用于 DCIM 服务器供应商的托管动态连接器。管理员可以添加任意多个接口实例。每次保存接口版本时，都必须明确冻结为 `legacy` 或 `bms` 协议；连接器不会猜测、自动回退或混用协议。

## 安全边界

接口地址和全部凭据始终留在 `idc-resource` 的机密出站代理内。只有不敏感的 `protocol` 设置会进入 WASM 内存。连接器只发送声明式相对 HTTP 请求和响应字段白名单。它拿不到原始访问令牌、接口地址、用户名、密码、访问用户或访问令牌，也不会把这些内容写入结果、证据或日志。

宿主根据冻结的协议选择认证方式：

- `legacy`：宿主在每次请求的表单中注入 `username` 和 `password`。
- `bms`：宿主在每次请求头中注入 `access-user` 和 `access-token`。

管理员只填写结构化字段，不能录入可执行代码、任意请求头或任意认证 JSON。

## 已证明的接口

旧版协议通过 `POST /index.php?m=api&a=getSaleGroup` 和 `getAllMirrorOs` 提供有界候选查询。它原来的开通和生命周期调用依赖财务系统本地服务器编号、回调令牌和机密响应值，新宿主契约并未提供这些内容，所以这些动作会安全地明确拒绝，不会假装成功。

BMS 协议支持服务器组和操作系统候选查询、通过 `POST /bms/source` 创建服务器、通过 `GET /bms/source/{id}` 查询资源，以及开机、关机、重启、暂停、恢复和删除。操作已有资源前会先精确查询该资源。网络结果不确定时会返回“结果未知”，交给人工核对，绝不会当成成功。

BMS 创建时的密码由宿主作为操作机密保存。只有固定槽位名 `password` 会进入 WASM，真实值由代理注入供应商表单。

## 商品配置

插件声明 DCIM 专用的商品配置和客户购买字段。这些字段不会进入通用商品、购物车、订单、账单或服务核心。磁盘继续由 `idc-resource` 以服务器组件提供，连接器只在构建冻结的开通请求时把它映射成 BMS 表单。

本连接器不新增独立管理页面。商品编辑和服务器操作继续使用 `idc-core`、`idc-resource` 提供的受治理页面。

## 净室参考

路由名、HTTP 方法、认证放置方式和请求字段名，是根据用户提供的智简魔方财务解码源码独立整理出来的，主要参考 `app/common/logic/Dcim.php`。本插件没有复制供应商源码。

## 商家自定义开通参数

直接开通支持显式填写非秘密接口参数，名称与标量内容随订单冻结并进入连接器实际表单；未绑定的客户资料不发送上游。认证信息、上游客户身份和已付款单位数量继续由所属服务控制，供应商是否接受自定义参数以真实响应为准。上游转售商品配置继续只读。
