# LinaPro Vben 插件适配器

这是一个只负责前端契约的独立源码插件，统一约束业务插件如何使用官方 Vben 页面、表单、表格、弹窗、抽屉和按钮。它不承载 IDC 业务页面，也不要求修改 `web-antd` 业务源码。

业务页面继续放在各自插件的`frontend/`中，并把宿主已经公开的 Vben 组件传给`createVbenPluginAdapter`。基础契约库可独立构建；隔离运行时构建复用工作区中的官方 Vben 包，不依赖其业务页面。

表单抽屉可以通过`actions`提供已翻译标签和`onClick(values)`回调。次要操作使用官方按钮，取得当前尚未保存的表单值；提交期间或抽屉关闭后不能执行，不会自动提交或保存业务数据。

表格可以提供已翻译的工具栏`actions`；运行时使用官方按钮，并遵守禁用、加载和销毁状态。每个隔离表格和抽屉应用都有独立的 Vue 编号前缀，嵌套抽屉与搜索字段不会重复使用无障碍标题编号。

`isolated`入口会打包自身使用的官方 Vben 运行时。`mountIsolatedVbenTable`支持可选的`search`字段、初始`values`和`onSubmit(values)`回调。搜索和重置使用表格的 Vben 表单，重置完成后才回传当前值；字段为空时不显示搜索区域。业务拥有方仍负责请求数据并提供准确的分页总数。

`mountIsolatedVbenFormDrawer`支持`mountContent(container)`，由业务方把可信界面挂到真实 DOM 元素中，并可返回清理函数。内容回调被替换、抽屉关闭或句柄销毁时，运行时执行清理。它不解析 HTML 字符串，也不接管业务请求。纯内容抽屉使用`readOnly: true`和`fields: []`；既有表单抽屉继续保持表单行为。业务标签继续由调用方翻译，标准搜索控件使用 Vben 翻译。
