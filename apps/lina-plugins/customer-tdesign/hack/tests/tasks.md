## 两轮并发和异常复查

新增`TC012`，自有夹具分别控制请求完成顺序，不依赖其他文件数据：

| 子断言 | 验收结果 |
| --- | --- |
| `TC012a` | 续费报价中锁定周期，双击只提交一次，修改周期使原报价失效，失败重试保留确认键 |
| `TC012b` | 分类切换后旧失败不能覆盖新列表，`403`不清空登录且可重新加载 |

| `TC012f` | 旧刷新挂起时退出并重新登录，新会话独立刷新，旧刷新返回不能清空新登录 |
