# FB-52 0.13 保密出站通道独立安全验证

验证日期：2026-08-28

## 结论

智简魔方云连接器以 `dynamic + managed` 方式交付。依赖供应商秘密的请求只通过宿主管理的 `confidentialoutbound.execute` 通道执行，不通过普通插件调用、普通请求响应、WASM 内存、日志、任务证据或业务数据库传递秘密明文。

本次独立验证发现并修复了一个失败关闭缺口：原实现会按字段名删除 `password`、`token` 等敏感字段，但上游仍可能把本次令牌或密码放进允许的 `status`、`name` 等字段值。资源 owner 现在会在白名单投影后，用本次实际令牌、接口凭据和操作秘密检查明文回显；命中后只返回固定错误，不把原值带给动态连接器。

完成修复和当前工作区验证后，0.13 保密出站安全门禁没有剩余阻塞项。

## 验证范围

- `idc-zjmfcloud` 的托管动态清单、业务扩展入口、资源 Provider 动态桥和安全响应。
- `idc-resource` 的动态 Provider 运行时、短时上下文注册、秘密句柄隔离、宿主侧 HTTP 执行、响应投影和秘密持久化。
- 宿主已有的 confidential outbound 注册表和 WASM host service 行为测试，仅作为只读验证证据，本次没有修改宿主源码。
- 不包含批量续费、服务器迁移 SQL、OpenSpec 状态、任务勾选或用户偏好更新。

## 安全边界

1. `idc-resource` 保存接口实例、上游地址和秘密句柄，并为一次准确的 Provider 方法创建最长 5 秒的上下文。
2. 上下文绑定 owner、动态插件、发布版本、发布摘要、声明摘要、契约、Provider 方法、用途和接口实例。
3. 动态插件的普通 invocation 只取得规范化业务参数、秘密槽位名称和随机上下文编号；接口实例编号、上游地址、秘密句柄和明文不进入该载荷。
4. WASM 只有在宿主确认当前执行来源是 business extension、清单已授权 `confidentialoutbound.execute`，并且请求上下文编号与当前 invocation 完全一致时才能调用保密通道。
5. 资源 owner 在宿主内短暂读取接口凭据、会话令牌和本次操作秘密，完成上游请求后只保留允许字段。原始响应字节会在投影后清除；允许字段中若仍出现本次秘密明文，整个结果失败关闭。
6. 宿主只接受按顺序、有限次数、有限字节的一次调用链；重放、跨插件、访客自行选择接口实例、过期和未知上下文都会在供应商处理器前拒绝。

## 威胁验证结果

| 风险 | 验证结果 | 主要证据 |
|------|----------|----------|
| 不是 `dynamic + managed` | 通过 | 清单测试固定检查 `type: dynamic`、`distribution: managed`，并拒绝源码兼容入口。 |
| 普通 invocation 携带秘密 | 通过 | 运行时测试确认普通载荷不含接口地址、接口实例、秘密句柄；只传规范化业务值。 |
| WASM 内存取得秘密或句柄 | 通过 | 动态操作投影只保留秘密槽位名称；托管 guest 测试扫描所有 host-call 载荷；宿主只在 owner handler 内读取句柄。 |
| 普通请求或响应泄露秘密 | 通过 | 登录只返回 `Authenticated`；业务响应先按字段白名单投影，再检查令牌、接口凭据和操作秘密是否被上游回显。 |
| 原始错误进入日志或证据 | 通过 | guest 将 confidential 错误压成固定错误；宿主将 handler 错误压成固定错误；公开日志、指标、证据和值对象的凭据扫描测试覆盖普通和编码形式。 |
| 任务证据或数据库保存明文 | 通过 | Provider 结果契约拒绝明文秘密；PostgreSQL 测试把秘密创建、替换、撤销后聚合读取绑定表全部行并检查原值不存在。 |
| 跨插件调用 | 通过 | 注册表用当前插件和冻结发布证据精确匹配；跨插件测试在 handler 前拒绝。 |
| 跨接口实例调用 | 通过 | owner 注册测试固定检查准确接口实例；guest 载荷不得携带接口实例；宿主测试拒绝 guest 自选其他接口实例。 |
| 过期、重放或普通路由调用 | 通过 | 注册表测试覆盖过期和序号重放；WASM 测试覆盖普通路由调用被拒绝。 |
| 允许字段夹带实际秘密值 | 修复后通过 | 新增令牌、接口凭据、操作秘密三类 canary 回显测试，均失败关闭且错误不反射 canary。 |

## 剩余风险说明

Go 的垃圾回收运行时不能承诺把每个临时 `string` 副本从进程内存中物理擦除。本门禁保证的是秘密不进入不可信 WASM、普通 invocation、普通响应、日志、证据或数据库，并尽量缩短宿主内明文生命周期、清除可控字节缓冲。若以后改变 HTTP 编码方式、增加允许响应字段或新增 confidential 方法，必须重新执行同等级 canary 回显、边界和持久化验证。
