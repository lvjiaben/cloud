# 群英风格官网

本插件遵守主仓入口。用户指定`https://www.qycn.com/index.html`为本插件视觉参考，允许缺失能力使用静态示例内容；该决定仅作用于本插件。

- 独立中英文、多页、托管动态官网；不得依赖宿主或其他插件私有源码。
- 公开展示消费已发布匿名接口；商品配置、购物车、核价及订单确认属于官网，复用已发布购买接口和受信任的认证桥。登录与账单付款进入配置的客户中心，不编造订单、价格或提交成功。
- `frontend/`维护页面资源，`scripts/build.mjs`生成声明中的实际页面；构建产物不作为源码维护。
- 验证入口为`pnpm test`、`pnpm test:e2e`和`pnpm package`。截图写入仓库`temp/<日期>/`；仓库外使用可配置的`E2E_OUTPUT_DIR`。
