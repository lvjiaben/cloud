# 群英风格官网模板

独立中英文、平台级、托管动态官网插件。布局参照[用户指定官网](https://www.qycn.com/index.html)，包含营销轮播、后台产品分类、真实商品卡片、服务优势、区域节点、生态展示、资讯与页脚。不修改其他模板或宿主。

## 构建与预览

需要`Node.js >= 22`、`pnpm 10.30.3`和`Go >= 1.25`。在本目录执行，复制到仓库外后使用相同命令：

```console
pnpm install --frozen-lockfile
pnpm build
pnpm dev
pnpm test
pnpm exec playwright install chromium
pnpm test:e2e
pnpm package
```

预览默认地址为`http://127.0.0.1:16880`。可通过进程管理器或终端设置环境变量：

| 变量                               | 默认值                  | 用途                                         |
| ---------------------------------- | ----------------------- | -------------------------------------------- |
| `PORT`                             | `16880`                 | 本地预览端口                                 |
| `HOST`                             | `127.0.0.1`             | 预览绑定地址                                 |
| `WEBSITE_API_ORIGIN`               | `http://127.0.0.1:6030` | 现有后端公开接口地址                         |
| `WEBSITE_CUSTOMER_URL`             | `http://localhost:6032` | 客户中心地址                                 |
| `WEBSITE_CUSTOMER_ALLOWED_ORIGINS` | `[]`                    | 额外受信客户来源的显式`JSON`数组，禁止通配符 |
| `WEBSITE_PROXY_IDLE_TIMEOUT_MS`    | `9000`                  | 预览上游响应的空闲超时，毫秒                 |
| `E2E_OUTPUT_DIR`                   | 仓库`temp/<日期>/`      | 可指定仓库外测试证据目录                     |

预览服务是开发工具，不是生产网关。它按路径及方法代理公开展示、访客购物车与账户购买接口；只向固定后端的账户购买接口转发认证头，访客购物车只携带自身的保护 Cookie。`frontend/dist/`包含真实的`14`个页面及本地资源；`dist/website-qycn.wasm`包含动态入口、清单和公开资源。没有`SSR`进程，不依赖私有仓库源码。

## 安装

通过现有插件安装界面上传`WASM`，满足声明的`idc-portal`与`idc-core`依赖，安装并启用后，在官网配置选择“群英风格官网”。品牌、标志、公司、联系方式、网站备案号、公安备案号及查询链接和导航继续在官网公共配置维护。模板声明中英文首页标题、副标题、背景图片及中英文合作伙伴（每行一个名称）字段；只有当前选中本模板时才使用其独立字段。切回旧模板时保留原配置。

现有官网网关负责加载选中模板的正式资源，并注入`window.__LINA_TEMPLATE__.customerUrl`。本插件不注册后台菜单、不改变认证、不自行切换当前模板。导航使用已声明的`.html`页面；文章详情使用`article.html?kind=news&id=<contentNo>`。

## 数据边界

| 内容                   | 来源与行为                                                                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 品牌与头尾导航         | `GET /x/idc-portal/api/v1/public/brand`；非空配置导航优先；空导航恢复模板菜单及接口分类                                                        |
| 商品                   | `GET /x/idc-core/api/v1/public/catalog/products`；有界游标分页，`namePrefix`与`categoryNo`由服务端筛选                                         |
| 商品配置               | 官网`/configure.html?product=<publicSlug>`，读取已发布配置、评估和报价接口；购物车为`/cart.html`，核价、订单确认位于官网，付款进入客户中心账单 |
| 新闻、公告、知识、下载 | `GET /x/idc-core/api/v1/public/content/items?type=...`；详情读取`/items/<contentNo>`                                                           |
| 下载                   | `POST /x/idc-core/api/v1/public/content/items/<contentNo>/download-tickets`，再访问`GET /x/idc-core/api/v1/public/content/downloads/<token>`   |
| 登录与注册             | 已配置客户中心的`/auth/login`和`/auth/register`                                                                                                |
| 产品分类与商品         | 使用公开目录，不展示硬编码商品或价格                                                                                                           |
| 合作伙伴               | `templateConfig.partners`与`partnersen`，每行一个名称，空值隐藏                                                                                |
| 节点、公司介绍         | 明确标识的静态示例；不会创建订单或提交结果                                                                                                     |

目录接口不提供最终权威价格，因此真实商品显示配置与报价入口，不伪造售价。下载读取文件响应后再保存，浏览器使用`30`秒空闲超时，持续传输不设固定总时限；文件错误、断流或停滞保留在详情页重试。文件在浏览器准备为`Blob`，没有额外业务大小限制。接口失败提供重试；真实列表为空或请求失败时，不用假记录替换。联系方式不编造。发布内容正文按文本显示，不执行其中的`HTML`。本插件不建数据库表；认证令牌只保留在页面内存，不进入 URL 或本地持久存储。配置草稿不是权威价格，报价与订单以服务端为准。

## 维护与验证

`frontend/locales/zh-CN.js`维护双语展示数据，`frontend/i18n.js`与语言资源维护语言切换；`frontend/views.js`维护页面结构；`frontend/app.js`维护交互和公开数据投影；`frontend/style.css`维护独立官网文档样式。`scripts/build.mjs`根据真实页面声明生成页面；`scripts/package.mjs`打包前检查每个声明页面。

`TC004`覆盖中英文、品牌/公司/备案、伙伴配置和真实分类失败恢复；`TC005`覆盖官网配置、账户购物车、历史访客合并、核价及幂等订单。`TC003`覆盖文件阶段失败、断网、票据校验、匿名下载和重复提交保护；可控时钟测试区分长下载与停滞。`TC001`覆盖桌面、移动展示和路由；`TC002`覆盖数据、游标与筛选参数、空导航、危险链接、错误恢复和下载。测试数据仅存在于`hack/tests/`，不进入发布包。交付测试通过真实预览代理验证下载响应头、匿名请求转发和构建残留清理。动态描述桥单测覆盖身份绑定和异常输入。在主仓工作时，使用`make lint dir=apps/lina-plugins/website-qycn plugins=1`检查本插件的`Go`代码。

描述桥与公开`WASM`打包工具来源于本项目`website-html`示例，在本插件独立维护。首页背景图形、图标、排版与交互均由本地代码实现。两张装饰参考图于`2026-10-22`下载并本地打包：`frontend/media/world-map.jpg`来源于`https://www.qycn.com/home/img/map_dark.jpg`；`frontend/media/city.jpg`来源于`https://www.qycn.com/home/img/why_huicui.jpg`。不包含第三方跟踪脚本、联系方式、商标图、凭据或远程运行依赖。

## 认证适配协议

官网读取可信网关注入的`window.__LINA_TEMPLATE__.customerUrl`，只向该来源的`/auth/website-session`请求会话，核对`postMessage`的来源、窗口和随机`nonce`。客户模板必须只信任管理员配置的官网来源。登录返回仍使用`POST /__website/session`，字段为`accessToken`、`returnTo`；本地适配器仅接受主客户中心来源、显式配置的附加来源及`cart.html`、`configure.html`、`products.html`和`services.html`。一次性交接保留`30`秒，凭据在服务端内存中，浏览器仅接收`HttpOnly`随机句柄。生产网关需实现同一协议；宿主本身不会自动提供这些地址。

公共备案资料由`idc-portal`拥有，需运行含本次字段的后端版本。未填写公司或备案资料时不伪造值。文件配置使用已发布的账户安全上传接口；本地开发代理单次上传上限为`64 MiB`，生产仍以拥有方策略和网关限额为准。

轮播默认每`6.5`秒循环切换，手动切换重新计时，不显示播放或暂停按钮；减少动态效果时取消动画而不取消定时切换，键盘阅读轮播链接和后台标签页暂停推进。`TC006`覆盖空导航、接口返回乱序、失败重试、默认自动播放与键盘焦点保护，以及手机和小屏桌面英文菜单。

品牌接口返回前，页面名称、Logo 与 favicon 不使用示例品牌占位。选配页将配置、购买周期和费用集中展示，默认配置及改配自动调用评估和报价；可选数值或枚举规格默认选择首个可售项，连续数值从声明的最小值开始，合法的零保留；已有合法选择和购物车恢复值不被覆盖。清空数字只作为编辑中的暂态，不提交空字符串；服务端评估恢复首值后重新取得权威报价，不提供“套餐默认”伪选项。连续修改取消旧请求，加载和报价失败显示重试，报价期间禁用加购；手机底部固定合计与加购入口。`TC007`覆盖品牌慢响应、自动报价、慢会话读取、连续改配、失败恢复和手机中英文布局。

选配评估与报价并行执行，输入合并等待为`120ms`；相同配置的重复输入/失焦事件不重复请求。仅在评估有效且配置版本与值一致时采用并行报价，服务端规范化配置后重新核价；不缓存交易价格。`TC008`覆盖并行启动、同值去重、规范化后报价和无效配置保护。

选配页左侧从公开目录读取真实分类和商品，支持分类筛选、分页、失败重试、中英文与手机布局。目录独立加载，不阻塞选配及核价；`TC009`覆盖慢目录、不同行为状态和移动端。核价使用后端已发布数据，资源候选读取数据库快照，真正购买仍重新检查准入与价格。

手机选配页的返回顶部按钮随底部购买栏实际高度定位，包括状态文案与设备安全区变化，避免重叠误触；`TC009`验证窄屏返回顶部、购物车不变及正常加购。

购物车参照用户指定的小白云页面，采用完整配置卡、数量增减与更新、原条目编辑/移除、固定底部总价与优惠码，以及独立结算详情。加购写请求前必须登录，安全回跳恢复配置/币种/周期但不自动加购；写入响应丢失时沿用原购物车版本重试，避免重复加入。需要`idc-core >=0.1.167`的账户购物车原子更新和批量价格选择/周期投影。修改后使旧报价失效，重新取得服务端金额；本地草稿只补充配置展示，不计算价格。优惠使用当前账户优惠资产及拥有方规则，当前保持整车结算。

结算详情从公开账户接口读取同币种余额和可用浏览器支付渠道；余额不足不允许预选余额付款。选中的方式通过安全查询参数交给客户中心账单，客户中心重新核验并要求确认，官网不发起付款。支付插件缺失或读取失败时提供账单内选择入口，不伪造渠道。`TC010`覆盖登录门槛与恢复、配置卡、数量失败重试、优惠、支付偏好、英文手机、丢失响应与原条目编辑。

`TC011`覆盖中英文单选/下拉/滑块、首项初始化、类型化原值和摘要、零值、清空后恢复、禁用/隐藏、可用周期及手机报价失败恢复。

加购直接复用打开和添加接口返回的权威购物车；加载复用合并接口返回的当前购物车，明确返回`null`时直接显示空车，只有旧拥有方缺少`cart`字段时兼容重读；普通核价使用返回的新购物车版本，不再重复读取，旧报价补配后仍读取最终权威状态。优惠券列表、余额和支付渠道独立加载，不阻塞结算入口，读取失败可单独恢复；付款仍在账单重新校验并明确确认，不缓存交易价格或授权决定。`TC010g–j`验证请求数、报价后乐观版本、慢辅助接口非阻塞、失败重试和旧报价必要重读。

加载时复用仍有效的报价，也会使用本页已存草稿冻结必填配置，并在修复后仅重读一次权威购物车，不重新创建报价；已冻结报价没有额外读取，无草稿仍须补全配置。`TC010k`覆盖恢复、缺少草稿和冻结失败后的重试。
