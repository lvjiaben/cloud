# org-core

`org-core` 是 LinaPro 官方提供的组织管理源码插件。

[English](README.md) | 简体中文

## 能力范围

该插件负责：

- 部门管理
- 岗位管理
- 宿主用户管理所消费的可选组织能力

## 宿主边界

宿主保留用户管理、认证和菜单治理能力；本插件补充组织相关 API、菜单和 `manifest/sql/` 下的插件自有表结构。

## 权限管理帮助

部门和岗位菜单声明在宿主`iam`目录下，与用户、角色入口归在一起。启动时的菜单同步更新已有记录，保留权限标识和角色授权。宿主已有空目录隐藏能力，因此原组织管理目录不再出现在导航中。

通过已发布的`layout.header.actions.before`插槽，在用户、角色、菜单、部门和岗位管理页右下角悬浮展示问号帮助按钮。抽屉以中英文说明配置步骤和权限边界，不修改宿主页面或路由。
