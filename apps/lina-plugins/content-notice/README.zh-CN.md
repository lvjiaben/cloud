# content-notice

`content-notice` 是 LinaPro 官方提供的内置公告源码插件。

[English](README.md) | 简体中文

## 能力范围

该插件负责：

- 公告增删改查、草稿发布与正文图片
- 持久排序与当前用户的已读状态
- 用户中心与官网共用的已发布公告源
- 挂载到宿主 `content` 目录下的默认菜单入口

## 宿主边界

宿主保留 `content` 目录骨架、认证、租户边界和菜单治理；本插件随宿主编译，业务数据仍只保存在插件自有表中，并通过宿主公开能力获取用户信息。已发布公告使用同一数据源且没有可见范围配置，阅读状态按当前登录用户隔离。它属于基础业务能力，启动时强制启用，不在插件管理中展示，也不能被停用或卸载。

## 插件元数据

| 字段 | 取值 |
| --- | --- |
| 插件 ID | `content-notice` |
| 类型 | `source` |
| 分发治理 | `builtin` |
| 作用域 | `tenant_aware` |
| 安装模式 | `global` |
