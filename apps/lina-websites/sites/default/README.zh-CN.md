# 默认公开官网

这个 Nuxt 应用只负责公开首页、商品目录与配置展示、新闻、公告、知识库、下载和帮助页面。

登录、客户账户、购物车、结算、订单、财务和认证由独立的 Vben`@lina/web-customer`应用负责。官网入口只使用部署时的`NUXT_PUBLIC_CUSTOMER_URL`跳转，本包不渲染客户私有路由，也不调用客户私有接口。

开发和生产均将匿名官网接口代理到`NUXT_API_ORIGIN`（默认`http://127.0.0.1:6030`）。后端使用其他端口时需配置这个地址。代理不开放后台接口，详见[官网公开接口说明](../../docs/api.zh-CN.md)。

安装并启用`website-default`或`website-minimal`后，在“系统设置 → 官网配置”选择并配置。两个插件使用不同的内置布局，公共信息和模板字段来自当前启用的配置。
