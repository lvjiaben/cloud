# 官网压缩包格式

压缩包根目录必须有`site-package.json`，其余文件是 Nuxt 生产产物。`site-package.json`必须通过`@lina/site-contracts/site-package.schema.json`检查，并列出除清单自身外的全部文件、字节数和小写 SHA-256。

生产包使用 Ed25519 签名。签名输入是移除`publisher.signature`后按 RFC 8785 规范化的 UTF-8 清单字节；`publisher.keyId`必须命中当前安装实例本地信任的发布者公钥。清单自带的身份或公钥不能自动成为信任来源，软件提供方的在线服务也不参与验签。示例中的零签名只能用于看字段，不能通过生产校验。

服务端安装器必须自己重新计算，开发期检查结果不可信。安装器还必须拒绝路径穿越、绝对路径、反斜杠绕过、符号链接、硬链接、设备文件、重复或大小写冲突文件、未声明文件、超限文件数量、超限压缩包和解压炸弹。

官网包只允许`nuxt-node-1`运行时，入口为`server/index.mjs`，静态资源为`public`，健康检查为`/__site/health`。压缩包不得包含源码安装脚本，不得在安装或启动时联网装依赖。

当前文件冻结清单字段和签名输入，但生产打包器、本地信任管理和后台安装器仍未实现，不能把示例压缩成文件后直接用于线上。
