### 总览页摘要

[官方总览](https://docs.idcsmart.com/docs/财务系统使用文档)把客户、商品、收款、交付、服务管理、工单及分销连成运营流程。总览只是能力导航，具体版本与子页可能不一致；不能据“支持”两字认定当前插件已实现或可自动开放。

### 必须保留的阅读限制

- `104`页含图片，合计`591`个图片引用，本轮没有逐张完成视觉核实。尤其“充值设置”“主题模板设置”正文缺乏字段解释；单独图片读取失败，随后浏览器页面虽已打开但查看连续超时，不能猜测截图里的开关、默认值或校验边界。
- 部分目录只列功能名，没有对应独立子页，例如信用额细则；退款汇总正文不完整。缺少规则不等于功能不存在，也不能由代理自行补规则。
- 正文混有旧版本、旧官网链接、截图及上一篇／下一篇的摘要。页面相邻文字不是该页独立规则；术语错误和明显模板化段落已经标注。
- 覆盖的是本次能从财务目录发现的子页面，不包含未链接的隐藏页面，也不扩展为全站其他版本、论坛、应用商城和第三方接口文档。分类外链接保留线索，后续实现对应能力时定向补查。
- 本轮未用这些参考说明向真实服务器发命令、进行收付款或测试现有客户数据。没有核实的项目业务，以下一律记录为待回归，而不是通过。

这张图是本项目现有业务边界的检查视图，不是把竞品实现复制过来。订单、账单、资金、服务和上游任务各有自己的状态；任意一层“成功”都不能替代其余层的权威结果。

## 已发现的重要差异

| 参考中的行为或表述 | 本项目处理边界 |
| --- | --- |
| 注销客户可删除关联订单账单，流水可直接编辑 | 保留账务及审计历史，不能通过改列表数据制造收款或抹掉交易 |
| 货币总览与细则对多币种描述不一致 | 遵循已确认的逐币种账户与显式定价，不靠汇率临时补价 |
| 降级可退余额；多个产品退款按首项提成扣减 | 不照搬；按本项目变配、退款和冻结归因规则处理 |
| 销售归属或比例变更后实时重算历史提成 | 不覆盖历史冻结证据，退款与冲回要有独立依据 |
| 个人、企业认证可由多种插件组合 | 仍先姓名及身份证实名，再企业认证；具体提供者与审核证据不可混用 |
| 机柜、独服、云主机共用部分管理入口 | 能力按类型与连接器声明展示，机柜不能出现无效重装或控制台操作 |
| 接口连通、保存成功、支付回跳都呈现成功界面 | 分别核对配置验证、权威到账、结清与上游终态，不能互相替代 |
| 默认加价比例、自动同步售价、导入后直接出售 | 用户已确认仅导入草稿、人工发布，支持按上游加价或填写最终售价；加价没有竞品默认值，不自动同步改价 |
| 魔方云允许自然月或订购日重置流量 | 当前实例没有可靠重置日期时，必须显示已确认提示；不能自己推算 |
| 旧版建议关防火墙、赋超级管理员、卸载重装 | 仅作旧故障线索，不作为本项目自动执行方案 |

## 业务回归检查清单

下面是从文档与本项目规则整理的验收索引，不是新增业务决策。尚有歧义的收费、状态、资格或权限，必须先查用户已确认规则，仍不能确定时再询问。每个检查项只有附上当前版本的自动化或真实操作证据后才可勾选。

### 客户与权限

- [ ] `C01`：客户列表、详情、订单、资金、服务器、工单和通知按同一目标身份及数据范围查询，替换编号不能查看他人数据。
- [ ] `C02`：个人实名与企业认证分开记录；未通过个人实名不能绕到企业认证，失败、取消和待审状态不能显示通过。
- [ ] `C03`：修改联系方式、停用账号、重置密码和注销不互相冒用；停用后的会话和敏感操作按现有规则处理。
- [ ] `C04`：完整模拟登录保留实际员工与目标客户双身份、十五分钟期限和单次交接；业务自身门禁仍生效。
- [ ] `C05`：客户备注与跟进仅按既有可见范围展示，状态使用可读中文；模态框可反复打开，黑名单提交不等于已审批。
- [ ] `C06`：销售个人范围、未分配客户和部门工单范围各自校验，不因显示同一客户摘要而扩大权限。

### 商品与供应商

- [ ] `P01`：商品区分连接器类型及具体接口实例；已保存、连接验证、启用和可售是不同条件。
- [ ] `P02`：导入商品前逐项校验地区、系统、处理器、内存、磁盘、带宽和地址配置；单位、必选、枚举、上下限和默认值按提供者契约解析。
- [ ] `P03`：支持浏览完整上游商品集合但分页有界；断页、重复商品、失效配置及并发导入不会产生重复商品。
- [ ] `P04`：商品导入遵守已确认的草稿、人工发布与定价规则；无法识别配置时列出缺项并生成待补齐草稿，补齐且通过校验后才可发布；已下单的价格、接口及配置快照不随上游同步改变。
- [ ] `P05`：接口详情“已激活／总量”统计本地服务器实例，“已设置”统计绑定商品，不能把三种数量混算。
- [ ] `P06`：云主机、独服、机柜和手动资源只展示真实支持能力；库存、空闲服务器、地址和上游余额不足时不假报开通成功。

### 财务与交付

- [ ] `F01`：报价、订单项、账单、币种和支付金额保持一致，税额只在已确认总价内拆分，不重复加税。
- [ ] `F02`：支付回调验签并核对商户、金额、币种及对象；重复、乱序、迟到回调不重复入账。
- [ ] `F03`：余额充值与使用余额付款分别记账，不重复统计收入或提成；同时付款不超扣。
- [ ] `F04`：未付款、部分付款、未结清与结果未知不得进入交付；返回收银台成功页面不等于账单已结清。
- [ ] `F05`：新购、续费、变配和附属购买分流准确，不能因库存标记共用而把流量包订单开成新服务器。
- [ ] `F06`：退款按照原资金来源和已确认同意流程执行，部分退款、组合支付与冲回不改写历史交易。
- [ ] `F07`：信用额度、可用额度、应还和余额分开；并发占用及释放由财务拥有方维护，不能由列表直接改金额。
- [ ] `F08`：合同准备失败不阻断无需合同的普通个人订单；电子签、发票申请、审核、实际签署或开具不得合并成一个成功状态。
- [ ] `F09`：报表按明确时区、日期、币种和真实资金事实聚合，待付订单不计实收，未知成本不当成零。
- [ ] `F10`：业务取消或逻辑删除保留订单、流水、快照、原始归属和审计；恢复不能重复收款或执行任务。

### 流量包与自动化任务

- [ ] `A01`：只展示适用当前商品与服务器能力的已发布固定容量套餐，报价冻结容量、一次性总价、币种和原服务器。
- [ ] `A02`：未知具体重置时间时，购买前显示“有效期按上游重置规则执行，暂未提供具体到期时间”；缓存、报价和服务器到期不能替代套餐有效期。
- [ ] `A03`：真实结清后只给原服务器追加一次；重复结清事件、进程重启和事务回滚不会多加流量，也不自动开机或解除暂停。
- [ ] `A04`：上游超时或响应歧义仅查询核对，不自动重放写入；真实任务终态与本地状态一致后才展示完成。
- [ ] `A05`：运行、关机及流量原因暂停的购买资格按已确认规则判断；无限流量、负数、零值和溢出不得通过增量接口。
- [ ] `A06`：定时任务区分最近开始、完成、失败和积压；一次手工运行成功不能代表长期正常。通知或上游请求不阻塞本地下单事务。

### 工单、通知、营销与界面

- [ ] `O01`：工单部门权限、员工回复、客户回复、关闭和私密备注分别测试；关闭与上游传递完成不是同一事实。
- [ ] `O02`：重叠传递规则、自动回复覆盖、敏感关键字和失败重试有明确规则；私密备注不得透传给客户或上游。
- [ ] `O03`：通知通道安装、配置、验证、模板审核、启用、额度和收件人同意分别检查；发送接受不等于送达。
- [ ] `O04`：推荐佣金与员工提成分别核算；新购、续费、退款、延迟确认和提现不重复计入，已确认反滥用规则不能因导入历史数据跳过。
- [ ] `O05`：后台和客户端使用真实`Vben`表格与搜索，灰色表头、其他表格区域白色，分页总数与筛选及权限一致。
- [ ] `O06`：表格不被侧栏遮挡、不无限增高，固定操作列和数字分页可见；移动端菜单默认关闭且跳转后收回。
- [ ] `O07`：公告、工单和配置抽屉具备清楚的按钮、表单边框、加载与失败反馈，可连续打开，保存操作区始终可见。
- [ ] `O08`：插件重启保留安装状态和配置；停用新入口不破坏已有订单、异步回执和审计；迁移前后按币种及对象核对而非只比总行数。

## 2026-10-25：商品编辑反馈的原生协议核对

用户指定参考：[魔方财务源码](https://github.com/aazooo/zjmf-manger-decoded)，核对提交`58532ead9cd01515b0794dabe744e186eea6eea2`，仓库标注版本为`3.5.8`。本次只研究公开协议、字段和行为，没有复制实现、模板、数据库结构或授权代码。该仓库不能证明魔方业务`V10`使用相同协议。

| 环节 | 源码位置及协议 | 本项目需要遵守的行为 |
| --- | --- | --- |
| 商品目录 | `app/home/controller/CartController.php::getProducts`，`GET /cart/all` | 返回可见分组内的商品；列表读取一次，按实际可见集合计数，不逐商品读详情 |
| 单商品定义 | 同文件`getProductConfig`，`GET /cart/get_product_config?pid=...` | 规格由`config_groups/options/sub`提供，具有类型、数量范围、分段方式、联动以及自定义字段；不能按名称推断为固定`CPU`、地区或线路 |
| 原始周期价格 | 同接口`product_pricings`和子项`pricings` | 基础价与选项费用分开，`-1`表示未提供；`pay_type`中小时及天周期的倍数必须保留 |
| 账号实际报价 | 同文件`getTotal`，`POST /cart/get_total` | 以配置项`ID`为键，传子项`ID`或数量；账号折扣、资源等级及再次代理会调整费用，原始价格表不能替代权威整件报价 |
| 创建及结算 | `/cart/add_to_shop`、`/cart/settle` | 商品、周期、配置项和客户自定义字段一起传递；不能把已创建未支付账单判为完成付款 |

当前实现已经完成商品编辑页签、参数弹窗、必选会员导航、库存/配套商品直接显示和购买链接；目录可见性改为读取资源接口的真实方法集合。额外修正原生小时/天周期被当作`1`以及账号价格调整被误认完整价格的问题。

最初核对时，原生转售仍受固定服务器计划限制，且尚未取得`V10`权威定义。该段是本轮实施前的缺口记录；随后已按下述官方源码补齐通用原生计划、财务完整选配和`V10`通用模块远程核价。此前的页面及本地验证事实继续保留，不能据此宣称已经通过真实供应商实连验收。


### 转售编辑行为复核

`app/admin/controller/ProductController.php::edit`的上游分支要求接口和上游商品编号，仅接受百分比或自定义价格方案；自定义方案保存本地商品周期价格，禁用的上游周期仍保持不可售。普通自定义字段及配置关联的保存位于非上游分支。`app/common/logic/Product.php::syncProduct`同步源配置、子项及其计价依据，内部保留可逆上游编号；这些是报价及下单依据，不是商家独立编辑选项价格的入口。

用户再次明确：对接转售上游不能改配置，也不提供配置选项价格的单独编辑；魔方云、`DCIM`等直接开通接口继续维护本地配置。已补充价格接口的保护：导入商品仍能维护本地基础售价，但创建、修改、删除及批量写入上游配置选项费用都必须拒绝，不能只靠页面隐藏。


### 本轮补齐的原生转售协议

财务`v0.1.7`与业务系统`V10 v0.2.4`使用独立`NativePurchasePlan`，必须显式声明`native_finance_v1`或`native_v10_common_v1`，不再填造服务器硬件计划。商品只冻结真实源商品编号与配置版本；上游配置和选项费用只读，商家只维护商品级百分比或自定义整件售价。资源拥有方保存回调关联、注入秘密令牌并保留查询优先幂等链，不能由客户输入采购身份或回调秘密。两连接器最低依赖为`idc-core v0.1.165`及`idc-resource v0.1.72`。

财务配置已保留普通选项、数量区间及阶梯语义、客户字段，以及`advanced`的等值允许集合并集、排除集合和数值范围。类型`20`按`ConfigOptions.php::getTree/webGetLinkAgeList`的真实`linkage_pid`保留候选父子树；终端叶携带整条配置与子项路径，采购还原全部祖先参数，价格累计各层周期费和安装费。高级联动可引用树内子层；不存在的子层不触发源前端的`sneq`条件。非叶、跨分支、孤儿或循环不能购买。

财务账号等级折扣的`get_product_config.data.flag`来自`getSaleProductUser`。所有财务原生转售均采用导入协议`v3`的`remote_evaluation`，只冻结配置和周期元数据，不对外输出公开原价或配置组件价作为整件售价。后台明确请求预览时使用真实默认选配核价；必填客户信息缺少默认值时不补零价。`get_total`使用真实默认币种编号，读取明确的`sale_signal_price`和`sale_setupfee_total`；普通账户读取`signal_price`和`signal_setupfee`。配置版本指纹排除金额，保留配置、收费算法、区间、周期和币种语义；当前价格与报价失效由实时核价及报价指纹处理。

`V10`依据[官方业务系统源码](https://github.com/idcsmart/ZJMF-CBAP/tree/cf3b2d0d7586ec482f064f4e99259c062c89043c/10.4.6)，提交`cf3b2d0d7586ec482f064f4e99259c062c89043c`，版本目录`10.4.6`。财务`3.5.8`源码的商品版本同步不能证明`V10`协议。业务系统先读取`GET /api/v1/product/:id/resource`的明确模块声明；本轮实现`idcsmart_common`，不下载或执行其模块压缩包。官方`reserver/idcsmart_common`包装接口兼容本机原生和再次转售商品。

| `V10`环节 | 官方源码依据 | 本轮映射 |
| --- | --- | --- |
| 配置和可售周期 | `reserver/idcsmart_common/controller/home/CloudController.php::cartConfigoption`及原生回退 | 读取`reidcsmart_common/.../configoption`，保留单选、多选、数量数组、有限重复数量、操作系统候选和客户字段 |
| 选配账号价 | 同控制器`cartConfigoptionCalculate`及`IdcsmartCommonLogic::cartCalculatePrice` | 请求`is_downstream=1`，按当前配置读取整件周期金额；不构造不存在的静态选项价表 |
| 采购参数 | `app/home/model/CartModel.php::createCart/settle` | 使用`config_options[cycle]`、`config_options[configoption]`和`self_defined_field`，不把数量标量误传成源默认值 |

资源内部`ImportedBillingSource`只接收拥有方已经核验的发布商品及冻结读证据，再校验接口版本、精确商品与资源声明、当前源配置并调用固定核价方法。它不借用员工权限，也不能由调用方指定任意供应商方法。采购数量与周期数每个原生意图均为`1`，上限沿版本化导入契约冻结；旧下游不能静默剥掉限制或动态计价模式。

支持边界仍需明确：未知`V10`模块和更新版本未证明的级联结构不可导入；财务同目标混合`seq/sneq`、不可表达的数值`sneq`结果、未知配置类型、未支持的`PCRE`或秘密密码字段不静默放行。规则、树深度及候选数量超出公开契约上限时拒绝处理。`V10`重复数量按本轮有界槽位表达，超过`32`槽不导入。

当前证据包括连接器单元测试、真实本地`HTTPS`读取—选配—账号核价—真实周期计划—参数构建—执行链，以及资源冻结绑定、版本隔离和拒绝越权的隔离`PostgreSQL`测试。它们没有调用真实第三方账号写接口，不能替代供应商账号、版本及实际开通结果的实连验收。
