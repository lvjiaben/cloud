# 服务器与资源怎么用

这个分组供后台员工使用。客户在客户中心查看、使用和续费自己的服务，不需要操作供应商运维工具。

## 四个入口

| 入口 | 谁常用 | 用来做什么 |
| --- | --- | --- |
| 服务器管理 | 运营、客服 | 查客户服务器、管理附属功能、批量操作和续费 |
| 供应商运维 | 运维、管理员 | 查看供应商状态，处理服务器操作异常 |
| 魔方云服务器管理 | 使用魔方云的运维人员 | 查看魔方云专属实例和详情；由魔方云插件提供 |
| SSL证书 | 证书业务的客服、运营 | 处理证书申请、验证、下载和未签发申请；由证书插件提供 |

魔方云和SSL入口只在对应插件已安装、已启用、依赖满足且本人获权时出现。通用资源插件不会代它们提供入口。

## 旧入口去哪了

| 原入口 | 新位置 |
| --- | --- |
| 服务器管理 | 服务器管理 → 服务器 |
| 服务器续费 | 服务器管理 → 续费 |
| 资源运营总览 | 供应商运维 → 概况 |
| 上游渠道健康 | 供应商运维 → 连接状态 |
| 上游任务核对 | 供应商运维 → 操作记录 |
| 供应商容量观测 | 供应商运维 → 资源更新 |

每个人只看到自己有权限的页签。查看权限不会增加执行、续费确认、资源更新或人工接管权限。

## 日常流程

客户购买并付款后，系统执行开通，员工到“服务器管理”查看已交付服务。需要续费时切到“续费”，先核对费用和到期时间，再提交。

开通、重启等操作异常时，运维人员到“供应商运维”看连接状态和操作记录。结果不明时先核对；人工接管会停止自动核对，不会重新执行或把结果改成成功。

“资源更新”只查看、更新供应商资源采集记录。商品库存仍由商家在商品中设置，资源更新不会自动改库存、价格或上架状态。
