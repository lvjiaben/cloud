## 财务设置

### 1．财务设置

官方地址：[财务设置](https://docs.idcsmart.com/docs/财务系统使用文档/财务设置)。

摘要：财务配置的导航入口，归集货币、优惠码、发票、订单、合同和常见问题，并把支付接口指向其他分类。

注意：正文提及信用额设置，但本分类目录没有对应独立子页；不能据导航说明认定授信规则已经完整公开。

### 2．货币设置

官方地址：[货币设置](https://docs.idcsmart.com/docs/财务系统使用文档/财务设置/货币设置)。

摘要：管理员可按收款需求调整货币参数；文中要求改动时同步维护汇率和商品价格，并说明不支持多币种同时运行。

注意：属于该财务系统的版本限制，不适用于本项目已经确认的逐币种定价与同时使用多币种要求。

### 3．优惠码功能

官方地址：[优惠码功能](https://docs.idcsmart.com/docs/财务系统使用文档/财务设置/优惠码功能)。

摘要：优惠可以按比例、金额、替换价格或安装费减免配置，并限制商品、周期、时段、次数、客户资格及组合购买；另有续费和升级适用选项。

注意：页面规定某些循环或升级优惠可超出原有效期与次数约束；这不是本项目自动继承的业务结论。

### 4．发票设置

官方地址：[发票设置](https://docs.idcsmart.com/docs/财务系统使用文档/财务设置/发票设置)。

摘要：配置发票开关、收费比例与快递方式，客户按账单申请，后台查看和审核；文中使用待付款、待审核、驳回、寄出等状态。

注意：正文限定纸质发票，并以审核通过表示寄出；不能映射为本项目电子发票已开具或已交付。

### 5．订单管理

官方地址：[订单管理](https://docs.idcsmart.com/docs/财务系统使用文档/财务设置/订单管理)。

摘要：分别管理业务实例、停用申请、流量包订单及产品订单；可查询关联客户和详情，后台新单选择客户、产品、周期、配置及付款方式。

注意：业务实例状态与产品订单状态是两套概念。流量包段落只介绍订单查询和删除，没有有效期、自动重置规则或重置日期。

### 6．电子合同设置

官方地址：[电子合同设置](https://docs.idcsmart.com/docs/财务系统使用文档/财务设置/电子合同设置)。

摘要：先启用合同并维护商家信息和印章，再创建含客户与服务信息的模板；商品关联模板后用于后续签订。

注意：这是本地模板设置说明，不是腾讯电子签接口、法律有效性或第三方签署完成的证明；未复制模板和变量语法。

### 7．常见问题

官方地址：[常见问题](https://docs.idcsmart.com/docs/财务系统使用文档/财务设置/常见问题)。

摘要：提供充值条件设置和账单起始编号两个下级说明入口。

注意：页面导语称账号编号，但实际下级页面解释的是账单编号，应按下级正文辨别对象。

### 8．充值设置

官方地址：[充值设置](https://docs.idcsmart.com/docs/财务系统使用文档/财务设置/常见问题/充值设置)。

摘要：页面主要以截图介绍充值设置，文字正文没有逐项解释；页面说明提及充值开关、金额范围、最高余额及已激活订单条件。

注意：字段线索来自官方页面说明和账单系统汇总页，截图未完成视觉核实；不据此冻结字段默认值、校验边界或客户资格。

### 9．帐单起始ID设置

官方地址：[帐单起始ID设置](https://docs.idcsmart.com/docs/财务系统使用文档/财务设置/常见问题/帐单起始ID设置)。

摘要：通过开关和起始值调整后续账单的编号起点，正文配有配置与显示位置截图。

注意：页面没有完整解释已有编号冲突、并发分配和是否重用等约束，不能据此改变本项目编号规则。

## 账单系统

### 10．账单系统

官方地址：[账单系统](https://docs.idcsmart.com/docs/财务系统使用文档/账单系统)。

摘要：汇总账单、流水、充值、退款、发票和货币管理；说明充值金额限制及可选降级退余额，退款部分仍是未完善说明。

注意：该页既是目录又有较长汇总正文；充值、退款等标题不等于存在独立子页，旧官网链接另列于下文。

### 11．账单逻辑

官方地址：[账单逻辑](https://docs.idcsmart.com/docs/财务系统使用文档/账单系统/账单逻辑)。

摘要：客户详情内可新建未付账单，组合筛选时间、付款方式、状态和金额；列表有分页与每页数量，可批量合并、取消、复制、删除或标记付款。

注意：“发票清单”小节实际描述账单列表，不应与税务发票混用。直接标记付款和永久删除不是本项目授权的财务操作方式。

### 12．账单

官方地址：[账单](https://docs.idcsmart.com/docs/财务系统使用文档/账单系统/账单)。

摘要：账单详情包含摘要、项目和付款流水，说明余额付款、移回余额及特定退款入口；可追加费用项目，另介绍通过替换文件调整标识图片。

注意：页面区分余额与未结清金额；退款入口限制不是本项目退款能力边界。替换服务器图片的步骤仅作资料，未执行。

### 13．交易流水

官方地址：[交易流水](https://docs.idcsmart.com/docs/财务系统使用文档/账单系统/交易流水)。

摘要：查看收入、支出与汇总，可筛选流水类型并人工添加关联客户的收支记录；预付款转入余额有账单关联、支出和手续费限制。

注意：文中人工新增流水的方式不能替代本项目带来源、证据、权限和复核的受控账务操作。

## 与本项目已确认规则的差异

以下比较依据[用户偏好与产品体验规则](../.agents/rules/user-preferences.md)，不修改业务规范或生产逻辑。

| 官方旧系统说明 | 本项目已确认边界 |
| --- | --- |
| 货币页不支持多币种并行，账单汇总页进一步限定人民币 | 支持多币种，由商家逐币种定价，不通过汇率自动补价 |
| 账单可直接标记付款、删除，后台可手工添加流水 | 使用权威结清与受控人工收款、调账；不提供直接改账单状态或删除流水入口 |
| 已付金额可从账单移回余额，特定付款入口才可退款 | 默认原路退款；不能原路退时取得客户同意，组合付款按统一安全流程处理 |
| 可配置产品降级退回余额 | 降级不退当前周期费用，下次续费生效；不能继承旧开关 |
| 发票说明以纸质寄送和附加费用为中心，审核通过即寄出 | 使用电子发票拥有方与供应商权威状态；附属能力价格已含税，不能再次叠加税额 |
| 本地印章及模板设置即可构成该页面的合同流程 | 本项目采用腾讯电子签、版本化模板与签署证据；腾讯及诺诺外部联调仍暂停 |

优惠持续适用规则、充值资格、编号起点等未形成一一对应的确认，不标成确定冲突，也不从旧文档直接补成本项目需求。官方总览与子页存在货币能力和术语差异，使用前须明确文档所指版本。
