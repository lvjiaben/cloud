# 后台怎么用

日常处理业务用侧栏；账号、规则和连接设置统一到“系统设置 → 系统配置”。先配置，再上架商品；客户购买后，在订单财务查看付款，在服务器或服务页面查看开通结果。

| 入口 | 谁主要使用 | 用来做什么 |
| --- | --- | --- |
| 运营数据 | 商家、负责人 | 看收入、销量、待处理事项，点击查看明细 |
| 客户业务 | 客服、销售 | 管客户、协助下单、代理价格与佣金、开放接口 |
| 商品与定价 | 商品运营 | 分类、商品配置、售价和上架 |
| 内容管理 | 内容运营 | 发布公告、文章、帮助和下载内容 |
| 服务器与资源 | 运维 | 管服务器、续费，处理供应商任务与异常 |
| 订单与财务 | 财务、客服 | 看订单、收款、账单、退款和对账 |
| 工单客服 | 客服、主管 | 领取工单、回复客户、请求协助和关闭工单 |
| 通知与营销 | 运营 | 看发送结果、处理失败通知和营销活动 |
| 合规与治理 | 审核人员 | 审核企业资料，处理合同、发票和资料删除 |
| 权限管理 | 管理员 | 设置员工、部门、角色和可操作范围 |
| 系统设置 | 管理员 | 配置账号与业务规则，安装或管理插件 |

## 常用操作

- 管理员先安装插件、配置业务账号，再给员工分配权限。
- 商品运营配置商品和价格并上架；客户注册、认证后购买。
- 财务核对付款；系统按商品规则开通服务，运维处理异常。
- 客服通过工单处理售后；通知、合同和发票由各自功能接着办理。
- 工单与内容：先搜索，必要时打开“更多筛选”；“重置”清空条件。
- 财务：先看账单、流水和退款；提醒、备注、导出在“更多工具”中。
- 供应商运维：先看概况，再按需要查看连接状态、操作记录或资源更新。
- 支付对账：按页签看渠道健康、日对账批次和差异；点击某批次的“差异明细”直接查看对应记录。
- 系统配置：选分类后点击“进入配置”，在当前页抽屉里办理，关闭后回到原列表。
- 通知：渠道设置发送账号，模板设置消息内容，发送记录查看结果；三者职责不同。
- 商品：导入只是草稿，核对配置和价格后再上架。

## 同系统连接器检查失败怎么办

在“系统配置”的供应商配置页面，点击右上角“同系统连接器安全检查”，在抽屉里操作。先检查是否还有未完成的订单、服务或任务；这些业务没有处理完，就不能停用连接器。

如果提示检查失败，连接器仍已启用且没有待升级版本，可点击“重新确认连接器授权”，阅读提示并确认，再检查一次。这个操作重新执行已有启用与授权流程，可能刷新当前同版本构建；不会自动恢复已经停止的新业务，也不会替你停用连接器。需要查询插件、启用插件及业务影响检查三个权限。

系统重启或其他连接器启停后，可能需要再次确认授权。这里的检查结果只是当前情况，实际停用时系统还会重新检查；有未处理业务仍会拒绝停用。待升级、未启用或状态不正常时，先到插件管理处理，不强行恢复。

## 插件与费用

魔方云和`SSL`证书由各自插件提供，安装启用后才有对应入口。支付方式同样按已安装的支付插件提供。没有配置真实账号或完成验证的服务，页面会说明当前不可用，不显示虚假的成功状态。

简化界面不会取消员工权限、付款、客户归属或重要操作确认。免费次数与费用按已保存的业务规则执行；换`IP`金额仍按对应币种的最小单位填写，如人民币的“分”。
