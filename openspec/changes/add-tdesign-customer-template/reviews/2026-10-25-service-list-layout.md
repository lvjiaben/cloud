# 已购列表空间与空分类反馈审查

本次使用`lina-feedback`的`openspec-existing`路径修正已购页面实现缺口，按`lina-review`检查本次范围。根因是资源插件固定520px表格高度、使用后台默认搜索排版且保留冗余工具栏，模板只按已有权益决定是否挂载页面，导致空物理机分类没有表格。用户明确要求空分类也保留搜索与表头；因此增加显式菜单展示插件配置，不按名称或图标猜测服务器类型。

## 范围和实现

审查范围包含资源客户页面／CSS／双语资源、模板容器高度和版本、菜单展示插件的服务／API／控制器／编辑器／双语文案、155迁移及官方生成的四个DAO／DO／Entity文件、受影响测试和本次文档、偏好、规范及任务。未纳入其他工作区改动；复用当前任务已读的领域规则、插件本地入口、`lina-e2e`及`lina-review`要求。

资源列表去掉可见标题和刷新动作，使用同一Vben表单的紧凑搜索行，保持可访问名称、查询与重置。读取期间禁用搜索输入及按钮并防止重复提交。模板按容器顶部与窗口剩余高度提供页面空间，资源表格随窗口变化调整；Vben继续负责表头、行滚动、准确总数和完整分页。

目录的`pagePluginIds`最多16个、保持顺序、拒绝重复，仅用于产品菜单；不传保留，空数组清除。配置是既有菜单的可替换关联，不是新独立业务模块，无独立软删除生命周期；自然复合主键覆盖租户／目录查询。保存沿用菜单授权、乐观版本、行锁、事务和审计，审计失败回滚；不修改商品归属、付款、权益或任何服务权限。读取按目录键集合装配，配置插件与真实已支付权益插件合并，零条内容块不改变真实总数，没有逐行插件验证或N+1。

155 SQL为独立幂等DDL，无Seed／Mock、自增ID写入或覆盖旧迭代。官方`linactl dao`在隔离目录定向生成新表的四个文件，再迁回插件，没有手写生成模型。API仅增加现有方法的可选字段和投影，既有控制器签名及公开方法不变；英文文档源与中文翻译同步。资源插件启用双语，新增占位和空态均有对应资源；模板仍是单语言插件。
