## ADDED Requirements

### Requirement: 官网选择必须依赖已安装启用的插件
系统 MUST 只展示已安装且启用的官网 provider，保存时重新确认生命周期状态。

#### Scenario: 未安装或停用官网
- **WHEN** provider 未安装或已停用
- **THEN** 不能选择保存该官网，公共 API 不返回该模板配置

### Requirement: 插件可用状态与官网展示选择必须分开
系统 MUST 允许多个官网插件安装并保持可用，官网配置只保存一个对外展示的模板；切换官网不要求停用或卸载旧插件。

#### Scenario: 保存切换官网
- **WHEN** 两个官网插件均已安装可用，管理员选择另一官网并保存
- **THEN** 仅新官网对外展示，旧插件仍可用，公共资料和各模板已保存配置保留；切回旧官网并保存后恢复其内容

#### Scenario: 选择尚未保存或保存失败
- **WHEN** 管理员选择另一官网但尚未保存，或保存请求失败
- **THEN** 当前已生效官网继续展示，页面保留输入供重试；只有保存成功后更新使用中标识

### Requirement: 模板独立配置和公共资料
系统 MUST 在官网配置页提供公共资料及所选模板声明的字段，保留各模板独立设置。

#### Scenario: 切换模板
- **WHEN** 在简洁官网与文字官网之间切换并保存
- **THEN** 首页采用对应布局，文字官网不显示首页图片，两个模板的独立字段互不覆盖

### Requirement: 系统配置中心移除官网设置
系统 MUST 将官网公共资料和模板配置集中在系统设置的官网配置入口。

#### Scenario: 查看系统配置
- **WHEN** 用户打开系统配置中心
- **THEN** 页面不再包含官网品牌设置入口和内容

### Requirement: 官网导航由当前模板页面生成可维护的头尾树
系统 MUST 在官网配置页提供头部、底部导航的新增、编辑、删除和排序。目标只能选择当前安装启用模板声明的公开页面、用户中心登录注册入口或合法外链；每处最多一百项、最多三级，保存时拒绝伪造页面、循环、缺失父级和危险链接。公开官网 MUST 消费同一份已保存导航，模板切换后不输出新模板不可用的旧页面。

#### Scenario: 保存和展示导航
- **WHEN** 管理员保存头部页面、子级登录注册链接和底部外链
- **THEN** 刷新后台后数据保留，官网展示相同顺序与层级，会员链接指向配置的用户中心，外链使用安全的新窗口属性

#### Scenario: 拒绝不合法导航
- **WHEN** 保存未声明页面、循环父级或非HTTP外链
- **THEN** 返回可操作的校验错误，原有生效配置不被覆盖

### Requirement: 官网插件可交付独立框架的公开应用
系统 MUST 支持官网插件通过正式公开资源声明交付HTML入口、脚本和样式，不限定前端框架；入口URL依据宿主冻结的插件标识和发布版本产生。官网网关只能加载当前选中且可用模板的正式公开资源，支持单页应用深链和多页HTML，不能使用任意远端入口、私有文件或嵌入框架。公共资料、模板独立设置和导航保持统一接口。

#### Scenario: 安装独立模板并切换
- **WHEN** 管理员通过正式插件上传、安装和启用流程安装原生HTML模板，并在官网配置保存选择
- **THEN** 官网根路径和单页应用深链展示该模板，资源正常加载；切回内置模板后恢复内置布局和其配置

#### Scenario: 非法入口被拒绝
- **WHEN** 模板声明绝对地址、路径逃逸、编码逃逸或非HTML入口
- **THEN** 声明校验失败，不能成为可选模板

### Requirement: 官网配置页直接提供真实开发说明
系统 MUST 在官网配置页提供开发文档入口，说明清单、公共与独立配置、公开页面和导航接口、正式构建上传安装启停升级流程及当前运行边界；没有可用模板时说明安装启用步骤并提供插件管理入口。

#### Scenario: 开发者读取接口
- **WHEN** 点击开发文档
- **THEN** 不离开当前页面即可读取当前源码维护的接口和交付流程，不展示不存在的能力

### Requirement: 官网源码和打包必须能脱离私有仓库
每个官网模板 MUST 自带应用源码、依赖锁、构建配置、静态资源、动态Guest和打包工具；复制到仓库外后可独立安装依赖、构建并产出正式WASM，不得引用仓库私有源码或返回仓库执行构建。完整默认与文字官网 MUST 保留商品配置、内容、多语言和SEO实现；SSR部署产物由独立Node进程运行，单WASM静态部署不宣称具备SSR。

#### Scenario: 仓库外构建与正式运行
- **WHEN** 将模板源码复制到仓库外干净目录并安装公开依赖
- **THEN** 独立构建生成正式WASM与SSR产物；正式上传升级后可选择并访问真实业务页面

### Requirement: 导航分组不需要跳转目标且页面清单必须真实
导航 MUST 支持只展开子菜单的分组，分组不接受页面或URL目标；原页面链接和外链语义保持不变。分组在桌面、移动端和键盘操作时展开子项且不跳转。空分组可保存但不在官网输出无用入口。页面候选 MUST 展示业务名称和实际路径；插件构建时核对每个声明页面的实际路由实现或HTML输出，禁止发布不存在的页面。

#### Scenario: 分组保存及展开
- **WHEN** 保存无目标的父分组及其页面子项后刷新
- **THEN** 分组保留，点击或键盘触发只展开；点击子项进入对应实际页面

#### Scenario: 静态多页和伪造页面
- **WHEN** HTML模板声明products.html页面或声明缺少实现的页面
- **THEN** 前者作为实际页面展示并可访问，后者构建失败，后台不展示未发布候选
