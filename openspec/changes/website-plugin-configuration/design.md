# 设计

idc-portal 拥有 website-template v1 扩展点。模板声明 singleton 字段和已支持 renderer，宿主负责安装、依赖和 provider 生命周期；官网业务通过公开 BusinessExtensionRegistrar 获取安装启用状态及原子准入。初始提供简洁官网和文字官网，两者可同时安装并保持插件可用状态，独立配置且实际首页布局不同。插件启用只是使模板成为可选项；官网配置中的`selectedPlugin`是唯一展示选择，保存成功后原子替换，不触发插件停用或卸载。

官网配置 GET/PUT /admin/site/configuration 使用现有品牌管理权限。公共资料包括网站名称、标题、公司名称、电话、邮箱、Logo 和简介。配置按模板独立保存，切换不会覆盖其他模板。公共 API 每次读取安装状态与存储，不缓存；停用或卸载的模板不返回公开内容。

存储沿用 portal 的 LINA_SITE_STORAGE 文件根，原子替换。多实例部署必须挂载同一共享存储；当前无跨实例写锁，官网配置单管理实例写入。这一限制应在交付文档明确，不能宣称多实例并发写支持。

DI：portal 启动期创建唯一 siteconfiguration 服务，显式传入同一 registrar 的 BusinessExtensions，并注入 admin/public 控制器。插件定义字段不含凭据与可执行脚本。图片地址限制本地绝对路径或 HTTP(S)，独立导航只接受安全站内路径。

i18n：portal 已启用双语，菜单/配置错误/接口说明分别维护。模板中文单语言清单含双语字段标签，不申请租户及宿主能力。

数据权限边界：官网是`platform_only`安装实例级公开资源，不属于某个客户、部门或租户。管理读取和保存均由宿主统一校验`idc:admin:portal:brand`权限；候选仅来自公开注册器的已安装启用证据，不读取客户或员工记录。匿名接口只投影已选模板的公共资料，不输出其他模板设置、内部标识或密钥。没有行级客户数据需要过滤，不能以此放开其他插件的数据权限。

生命周期：官网 owner 注册公开 BusinessImpactHandler。模板只提供只读描述和展示配置，不持有销售商品版本、服务、任务或历史动作，因此无事务阻塞；停用不删除配置，公共读取继续以权威 provider 状态决定可见性。
