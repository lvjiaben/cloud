# 商品配置慢响应验收

## 根因与修复

`UX18`针对真实商品抽屉无法加载、产品配置校验失败及数量价格长期呈现骨架的问题。本地只读计时证明，陕西商品详情约`0.426s`、成本`0.007s`，但已存配置读取约`11.103s`，价格候选读取约`11.148s`，均超过共享请求客户端默认的十秒上限。证据为`temp/20261021/091600-editor-read-timing.log`及本轮只读候选请求结果。

仅在`idc-core/frontend/pages/catalog-client.ts`为配置读取、价格候选、配置校验和配置保存设置三十秒有界等待。其他请求保留默认。没有修改宿主请求客户端、关闭超时、增加写入重试或改变金额、版本和权限契约。原有只读临时服务失败的一次重试规则不变，超时不触发自动写入重放。

## 验证与本地部署

- `092400-slow-read-reproduction-e2e.log`在旧构建复现：十一秒配置响应导致整个商品抽屉失败，正常字段不能出现。
- `093600-slow-catalog-e2e.log`的`TC065h/i`两项通过：十一秒配置及候选项能完整回填，十一秒校验和十一秒保存仍使用原版本，只提交一次，最终规格为用户填写的值。测试写入全部由浏览器拦截，不修改真实商品。
- 补齐慢读取用例的独立校验响应并让截图显示价格表单后，`094700-slow-catalog-clean-e2e.log`单独通过`TC065h`，不是依赖其他用例的结果。
- `094300-slow-catalog-regression-e2e.log`八项通过，覆盖原数量价格、失败恢复、已确认保存后的刷新、停用价格、英文窄屏、权限和迟到配置校验。
- `095100-catalog-final-tests-types.log`测试类型检查通过；`093800-catalog-client-types.log`以真实宿主适配器类型定向检查本次客户端文件通过。临时配置最初缺少继承的类型库与虚拟模块声明，已补齐绝对路径及原有声明后重新通过，没有把配置失败写为源码检查通过。
- `092800-slow-catalog-production-types.log`后台类型检查和`092800-slow-catalog-admin-build.log`正式构建通过，资产为`092800-slow-catalog-admin-public`。已合并到本地后台运行目录，入口最后替换并保留旧哈希资源。只更新后台资产，后端保持已启用的`idc-core v0.1.153`。
- `Chrome`只读重新打开真实陕西商品，基本资料、原上游默认参数、数量价格表单均可加载；未保存任何真实字段或修改价格、范围。

关键截图已视审：`temp/20261020/200245-slow-product-and-price-candidates-loaded.png`显示慢读取后的价格、币种和可保存表单；`200108-slow-product-validation-and-save-completed.png`显示规格`3`与保存成功提示。后者同时保留客户选项因配置版本改变而需要重新核对的提示，没有自动覆盖其他表单输入。

## 任务级审查

按`lina-review`检查本次客户端、`TC065h/i`、插件本地页面对象及记录，未发现阻塞问题。触发`E2E`质量审查，断言证明字段完整回填、写入版本和次数、原值及保存结果，截图覆盖加载完成与提交成功。复用八项相关异常、权限及英文回归。本次没有新增运行期依赖、数据库、缓存、公开接口字段或翻译键，无新增`i18n`影响，宿主文件保持无改动。

这次修复消除正常慢响应被十秒上限截断的问题，不将真实供应商错误伪装为成功；后续继续优化本地资料的首屏等待，避免上游读取影响基本资料编辑。
