# 用户中心服务分类反馈验收

## 根因与范围

服务分类页复用了完整会员导航，系统页面、外部链接和插件页面都被渲染成服务筛选按钮；后端正确拒绝非产品菜单读取服务，因此出现无法使用的分类入口。新客户模板的动态产品路由也没有先按导航类型区分，混合菜单会影响分类页码。

沿用本变更的会员导航规范及偏好主题`73-customer-product-directory.md`，只修正实现。商品归属、导航配置、订单、服务、金额和权限保持原业务含义；未替客户或管理员确认、重新开通或退款。

## 实施

- 客户目录查询增加可选`navigationType`类型筛选；不传仍读取全部启用导航。类型条件在数据库计数与分页之前统一应用，服务数量仍由当前可信客户身份限制，单次查询集合装配，不逐项查询。
- 服务分类页及动态产品路由显式查询产品类型；侧栏继续查询完整导航，保留系统、外链和插件目标。路由页码按产品目录排序计算，第`101`项可以正确进入第二页并在刷新后恢复。
- 已购服务表格在窄屏让完整分页条换行，避免页码与翻页按钮被裁切；表格继续使用原有有界高度、内部横向滚动及准确总数。
- 相关测试截图助手按源码位置定位项目`temp/`，不依赖调用目录；本轮旧助手已生成的五张目录截图移回项目内，并验证三个助手均解析为项目目录。

按`lina-review`限定`UX5`的请求、目录读取及契约、控制器映射、客户模板目录客户端、路由、服务分类页面和测试。复用已读的接口、数据权限、后端、前端、插件、测试和多语言规则，不审查无关历史工作区。

目录服务继续由`backend/plugin.go`启动期使用共享数据库、可信客户访问解析和业务审计构造；没有新增运行时服务图。类型筛选只缩小读取集合，不接收调用者指定客户编号，不改变访问权限。原全部导航接口默认行为及非产品服务入口保护保留。没有新增迁移、缓存或按行增长的数据库／上游调用。

触发`E2E`质量审查：有效断言覆盖请求类型、非产品按钮排除、侧栏保留、服务内容与地址同步、第`101`项准确页码、刷新、失败保留、重试、英文真实文案、窄屏和完整分页。人工异常与服务器入口回归继续证明付款及服务管理语义未变化。已视审产品分类、第二页及最终英文窄屏截图，未见原始翻译键、元素重叠或分页裁切。

未发现阻塞问题。所有供应商、支付和财务写入均未由本任务触发；已购服务中的存量待开通状态没有被伪造为开通成功。
