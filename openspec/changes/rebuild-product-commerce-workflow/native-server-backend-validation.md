# 原生服务器管理后端验证

## 范围与状态

本记录覆盖`idc-resource`原生管理后端、相关公开资源端口及`idc-zjmfcloud`客户可见运行事实投影。前端由用户中心对话负责，核心商业与退款互斥由核心拥有方对话负责。未修改宿主，未对真实上游执行写操作，未单独重启共享服务。

当前后端已实现本地事实、十八种免费管理动作的通用编排（各连接器仍按真实能力开放）、普通管理日志分页、显式一次秘密输出、收费报价及结账适配、商业任务绑定、快照和备份删除回执、换`IP`持久占用。变配动态表单、目标报价与商业入口投影已接入；快照和备份创建后的权威对象编号、前后端真实联合验收仍未完成；商业操作记录与真实对象账期读取已接入，主任务保持未勾选。

## 实现核对

- 原生任务以真实权益、公开服务器编号及资源绑定定位，不借用旧服务编号。参数、确认、秘密绑定、审计及入队在同一权益事务中提交。
- 普通管理的`nativeWriteClaim`和核心`QueuedWriteAccess`持久互斥同事务提交，上游只读观察与写调用均在事务外。已存在执行占位的拒绝进入未知结果，不能成为“请求未发出”的退款依据。
- 回执调度每次读取核心最多十六个待核对任务，资源通过一次集合查询加载真实结果；无记录、不匹配身份或非终态不猜测失败。未知继续占用，已知终态才报告解除。
- 所有原生路径编号显式读取路由参数；`GoFrame`正文合并不能覆盖网址里的服务器、操作及输出目标。
- 恢复快照与备份核对明确可用对象、已关机状态、公开服务器编号及商业使用资格。删除在成功回执后才停止续费，付款关闭等待不回滚已有关闭请求。
- 商业重复结账优先读取既有购买，不再次访问供应商或消费确认；缺少确认或金额变化会回滚新订单和库存占用。
- 报价、购买及流量套餐金额通过十进制字符串返回；真实`HTTP`覆盖超过`2^53`与`int64`最大值，不经过浏览器浮点数。
- 已验证非受理的重试由真实任务转换事务记录`nonAcceptanceAttempt`，新租约只能推进已被该证明覆盖的执行占位；无证据的重试仍拒绝。真实`PostgreSQL`回归先复现旧实现停滞，再验证修复通过。
- 已启用插件的接口源文案保持英文，中文文档翻译覆盖当前接口元数据并有源摘要回归测试。此次没有新增长期开发工具；临时验证文件位于`temp/20261023`。

- 动态表单共享二点五秒总读取预算，阻塞候选会返回可重试提示；仅使用商品编译器的公开字段与类型值，最多一百个字段、十六KiB；读取冻结值与空编辑区分，目标报价不进入购物车。商业能力另列`commercialCapabilities`，`canQuote`只说明资源前提，不替代商家价格和库存校验。
- 未知换IP请求不再根据相同IP数量误报成功。数据库回归验证未知状态、原租约和互斥保留，且不写入虚假成功证据；正常任务终态仍须经过核心的新鲜地址集合变化验证。

- 已确认旧魔方`PUT /clouds/:id/ip`只表达数量调整，撤回错误的换址能力。集中撤回规则只针对`idc-zjmfcloud + server.ip.change`，覆盖旧能力快照展示、报价验证、新任务及排队准入；供应商执行入口也在登录之前拒绝，其他连接器不受影响。历史未知任务与证据保留。

- 商业记录与对象账期读取使用资源保留归属及核心独立校验，不要求新鲜供应商状态或父服务可操作；渠道禁用、父服务不可操作时仍可读取。真实账期、冻结待付账单总额和未完成时间保持空值，金额保持字符串。

- 魔方快照与备份就绪状态未经权威矩阵确认，源目录及旧缓存投影为`unknown`，恢复动作撤回且源/动态执行在认证前拒绝。删除只依赖新鲜唯一归属及类型，仍保留确认、互斥和实际终态回执。其他连接器有真实就绪依据的恢复不受影响。
- 动态实例详情出站请求独立申请已验证的主机名、系统、登录用户、规格和启动顺序字段，其他候选接口不扩大白名单；受控宿主先按请求字段过滤响应，再进入实际WASM。

## 运行与交付限制

版本冻结为`idc-resource v0.1.71`，最低依赖`idc-core v0.1.164`；`idc-zjmfcloud v0.3.16`需与候选后端一起安装。资源迁移`041`此前仅在隔离环境验证；共享环境必须通过统一插件升级执行迁移，不能只替换二进制或手工改共享数据库。
