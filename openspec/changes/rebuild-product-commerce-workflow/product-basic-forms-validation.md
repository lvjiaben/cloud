# 商品基本资料直接表单验收

`UX12`归入现有商品经营流程变更。实际商品抽屉只能只读查看销售分类，库存仍需另开弹窗，未完成用户要求的`Tab`加直接表单。现已在基本资料增加分类选择，库存改为同页表单；五个原页签、原售价、配置、合同与开通能力保留。

分类沿用商品修改权限及商品版本围栏，复用拥有方的有效分类行锁。分类、销售资料、会员导航的可选变更与审计同事务提交；不传分类保持原归属，空值、错误格式、停用、删除、其他租户及不存在的目标被拒绝。没有修改历史成交、商品地址、价格、配置或服务归属规则。分类和会员导航仍是独立字段。

候选仅在有对应读取权限时获取，最大五百项分类一次读取，无按行请求。候选失败会保留当前归属并禁用相应选择，保存其他资料时省略该归属字段；没有权限仍可维护获授权的其他资料。分类可用父级名称区分同名子类。

库存使用原接口、权限及立即应用事务。页签切换和失败保留未提交输入，等价内部工作副本更新只推进写入锚点；库存事实不同则保留输入、阻止覆盖并提供重新读取。库存限制关闭与数量为零的含义保留。超出浏览器安全整数范围的已有库存不能在该表单保存，避免数字舍入导致误写，没有缩小后端整数契约。
