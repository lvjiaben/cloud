# 数量与阶梯价格直接表单验收

`UX16`补齐产品配置页仍依赖多层弹窗维护数量费用的问题。在原固定规格价格表旁直接提供“数量与阶梯价格”，按收费项、币种、周期回填已有金额和全部区间。两种计价方式及价格系数工具保留；旧弹窗复用同一表单，不另建收费算法或写入接口。

保存沿用已有维度和价格方案。价格停用状态不会因编辑金额而改变，新价格必须明确填写金额，免费须填`0`。关闭一次性费用区域只折叠字段，不清除费用；一次性购买不显示续费输入。双击、失败重试、切换页签、外部修改及已确认保存后的读取失败均有明确处理，读取失败只重读，不重复提交已确认的费用。
