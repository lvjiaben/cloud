# 商品直接表单与列表反馈验收

## 问题与实施范围

旧自动开通页签需要先选择插件、弹窗关联接口，再独立保存交付方式；两个提交无法共同回滚。商品列表只显示币种及计费规则数量，并重复提供分类、销售状态筛选，无法直接辨认基础售价。

本轮沿用现有变更，先合并自动开通表单与事务，再继续处理产品参数、客户选项及计费表单。第三方界面仅只读；未代替管理员确认订单、创建服务器或退款，也未修改真实商品金额、规格和销售开关。

## 已启用的第一轮

核心插件`v0.1.138`：

- 同一页签直接选择已有接口与开通方式，一次事务保存；可按名称搜索并准确分页，包括资源拥有方的本地接口投影，保留实际绑定准入及字段权限。
- 不选择接口不能提交自动开通；停用接口不能新选，原有绑定按真实状态显示；失败保留输入，页签切换不丢失，搜索翻页保留已选标签。输入框按`Esc`只关闭选项，不关闭商品抽屉。
- 列表通过有界页内集合投影显示明确币种、基础购买价格、周期和一次性费用，排除配置附加价、续费专用价、非本次数量区间、非有效价格及其他租户；显式零价和未定价分别展示。查询为同一只读一致性事务内计数加分页投影，不新增逐行详情或上游查询。
- 分类由左树筛选，销售状态由快捷筛选维护，保留服务端准确总数、数字分页及复制、上下架操作，删除重复的筛选和版本来源展示。
