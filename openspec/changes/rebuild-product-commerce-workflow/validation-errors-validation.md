# 商品校验错误与入场等待验证

## 范围与实际行为

本阶段只调整`idc-core`商品执行适配器、纯配置校验及错误翻译，资源适配器复用同一公开的无状态`provideradmissioncap`。不修改宿主，不新增表、缓存、权限、运行期依赖或自动重发策略。既有`idc-resource`对核心插件的源码依赖保持不变，共享辅助方法不注册服务或创建独立实例。

只有类型化的`PLUGIN_LIFECYCLE_ALREADY_RUNNING`且业务回调未进入时才沿用四十次、一百二十五毫秒的等待；已进入回调、普通文本、未知失败及取消不重试。带不透明运行时上下文的直接接口调用仍只执行一次。纯校验临时上下文继续没有凭据、接口身份或外发权限，离开调用后撤销。

纯校验上下文准备失败、调用失败、无结果、协议不符、超限、无效正文及缺失布尔结果均对应稳定的业务错误与固定原因；错误和日志不包含任意插件正文或底层错误。明确配置拒绝与供应商能力未确认仍保留原含义。页面保留输入并允许管理员手工重试。

此前分段计价用例首次上架曾出现通用不可用，后续同商品重试成功；没有足够证据确定该次具体根因，本阶段不将其追认为已复现的宿主锁忙。
