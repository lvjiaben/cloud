# 商品本地资料先显示验收

## 结果及范围

`UX19`至`UX21`在商品抽屉内完成。本地详情返回即可填写基本资料、选择自动开通及维护商品级售价，上游候选和成本继续独立加载。失败后可单独重试，保留已填资料；未取得成本前显示真实加载或失败状态，不伪装为空成本，不允许新增成本。

配置及成本仍以该次本地详情的商品版本为锚点，成功保存后的完整刷新继续原子装配详情、价格和配置。请求序号拒绝旧请求覆盖，新商品及当前请求不会被迟到响应改写。没有增加后台调用数量、上游写入或新的缓存；初次三项读取保持原有数量，失败依赖的单独重试无需重新读取本地商品。

英文窄屏还复现了主页签被导航位移裁切的问题。仅在小于六百像素的商品抽屉内换行排列五个主要页签，保留当前选中状态，避免切回基本资料时找不到入口。配置内的价格页签和其他页面不受此选择器影响。

## 生产类型检查

原后台应用类型检查未覆盖插件目录中的商品组件。本轮新增插件内`tsconfig.catalog.json`及`pnpm -C apps/lina-plugins/idc-core/frontend run typecheck:catalog`，使用实际宿主适配器与组件声明检查商品编辑依赖闭包，所有路径均相对仓库，不引入声明替身或修改宿主。独立运行时原有构建和类型检查命令保持不变；中英文插件说明均已补充开发检查入口。

真实类型检查发现并修正：价格创建及更新类型漏写后端已经支持的停用状态；履约策略类型从未导出该类型的客户端导入；新周期表单缺少上下文类型；币种选择事件类型过窄。币种事件现在仅对字符串推进原逻辑，合法币种、价格精度、启停和保存契约不变，同时移除当前商品编辑文件的未使用导入。
