# 配置编辑与价格系数反馈验收

## 范围与根因

本轮沿用`rebuild-product-commerce-workflow`，对应`CONFIG1`至`CONFIG4`。此前仅增加四种展示控件，没有补全本地字段、分组、子项名称和价格表。本轮通过用户已打开的参考页及所提供源码核对能力，仅作只读观察，没有点击、修改或重载第三方页面，也未搬用其代码。

实际保存冲突为旧内存范围`1024—1024 GiB`与新下拉子项`2`同时提交。另有动态表单初始化过滤未注册字段，以及保存后异步刷新尚未完成就重新打开旧配置的问题。真实回归还发现已保存配置的读取及本地展示保存被实时上游候选查询阻断，已将失败候选明确作为空列表显示，并仅在接口、修订与默认值均未变时复用已验证商家事实；实际上游参数变更继续实时校验。价格系数曾因构建工具把大整数幂运算转换为`Math.pow`而失败，已改成构造十进制字符串倍率，保留精确整数计算。

## 实现

- 可选数值下拉、单选的范围由子项形成，重复、越界、步长与计价方式不匹配在提交前说明；核心字段保留，核心数值范围保持接口声明。
- 本地字段支持单行、多行、整数、小数、开关、单选、多选、日期、日期时间、树和地区层级；维护分组、双语名称、说明、单位、排序及高级展示。整数子项可独立命名。
- 本地定义随配置契约保存、读取、复制与冻结，使用同一校验和定价体系；本地字段不能声明动态方法、秘密或文件能力，履约时移除本地字段。
- 数量单价、整档与独立规格价格明确分开。原方案保留以便切回，当前报价只采用当前方式，不能重复收取或把固定规格价再次乘数量。
- 固定规格价格表集中维护币种、周期、新购、初装与续费，支持修改、删除；最多256行在一次请求内原子保存，权限、草稿、旧价格行与审计均验证，集合读取和批量写入，无逐行请求。
- 自动计算为本次编辑的可选工具，默认关闭；商家输入基数、每行系数，预览、填入后再保存。按币种最小单位四舍五入，安装与续费独立，不自动修改已有价格或发布商品。
- 配置保存直接回填提交结果；价格表每次打开独立读取最新目录数据，保存后刷新不依赖自动化配置或成本读取；已确认提交但刷新失败时明确已保存并关闭，避免重复提交。网络未知结果保留输入并提示核对。

## 权限、依赖与数据边界

新增价格批量接口同时经过既有价格权限和配置拥有方授权；只处理可见的同一商品草稿。沿用共享商家目录的全局范围与`tenant_id=0`，不扩大客户数据权限。控制器复用启动期已绑定的目录及自动化实例，自动化服务通过构造参数接收打包的双语开关标签，不新建运行期服务图或缓存。

本轮不修改宿主，不提交、推送或归档。未替用户调整实际商品规格、价格、发布状态或账单。真实接口验证只操作唯一前缀、未发布、零库存测试副本；清理限本地数据库及该副本，审计保留测试事实。原商品、各版本、配置和价格在测试前后进行指纹核对。
