# 实现设计

## Context

根因见`proposal.md`。协助报价已有配置快照与正常交易接缝；代理存在计算器但没有正式报价接入；渠道先结账后扣款形成事务缺口。用户严格禁止修改宿主。

## Goals / Non-Goals

在业务插件内完成真实管理、价格与交易闭环；不以自动批准保留旧审批，不直接读写其他插件私表，不修改宿主或虚构未验证的第三方兼容能力。

## Decisions

- 协助创建在核心交易事务内完成配置校验、报价和结账，历史申请证据只读；保留已有精确创建权限键以避免角色授权静默丢失，移除审批路由和按钮。
- 代理规则由核心持久化并接入正式报价路径，网页与渠道共享；报价和订单冻结规则证据，避免另建渠道价格表造成漂移。
- 等级总收费百分比使用独立追加版本表和价格管理接口，避免资格管理权限修改价格或普通等级编辑清空总价。按客户定制价、商品等级价、等级总百分比、普通价依次选择；等级总百分比覆盖所有未单独设置的币种周期，包括正式续费历史周期。导出仅投影真实商品计费组合，报价保留不可变来源与摘要，清除追加撤销版本。
- 佣金使用核心实收与退款事实，幂等生成与冲回；结算仅登记线下结果，独立于客户余额。
- 渠道只拥有凭据、授权、请求证据与连接；核心公开能力负责报价、交易及余额。扣款与结账保持同一核心事务，不能用预查余额代替锁和原子性。
- 同系统采购由受管连接器消费公开协议，继续验证插件发布证据及资源保密出站边界。履约请求携带订单项已冻结的币种、收费类型、周期单位、周期数量和购买周期数，不解析翻译后的周期名称，也不从当前商品价格重建历史采购条件。
- 导入覆盖全部可销售商品，遵守既有商品规则：管理员明确导入未上架草稿，核对本地显式售价后手动发布。上游配置的初始视图和普通周期预览不能作为完整可导入价格方案；客户最终报价继续使用本地正式价格，不因接入同系统而改成同步远程询价。配置、价格及交付映射使用通用契约，不按服务器字段推断一次性交付或长期权益。
- 独立业绩保存到账时的归属快照，管理员推荐归属优先；没有佣金规则也保存付款事实。佣金消费同一归属事实，退款关联原到账快照，逐币种汇总，不用佣金冲回额替代真实退款金额。
- 新管理服务在插件启动入口显式创建，复用数据库、身份、权限及审计实例；精确装配链随实际实现记录在验收文件中。
- 新页面继承既有主题、语言与表格表单能力；中文、英文菜单及接口文档同步。列表有界分页，候选项搜索，拒绝逐行查询。
- 员工候选复用宿主公开目录的权限、启用状态、关键词、分页与总数，只对当前页最多100个用户做一次插件员工身份集合查询并标明是否可选；非员工保留可见分页位置但禁选，保存再次严格校验。公开目录没有按插件员工身份过滤的能力，因此不扫描整目录、不内存重分分页，也不读取宿主私表。
- 佣金账户按员工姓名搜索时只做一次宿主可见目录查询；匹配超过100人明确要求缩小姓名范围并拒绝结果，避免截断后遗漏账户。员工与推广客户匹配均同时约束受益人类型，避免字符串编号相同造成误匹配。
- 生命周期业务影响使用宿主可信源码拥有方注册器，核心和资源各用一次集合聚合读取自己拥有的表，返回固定类别总数和阻断数。此入口由宿主平台管理员生命周期授权调用，不能改成普通客户查询；不返回客户、订单、秘密或渠道详情。停止新业务仅围住新增，历史任务和补偿继续受排空保护，暂停商品、终态订单及已终止服务不产生新阻断。
- 宿主同步发布元数据时可能丢失业务授权。插件页面提供明确确认的现有正式启用操作，仅作用于已安装、已启用、正常且生效与发现版本一致的`idc-peer`；要求查询、启用及影响检查权限，确认后重读、执行后重读并检查原新业务状态保持。公开详情不提供工件摘要和条件更新参数，不能宣称冻结相同工件或消除并发窗口；确认内容说明可能刷新当前同版本构建。随后正式影响检查失败则清空结果。重启或其他连接器启停后可重复确认，不后台自动授权、不缓存放行结论、不修改宿主；正式停用继续由宿主权威排空门禁控制。
- 已付款门禁恢复使用现有primary后台注册，每5秒最多20个订单项。启动期显式复用财务投递的冻结配置校验器、风险/合同门禁及稳定系统原因创建正式释放拥有方，再注入单一恢复worker；worker以订单和订单项keyset游标轮转，未批准和失败均推进，下一轮到尾再从头，不更新历史快照和观察时间。进程重启游标复位，后续轮询继续推进；多实例只注册primary任务，重复执行由正式拥有方行锁和唯一意图任务收敛。

## Risks / Trade-offs

- 历史申请与渠道凭据语义变化：保留证据、禁用旧写入口，不把历史审批伪造为新流程。
- 并发余额支付与佣金事件重复：核心事务锁、唯一幂等键及隔离数据库测试覆盖失败和竞争。
- 外部同系统请求结果未知：记录证据并查询确认，不自动重复扣款或开通。
- 当前通用商品履约上下文只提供配置与业务证据，没有注册保密出站处理器；同系统连接器必须通过资源拥有方的公开受治理能力获得出站授权。普通上下文编号不能替代保密出站上下文，不得把密钥塞入商品配置或通过宿主补丁绕过。
- 宿主已有其他任务改动：以`temp/customer-business-host-baseline.json`核对本轮宿主文件集合与哈希不变。

## Migration Plan

插件增量迁移重复执行验证幂等；先安装字段和索引，再启用新入口。旧证据不删除，回退代码前必须评估新记录状态，不能回退数据库抹除交易。验证使用隔离数据，不重置开发库。
