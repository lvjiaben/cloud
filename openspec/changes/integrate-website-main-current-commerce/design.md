# 官网迁入与适配设计

## 背景

来源固定为`240aec4`的`website-main`目录。官网外三方比较共识别`50`项冲突，用户先要求逐项列出，后明确授权按官网必要性和不影响当前功能的原则由代理取舍，最终清单位于`temp/20261029/001800-官网之外逐项冲突.md`。本地未提交改动必须完整保留。

## 目标与边界

保留官网的独立页面、素材、英文适配和布局，适配本地当前业务；用户进一步明确所有页面禁止改样式，全部原HTML/CSS/图片/字体按分支原字节保留，新增控件与购物车直接复用原组件，删除外来购物车样式；不引入其他模板、模拟插件、旧运行器工作区或远端环境验收结论。不修改宿主，官网外保留当前业务；必要修复单独核对、最小引入。

## 决策

- 以当前公开契约为准，旧官网的业务适配器在插件内调整；共享接口已有等价能力时不恢复旧交接后端。
- 官网内拥有选配、购物车和订单确认，认证复用客户中心，官网原结算区域选择付款方式并使用当前账单和支付接口。已有服务器登录凭据写入和消费链路直接复用。
- 逐文件记录来源摘要，独立构建、页面自动化及真实本地请求共同验收。图片和页面许可记录保留，历史文档注明来源环境，不据此宣称本地通过。
- 当前任务的冲突决策单独跟踪；按用户最终授权处理，翻译同键本地优先、文档本地优先、官网固定`NEW`；不恢复旧功能。

## 风险与取舍

旧官网的多数页面测试基于旧接口，需要按当前用户行为补测，不能仅运行旧静态测试就判定可用。公共资料新增字段与本地命名冲突时先适配现有资料；按2026-10-29最新反馈补齐分支截图中的独立头尾Logo、版权、联系方式及许可证资料，保留原字段和其他模板配置。真实付款及第三方采购沿用现有授权边界。
