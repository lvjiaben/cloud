# 引入官网分支并适配当前业务

## 为什么

用户要求从`codex/官网交付`选择性引入官网动态插件源码。该分支基于旧业务实现，不能用整分支合并覆盖当前商品、公告和购买链路。

## 变更内容

- 只引入`website-main`独立官网插件源码、素材、许可与插件内验证资产，保留其视觉和中英文页面。
- 官网适配当前公开品牌、内容、商品配置、认证、购物车和结算契约，接入已确认的逐台服务器登录信息输入。
- 官网之外先做逐项三方差异审计；冲突文件在用户逐项确认前保留本地。无冲突的独立修复另行核对必要性，不搬入旧功能和环境产物。
- 构建独立`WASM`包，验证实际本地业务与插件安装运行。

## 能力

### 新增能力

- `website-main-template`：分支官网模板通过当前业务契约独立展示、购买及动态交付。

### 修改能力

无。已有商品收费、内容、认证及客户中心付款语义保持当前规则。

## 影响

主要源码为`apps/lina-plugins/website-main/`，记录当前变更和相关长期偏好。不修改宿主。官网外冲突文件的许可范围以用户后续逐项确认为准。
