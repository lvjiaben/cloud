# 运营数据实现设计

## Context

新口径替代旧首页分工，业务确认见偏好主题`72-customer-website-visual.md`。现有统计使用订单金额、近三十日与去年比较，不能继续作为页面数据源。

## Goals / Non-Goals

实现可核对的首页和明细，保持支付、退款、工单和服务写操作不变。

## Decisions

- 插件拥有统计和有界分页接口，共用过滤谓词；首页一次获取概览。明细每页最多一百条，数据库过滤后分页，不加载全部记录。
- 实收取账本现金借方的真实收款交易，排除余额支付、赠送、迁移和冲正；与退款净额分开。订单以`paid_at`统计，商品数量来自订单数量快照。
- 时间窗在`Go`按商家`IANA`时区生成半开区间，趋势最多三十一天；数据库集合聚合，禁止逐行查询。当前和上月不存在的同日不伪造对应。
- 总后台沿用安装实例和广域数据权限门禁，窄范围、代操作、客户身份拒绝。明细通过启动期显式注入的宿主`Authz`检查目标业务权限，不能依赖未填充的请求权限快照；全部工单明细要求查看全部工单权限，防止统计权限扩大为详情权限。
- 宿主只提供通用会话`SPI`，由同一启动期会话服务产生可嵌入查询的受治理谓词。插件以自身身份绑定映射客户，按客户去重；不读取宿主私表，不向动态插件暴露私表语句。
- 新页面独立使用原生`Vben`与`ECharts`，普通白色卡片、冷灰背景、蓝色操作色；各业务页适配统计下钻条件，复用已有详情能力。
- 不新增统计缓存。会话共享投影沿用宿主一致性语义；新增读契约、菜单和错误同步双语资源。

## Risks / Trade-offs

- 集群活跃时间投影可能有不超过一分钟的延迟，查询仍严格按有效期过滤，不能把等待清理的过期会话算在线。
- 数据会实时变化，指标及明细共享时间窗，但工单状态和在线人数允许在刷新后变化，不承诺历史状态快照。
- 旧大变更的一个既有服务器能力条款误放在`Purpose`下，已仅移动增量章节标题修正解析，不改变业务文字；旧首页职责条款明确标记被替代。

## Migration Plan

更新插件菜单资源并运行标准资源同步，旧路径继续指向新首页。新增幂等付款时间和客户注册时间索引；已有账本币种时间索引、订单项与数量快照业务键、服务权益到期索引继续复用。累计精确聚合需扫描匹配历史索引，按月及明细查询保持时间范围有界，无逐记录查询。回滚使用原版本资源与页面，不修改业务历史记录。
