# 运营数据首页重建

## Why

旧首页将订单金额当收入、下单数当付款数，日期比较和客户指标也与运营口径不符。用户已确认新口径，需要同时重建首页与可核对明细。

## What Changes

- 一级菜单统一为“运营数据”，替代旧分析页、快捷工作台的首页分工。
- 按实际到账、付款时间、商家时区的自然月统计；保留原币种。
- 增加客户、服务器、工单和商品排行，所有指标进入相同条件的有界明细。
- 通过宿主管理的会话查询接缝统计有效在线客户，禁止业务插件读取宿主私表。

## Capabilities

### New Capabilities

- `idc-operations-analytics`：完善尚未归档的运营统计能力，定义首页统计与下钻契约。

### Modified Capabilities

无已归档能力变更。

## Impact

影响`idc-core`统计服务、接口、首页、业务列表适配，以及宿主会话查询接缝。双语界面与接口文档同步；不改变支付、履约或工单写操作。
