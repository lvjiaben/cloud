## 使用方法

本矩阵把智简魔方财务、业务管理系统`V10`、官方市场需求信号和用户明确决策映射到本变更的规范、任务与验收用例，用于约束“服务器运营范围内只多不少”。来源真实性和`clean-room`边界见[功能证据矩阵](./evidence.md)。

来源缩写：

- `F`：智简魔方财务官方文档及用户授权的本地源码静态审计。
- `V`：业务管理系统`V10`官方产品、公开仓库与应用体系。
- `M`：官方应用市场需求信号，不代表接口已经验证。
- `U`：用户在本任务中的明确业务决策。

状态含义：

- `首版强制`：必须完成规范、任务、代码和验收证据才能发布。
- `能力门禁`：首版必须交付，但具体外部动作只有在正式文档、商务授权和契约测试通过后启用。
- `批准例外`：用户已经明确允许首版不提供，不计为覆盖遗漏。
