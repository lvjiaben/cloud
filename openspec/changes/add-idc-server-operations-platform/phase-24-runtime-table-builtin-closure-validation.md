## 三轮复审

### 第一轮：复现错误并确认真实根因

- 分别从商品详情、无商品项订单、工单关闭、合同配置和阿里云配置追到实际 SQL 或固定配置号，没有用前端兜底隐藏后端错误。
- 在本地 PostgreSQL 补齐仅用于验收的幂等关系数据，生产初始化不写入外部供应商结果，也不伪造真实凭据。
- 对客户侧栏持续悬停、移动端跳转和表格页签切换进行真实浏览器复现，确认问题来自运行期布局状态和高度链，而不是截图差异。

### 第二轮：同类页面与生命周期扫描

- 扫描后台、客户中心及可达插件业务页的原生表格、无界高度、操作列、搜索区和分页，增加统一表格归一化与静态治理测试。
- 检查公告、部门、岗位和插件管理边界：内置插件从管理列表隐藏且拒绝生命周期写操作，业务菜单和数据保留。
- 检查可选动态插件重启语义：四类支付、迁移和云速 SSL 的显式安装启用状态在同步后保持，不把“内置”规则扩散到可选插件。

### 第三轮：类型、双语、浏览器和代码门禁

- 后台与客户中心 TypeScript 类型检查通过。
