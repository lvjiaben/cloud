# 第 8 阶段服务器批量操作验证记录

## 范围

本记录对应任务 `8.14`。实现只属于 `idc-core` 插件，没有向 `web-antd` 写入 IDC 页面、接口客户端、路由、状态或多语言资源。

已实现的安全操作包括批量添加标签、移除标签、从后台固定分类目录中为每台服务器单选分类、追加非敏感内部备注和发送续费提醒。已实现的危险操作包括批量暂停、重启、重装、换 IP 和终止。

## 安全边界

- 每批只能提交 1～20 个不重复的明确服务编号，不提供无边界“全选”。
- 安全操作和危险操作使用不同的受保护预览、执行接口，避免权限互相串用。
- 所有操作先保存逐台预览。预览包含客户、欠款、本次费用、到期时间、本地资源摘要、三维状态和不可逆标记。
- 危险操作执行前必须取得绑定当前操作人、当前登录会话和这份精确预览的短期一次性证明。刷新旧登录状态不能代替最近一次完整登录。
- 每台服务器分别创建幂等操作或任务。单台失败不会回滚或遮住其他服务器结果；危险操作的单台失败进入人工处理状态。
- 换 IP 继续使用已有资格、频率、报价、库存预留和结算流程，不绕过付费或库存规则。
- 重装镜像逐台读取资源插件发布的可选镜像目录；过期、不存在或不可选的镜像在预览阶段直接跳过。
- 标签和内部备注只保存在本地数据库；内部备注禁止空白首尾，页面明确提醒不得填写密码、密钥或令牌。
- 后台可以新增、编辑和停用固定分类；批量分配只接受仍处于启用状态的分类编号，每台服务器最多保留一个分类。
- 重新登录证明不写入批量表，也不出现在审计快照中。

## 数据与性能

- 批量服务、客户、状态和欠款使用集合查询；欠款按“服务 + 账单”先去重，避免同一账单被重复累计。
- 重装镜像和换 IP 报价必须逐台访问资源权威来源。批量硬限制为 20 台，因此调用次数有明确上限，不会随数据库总量增长。
- 数据库迁移 `066-server-safe-batch.sql` 使用 `CREATE TABLE/INDEX IF NOT EXISTS`，表名均带完整插件前缀。批次、批次明细、标签和备注均有稳定唯一键与外键约束。
