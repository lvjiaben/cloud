# 智简魔方公有云 `v1` 契约冻结记录

## 目的与证据范围

本记录为任务`9.1`的离线契约基线，约束`idc-zjmfcloud`后续实现。`2026-08-06`对用户授权的已安装实例执行了以下只读核对：

- 通过后台“开发文档”查看生成式`v1 API`文档，共识别`570`个接口章节。
- 通过`GET /v1/upgrade`确认该安装实例版本为`3.9.14 beta`。
- 通过`GET /v1/tasks?page=1&per_page=1`核对任务分页响应外层为`data + meta`，未输出或保存既有任务内容。
- 对照用户授权的旧魔方财务连接器源码，确认管理员直连`v1`与魔方财务上下游接口是两套协议，禁止混用认证、资源编号和状态。

本次只执行登录和`GET`请求，没有创建、修改、暂停、重装、续费、变配或删除任何用户与实例。后台路径、文档票据、账号、密码、访问令牌、既有资源编号和响应数据均未写入仓库。

## 传输、认证与响应约定

| 项目 | 已验证契约 | 适配器约束 |
|---|---|---|
| 基础地址 | 接口地址位于商家配置的后台二级目录下，文档中的路径从`/v1`开始 | 后台只保存经过安全校验的基础地址；不得猜测后台目录，不得把目录或凭据放入查询串、日志和证据 |
| 登录 | `POST /v1/login`，参数为`username`和`password`；本次实例返回`201` | 凭据只从`secretcap`受限 accessor 获取；同渠道登录使用单航班合并 |
| 令牌格式 | 响应是包含令牌的 JSON 字符串，不是对象；文档说明正常过期时间为一天 | 必须用 JSON 字符串解码，不得用宽松裁剪猜测格式；令牌只保存在进程内短期缓存，禁止普通日志和持久证据 |
| 鉴权 | 后续请求使用`access-token`请求头 | 只读请求收到`401`时允许单航班刷新并重放一次；已经发送的写请求收到`401`只失效令牌并标记结果未知，禁止自动重发 |
| 成功状态 | `GET`可返回`200/204`；`POST`可返回`200/201/202`；`PUT`和`DELETE`可返回`200/202/204` | `202`只表示受理，不得当成业务完成；空响应也不得猜测成功后的资源状态 |
| 错误状态 | 文档列出`400/401/403/404/405/500`，错误体形如`{"error":"..."}` | 保存稳定错误分类和脱敏摘要；不得把上游原文直接展示给客户 |
| 限流 | 生成文档未声明限流规则；一次只读任务查询未观察到限流或`Retry-After`响应头 | 能力矩阵标记`unknown`；使用本地并发上限、指数退避与抖动，并兼容未来`429/Retry-After`，不得假定“没有限流” |
| 上游幂等 | 创建及生命周期文档未声明幂等请求字段或请求头 | 本地业务幂等不能冒充上游幂等；写请求结果未知时先查任务和资源，无法唯一确认时转人工，禁止盲目重试 |

当前授权实例的直接地址无法通过受信任证书链校验。该事实只允许作为只读契约研究条件；正式适配器必须要求`HTTPS`、有效证书和主机名匹配，禁止提供跳过证书校验或任意重定向开关。任务`9.7`在取得合格的`HTTPS`入口前保持阻断。

## 任务模型

| 能力 | 端点与字段 | 规范化规则 |
|---|---|---|
| 任务列表 | `GET /v1/tasks`；支持`page`、`per_page`、`status`、`cloud`、`rel_type`、`type`；响应包含`data[]`和`meta` | 始终分页，不使用无限制全量读取；按资源编号和任务类型收敛查询范围 |
| 任务详情 | `GET /v1/tasks/:id`；返回`id`、`hostid`、`status`、时间、`progress`、`msg`、`type` | `msg`只作为脱敏诊断摘要，不作为稳定状态机输入 |
| 任务状态 | `0`未开始、`1`执行中、`2`成功、`3`失败、`4`强制结束、`5`已取消 | 映射为等待、运行、成功、失败、终止、取消；未知整数进入`unknown + manual_review` |
| 实例资源核对 | `GET /v1/clouds/:id`；全量详情包含实例状态、`IP`及可能的系统凭据 | `QueryResource`只投影白名单状态和`IP`数量；未知状态不猜测，原始详情及其中的敏感字段在投影后立即清除 |
| 取消任务 | `POST /v1/tasks/:id/cancel` | 文档明确目前只支持迁移和磁盘迁移，不能向普通生命周期任务展示通用取消按钮 |

## 安全投影规则

生成文档显示多个只读响应也可能包含密码、私钥、认证串、内部路径和管理地址。因此适配器禁止“先把原始 JSON 整包写入证据，再做展示脱敏”，必须在网络响应边界执行字段白名单投影：

1. 区域只保留编号、名称、国家、状态和容量统计。
2. 节点只保留编号、名称、区域、类型、可用状态和公开容量。
3. 镜像只保留编号、名称、分组、状态、启动方式和兼容约束。
4. 存储只保留不透明编号、展示名、类型、状态与剩余容量。
5. 实例列表只保留映射、规格、状态、公开网络资源和能力限制；`QueryResource`读取`GET /v1/clouds/:id`全量详情时只投影白名单状态和`IP`数量，原始详情中的 root、VNC、SSH、面板密码及其他敏感字段在投影后立即清除，不转换为交付凭据。
6. 原始响应仅允许在内存中完成有大小上限的解码；日志、指标标签、审计、任务载荷和数据库不得保存原始响应。

## 仍需验证的边界

- 正式上游没有公开限流、幂等、成本、余额、到期和续期契约，对应能力保持`unknown`或`unsupported`。
- `GET /v1/stores?list_type=all&enable=1`的公开前端消费形状已经纳入可控假服务契约；真实安装实例仍不得使用逐节点请求补齐库存，若后续版本改变顶层`data[]`形状或不再接受全量筛选，必须失败关闭并重新冻结契约。
- 生成文档中的版本注记不是完整变更日志；每个启用能力仍需可控假服务覆盖成功、失败、乱序、重复、超时和未知字段。
- 生产写测试必须等可信`HTTPS`入口就绪，并且只允许作用于本次创建、带专用标识且再次核对过的测试对象。
- 本记录完成任务`9.1`，不代表任务`9.2`至`9.8`或生产联调已经完成。
