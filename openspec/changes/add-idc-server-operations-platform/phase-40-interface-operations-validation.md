# 自动化接口操作恢复与会话限制调整

## 根因与修复

用户反馈新增接口要求重新登录、删除其他产品接口报商品目录管理不可用。本轮承接已有反馈，使用`lina-feedback`定位，按`lina-review`进行任务级审查，范围仅限本轮业务插件改动及对应规范和验证资产。

- 原操作证明及供应商、通知、工单配置把有效会话限制为最近五分钟登录，导致正常管理员保存密钥失败。现在使用当前有效会话签发操作证明，数据库消费约束同步取消登录年龄限制；保留身份、权限、目标绑定、签名、过期及单次消费。
- 未使用的其他产品接口存在配置修订和秘密引用，原外键及只追加触发器阻止删除。迁移`128`允许父接口删除时级联清理，直接删除子配置仍拒绝；在共同事务中撤销所有历史秘密，审计或删除失败整体回滚。曾关联业务的接口仍保留历史保护。
- 服务器接口删除已经提交后，再读取隐藏配置造成失败响应。删除分支现在返回已经提交的状态和版本，不再读不到后误报。
- 回归发现导入商品先按插件固定客户字段校验，阻断真实导入契约；改为优先使用已经验证的导入契约，普通插件仍用原契约。
- 同步批量操作、企业微信和服务器配置提示，以及相关接口中英文说明，不再指导管理员反复退出登录。
