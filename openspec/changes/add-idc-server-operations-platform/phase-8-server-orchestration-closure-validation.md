# 第 8 阶段服务器编排收口验证记录

## 范围

本记录收口任务 `8.2.b`、`8.2`、`8.5.c.2.b`、`8.5.c.2.b.2`、`8.5.c.2.b.2.b`、`8.5.c`和`8.5`。它汇总已经逐项验证的实现，不用单个页面测试代替后端状态机，也不把魔方 KVM 之外的财务适配规则混入服务器 Provider。

## 三维状态与竞态

- 核心拥有权益和运行状态，资源插件拥有 Provider 任务状态；跨插件只通过版本化契约和幂等回报收敛，不跨插件查表。
- 收费操作先冻结价格和业务操作，只有 `financially_settled` 后才派单；免费操作不伪造账单或结算事实。
- 暂停、恢复、终止、退款和普通操作在同一服务锁与版本栅栏下复核；结果未知保持原安全状态并转人工处理，禁止盲目重放。
- 续费与到期终止、退款与普通操作、换 IP 最后库存、重装与其他写操作、付费变配失败退款均已完成真实 PostgreSQL 竞态回归。
- 部分回收失败时服务继续保持 `terminating`，并冻结最多 16 条未回收资源安全投影，不会误报已释放。

## Provider 编排闭环

| 能力 | 已验证链路 |
| --- | --- |
| 新购开通、查询 | 结清后逐台建服务和资源任务；同步或异步完成都原子写入映射、任务、脱敏证据和跨 owner 回执；无任务号时用新鲜 `QueryResource` 收敛 |
| 暂停、恢复、终止、续费 | 生命周期托管作业、数据库时钟、服务锁、版本栅栏、任务查询和结果未知保护均已接线 |
| 开机、关机、重启 | 动作与运行状态矩阵、服务互斥、Provider 参数白名单和任务回报均已闭环 |
| 重置密码、控制台、重装 | 输入秘密只保存不透明引用；孤儿句柄有补偿；输出使用一次性密码或短期控制台票据，过期和重复读取拒绝 |
| 换 IP | 独立资格、报价、库存预留、结算、参数型权威查询、成功地址投影、失败释放和并发保护均已闭环 |
| 变配 | 权威可选项、升降级规则、结算、Provider 白名单、配置版本、续费价和失败统一退款均已闭环 |
| 配件能力 | 快照、备份、流量、安全组、NAT 和虚拟介质均走能力目录、对象归属、结算门禁、互斥和结果未知保护 |

资源任务执行、观察、资源查询和跨 owner 回报都由 `pluginhost.Jobs` 在主节点启动时显式装配。一次任务批次集合化解析映射并按渠道复用会话，不按返回行数逐项查库；秘密输出在事务失败后执行确定性孤儿补偿。
