## 结论

本节以下“已经完成”均为回归更正前的历史结论，只有仍与上方更正一致并由新组合测试重新证明的部分才可复用。服务器接口的当前权威边界固定如下：`idc-resource`渠道及其接口配置是唯一供应商实例，资源插件保存通用商品接口编号到本地渠道的冻结映射；商品核心不保存服务器端点、账号、密钥或资源池；服务器动态连接器只通过`resource-provider`接受资源拥有方任务。

服务器专用能力已经从通用商品与财务核心中收回到`idc-resource`服务器业务插件。通用核心只保留商品、订单、账单、付款、通用权益和逐项续费能力，不再识别 CPU、内存、镜像、磁盘、带宽、资源池或供应商品牌。

服务器插件现在负责服务器接口实例、资源池、服务器权益投影、生命周期操作、批量续费和转移规则。智简魔方云以`dynamic + managed`托管动态连接器交付；它通过`resource-provider`扩展点被服务器插件发现，不再作为内置源码 Provider 写死。

本记录先保留回归重写过程；当前同一条真实组合链已经补齐。任务`0.13`只等待本轮完整门禁和`lina-review`最终确认，`FB-52`仍不关闭。任务`0.14`当前要求服务器、SSL 和完全人工非服务器商品三类验证；首版不开发手机插件。

## 完成范围

### 服务器插件契约

- `idc-resource`发布并消费通用`resource-provider`扩展点，通过清单声明选择兼容连接器，不按插件名称或品牌猜测能力。
- 接口实例保存冻结的插件、发布版本、契约版本和声明摘要；已经发布的商品版本与历史服务不会因管理员后来更换接口而静默漂移。
- 资源池保留优先级、权重和`active`、`draining`、`maintenance`、`disabled`四种状态。它是服务器插件自己的供给能力，不进入通用商品库存模型。
- Provider 候选只包含当前已安装、已启用、仍接受新业务的有效动态发布。停止新业务后不再允许新绑定，但已有服务、历史查询和必要操作仍保留。

### 生命周期、续费和转移

- 开机、关机、重启、重装、控制台、快照、备份、换 IP、变配等操作继续由服务器插件处理，没有包装成所有商品共用的固定字段或页面。
- 批量续费入口位于服务器插件，只能从服务器插件投影出的可续费权益中勾选，单次最多`20`台并统一选择周期。
- 每台服务器仍由通用核心独立报价和确认；其中一台失败不会冒充整批成功。确认前会重新核对服务器投影、客户归属、报价和到期时间，避免页面停留期间事实变化。
- 金额在接口和前端之间使用十进制字符串传递，避免 JavaScript 浮点数改变付款金额；内部投影版本不展示给用户。
- 服务器转移只携带已付款、有效、未过期并且只属于该服务器的快照和备份权益。历史订单、账单、付款和退款留在原客户；原自动续费关闭；存在未付续费或增购账单时拒绝转移。
- 转移完成时，通用权益拥有方和服务器权益投影同步改变客户归属。旧续费 worker 在执行前重新检查当前归属，不能继续替原客户续费。

### 托管动态连接器和保密出站

- `idc-zjmfcloud`清单固定为`type: dynamic`、`distribution: managed`，并声明`resource-provider`扩展点。
- 后台按连接器声明创建接口实例，不允许录入可执行代码，也不把接口地址、秘密句柄或供应商凭据交给动态插件。
- 供应商秘密只在宿主管理的保密出站通道内短暂使用。普通调用载荷、普通响应、WASM 内存、日志、任务证据和业务表都不能得到秘密明文。
- 跨插件、跨接口实例、过期上下文、重放、普通路由调用和上游在允许字段中回显秘密都会在供应商结果进入插件前被拒绝。
- 独立安全验证和详细威胁用例见[保密出站通道独立安全验证](../../../apps/lina-plugins/idc-resource/FB-52-0.13-CONFIDENTIAL-OUTBOUND-SECURITY-VALIDATION.md)。

### 开发数据迁移和重建

- 当前开发数据库只有一个通用人工商品草稿和版本草稿，没有旧服务器订单、服务、任务、映射或投影，因此本轮没有删除、覆盖或伪造开发数据。
- 其他开发库若存在旧服务器数据，先由`idc-core`把具有唯一冻结事实的旧服务幂等迁移为通用交付记录和权益，再由`idc-resource`依据成功资源任务、活动映射及耐久权益事件重建服务器投影。
- 证据不完整或归属冲突时停止并转人工核对，不猜测、不重新调用供应商。详细步骤和对账门禁见[开发数据迁移、重建与对账验证](fb-52-0.13-development-data-migration-validation.md)。

## 后台与客户页面验证

- 后台接口配置页展示连接器名称、版本、接口实例和资源池，不向普通管理员展示插件内部编号。
- 没有可用连接器时，新增接口按钮禁用并明确说明原因；不会给出一个必然失败的空表单。

## 2026-08-28 回归重写进展

- 删除服务器连接器直连商品履约后，进一步发现`idc-resource`的服务器拥有方解析器会因为连接器自有字段而拒绝整个冻结商品配置。现已改为只读取地区、线路、CPU、内存、系统盘、数据盘、带宽和操作系统这些服务器共有字段；`upstream_product_id`、上游配置项映射等连接器字段继续原样交给冻结的精确连接器发布版本。新增回归测试证明连接器字段不会被资源拥有方解释或丢弃，同时缺少共有字段和非法数值仍会失败关闭。
