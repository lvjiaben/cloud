## 审查中发现并已修复的问题

- 插件生命周期写库后未刷新启动快照，可能在重启后恢复旧状态；已在统一生命周期状态写入路径刷新快照并补充回归测试。
- 开关外层滑块虽为圆形，但 Ant Design 的`::before`伪元素仍是直角；已在管理端和客户侧作用域内同时约束滑块与伪元素。
- 新增 mock 客户编号不满足业务格式，导致真实页面无法稳定关联；已改为合法`CUS_`编号并补充格式测试。
- 新增 PostgreSQL mock SQL 存在未引用标识符和用途注释遗漏；已全部修正并通过方言测试与真实数据库双轮幂等执行。
- 个别业务页面仍显示`Loading`、`CREDIT CONTROL`、`MAX 20`及内部认证枚举；已改为中英文资源和普通用户能理解的名称。
