# 第三十三阶段：后台布局与易用性验证

## 范围与结果

本轮按用户要求整理后台日常使用方式，沿用上一阶段的服务器管理和供应商运维归组。在插件范围统一46个后台页面的间距、标题、页签及窄屏布局，去掉通知页面双层容器、配置抽屉重复标题和没有翻页数据时的无效箭头。内容入口归入内容管理，工单分组改为工单客服；菜单标识、路径和权限不变。

工单与内容优先显示常用筛选，其他条件通过“更多筛选”展开，增加明确的搜索和重置。财务低频工具默认收起，首次展开才加载。中英文文案去掉重复技术解释，保留费用单位、商家承担第三方费用、重要操作结果及必要确认。换`IP`设置不再显示只读版本输入框，请求中的并发版本仍保留。

使用方式和每个入口对应的人员见[后台怎么用](../../../localdocs/admin-usage-guide.md)。魔方云和`SSL`入口仍由`idc-zjmfcloud`和`yunsu-ssl`各自安装启用后的页面表面提供；核心与资源插件未新增固定入口，未伪造上游可用状态。

## 根因与修复

- 原页面同时使用外层卡片、内部面板和各自样式，导致重复内边距、标题与不一致布局。新增适配层`admin.css`，仅作用显式标记的插件后台页面；通知独立构建也保留自己的局部页头样式。
- 通知配置在聚合抽屉内读取外层系统配置路由，错误显示渠道页面。四个入口现在传入明确目标路径，通知模板抽屉实际显示模板和发送规则。
- 实名认证配置真实草稿返回空连接状态，前端把未定义翻译键传入翻译函数导致白屏。空状态按“未测试”展示，未伪造连接成功；真实草稿回归覆盖该场景。
- 开放接口列表正式路由仍调用未实现的控制器方法。三个路由方法改为调用已装配的原有业务委托，保留客户授权、状态校验、分页和错误；不恢复旧渠道审批、授信或发布流程。
- 合同详情测试仍依赖旧表格结构，且菜单加载重新装配时可能回到初始页签。页面对象按当前表格行和固定操作列定位，并等待目标内容稳定后操作；详情、退款申请、重新发起和解除合同回归证明业务结果未改变。英文手机隐私测试先切换语言再缩小窗口，避免测试调用只面向桌面的语言菜单。

## 实际限制

合规独立构建脚本因缺少本地`esbuild`依赖未通过；该脚本构建的编辑器供应资产不在本轮修改范围，后台全部源页面的生产构建已经通过，不能把它记录成合规独立构建成功。
