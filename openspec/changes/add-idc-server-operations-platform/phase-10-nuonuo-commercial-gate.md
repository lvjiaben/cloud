# 第十阶段诺诺电子发票外部证据门禁记录

## 1. 当前结论

截至`2026-08-17`，任务`10.4.c`和`10.10`仍受外部证据阻断，不能勾选。当前公开资料只能证明诺诺提供电子发票相关产品，并通过`API`、账号授权和数据安全调用向`ISV`及客户开放部分产品能力；它不能代替当前购买方与诺诺之间的正式接入确认，也不能证明本项目需要的精确开票能力已经全部可用。

因此真实诺诺客户端、主体识别器、回调验证器、主动查询器、用量采集器和生产业务路由继续保持未注册。系统不得改成软件提供方统一`ISV`代接、中央业务网关、中央结算或统一回调转发。

## 2. 公开资料已经证明的内容

- 诺诺提供电子发票全生命周期相关产品，包括诺诺发票、极速开票和智能编码等。
- 诺诺官方生态页面说明开放平台可通过`API`、账号授权和数据安全调用与`ISV`及客户合作。
- 诺诺官网提供企业自行注册、登录和使用产品的入口。

官方公开来源：

- [诺诺生态与开放平台](https://hangzhou.nuonuo.com/nuonuo/web/teamwork/teamIndex/index.html)
- [诺诺网企业数智服务平台](https://www.nuonuo.com/)
- [诺诺网官方产品与公司说明](https://www.nuonuo.com/nuonuo/web/aboutone/index/index.html)

这些资料只足以保留诺诺作为首个电子发票适配器候选，不能证明生产接口契约。

## 3. 仍缺少的外部证据

以下每项都必须由诺诺提供给当前购买方的正式合同、正式开放平台文档、已授权控制台能力或书面确认来证明：

| 待确认内容 | 必须明确的细节 |
|---|---|
| 独立接入身份 | 每个购买方能否用自己的企业、自己的开放平台应用、自己的凭据和自己的纳税主体独立接入，而不是必须挂在软件提供方统一`ISV`账号下 |
| 授权和鉴权 | 应用申请条件、授权流程、凭据类型、签名算法、权限范围、回调验签、密钥轮换和撤销 |
| 开票接口 | 准确接口、请求字段、响应字段、幂等要求、状态、错误码、主动查询、回调和限流 |
| 票种 | 当前购买方实际可开的数电票、电子普票、专票或其他票种，以及各自限制 |
| 税收分类 | 商品和服务税收分类编码的来源、校验、版本、税率和优惠政策字段 |
| 源文件 | 可长期下载的`PDF`、`OFD`、`XML`或其他权威源文件类型、下载授权、地址有效期和哈希核验方式 |
| 红字处理 | 红字确认单、购销方确认、部分红冲、整张红冲、状态查询、失败恢复和不能自动处理时的人工流程 |
| 外币规则 | 是否允许外币计税、允许币种、汇率来源和日期、人民币折算、税额舍入及票面字段 |
| 用量和费用 | 套餐、开票量、接口调用量、文件或短信费用、余额或额度、对账明细和查询时间范围 |
| 直接结算 | 费用是否由当前购买方直接与诺诺结算，是否存在必须由统一`ISV`购买或转售的能力 |
| 数据责任 | 诺诺、当前购买方和软件提供方各自的数据处理角色、留存、删除、出境、事件通知和审计责任 |

公开产品页面、销售口头描述、网上流传的接口样例、其他企业的账号截图或无法证明授权来源的文档，均不能替代以上证据。

## 4. 解除门禁所需材料

至少需要以下材料组合后才能重新审查：

1. 当前购买方自己的诺诺企业账号和开放平台应用已经获准接入的证明；
2. 诺诺提供给该购买方的正式接口目录和准确版本；
3. 开票、查询、回调、红字、源文件、用量和结算接口的正式字段、签名、错误码与限流说明；
4. 实际可用票种、税收分类和外币规则的诺诺确认，以及购买方财务或税务负责人确认；
5. 购买方与诺诺直接结算及数据处理责任的合同或书面确认；
6. 可以隔离验证的测试账号、测试企业主体或诺诺认可的联调环境。

材料齐全后必须先更新本记录、`evidence.md`、设计和规范，再实现真实客户端，并重新执行安全、真实 PostgreSQL、双平台组件包和浏览器验收。不能先写客户端再倒推接口。

## 5. 当前安全状态

- `nuonuo_invoice`只保留供应商中立的关闭状态、配置投影和数据模型占位，不发起真实网络请求。
- 本地网关的诺诺识别器、写入客户端、回调路由、只读查询器和用量采集器集合为空。
- 商家尝试启用时必须得到`external_confirmation_required`或等价明确原因，不能显示已开通。
- 任务`10.11`中不依赖诺诺的供应商中立发票领域可以继续设计，但诺诺授权向导、真实开票、真实红字、真实文件下载和真实用量接线不得越过本门禁。
- 任务`10.18`的真实诺诺浏览器流程也受本门禁阻断，不能用假服务结果冒充生产能力。

本记录只证明阻断条件已经明确，不证明`10.4.c`、`10.10`、`10.11`或`10.18`完成。
