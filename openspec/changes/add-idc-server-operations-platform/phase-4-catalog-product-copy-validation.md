# 第四阶段商品整图复制验证记录

> **`FB-52`部分失效声明：**创建新商品身份、显式新文案和不复制销售状态的边界可以保留；旧固定服务器配置图、兼容边和资源池字段不能作为通用复制模型。现行复制只重建冻结插件声明允许的通用配置、计费、价格与税务引用，并且不复制接口实例绑定、简单库存、成本或插件私有证据。

## 结论

`4.2.c`的插件内实现已经完成。后台商品复制使用独立精确权限，先锁定源版本和源商品，再以固定 5 次投影查询读取配置组、配置项、兼容规则、计费规则和价格。目标是全新的商品身份与`copy + draft`版本，销售文案和公开 slug 必须显式提供；目标没有当前发布版本、资源池、库存、成本或 Provider 审核证据，不能因复制直接销售。

插件后端、真实 PostgreSQL、代码质量和插件治理门禁均通过。插件自身多语言覆盖通过；仓库级`make.cmd i18n.check`仍仅被无权修改的宿主通知预览页 6 个既有缺失键阻断，因此子任务暂不勾选。

## 实现范围

- 复制权限与分类创建、商品创建、Provider 草稿创建、Provider 审核和正式发布权限全部分离；授权在输入规范化和任何商品表访问前完成，畸形源版本号也不会触发身份或权限依赖读取。
- 输入必须显式提供目标分类、新公开 slug、新中英文名称和新中英文摘要。商品类型和固定/可配置模式来自源商品，目标分类必须仍启用、未删除且类型一致。
- 源版本行作为商品子图统一并发栅栏先被`FOR UPDATE`锁定，再锁源商品并集合读取子图；目标版本插入后也显式锁定，随后才允许批量写入子图。
- 配置组、配置项、兼容规则、计费规则和价格各使用一次字段投影查询，共固定 5 次，不按组、选项、规则、币种或价格循环查库。
- 全部 5 类子图共享 20,000 行总上限。每次查询只允许读取“剩余预算 + 1”行，任一阶段越界立即拒绝，不能把每张表各自 20,000 行误当成总上限。
- 复制前重新校验固定/可配置共享图不变量及每个选项的规范组件 JSON，并验证兼容、计费和价格引用完整；无效或孤立源图不会传播到新商品。
- 新配置组、选项、兼容、计费和价格业务号由“对象类型 + 目标版本号 + 源业务号”的`SHA-256`摘要截取 128 位生成，稳定重建内部引用且不复用源业务身份；各表以 500 行固定批次写入。
- 目标版本号为 1，来源为`copy`，本地`source_version`只记录源商品版本号，Provider 指纹保持空白；版本级`requires_contract`作为销售行为配置随版本复制。
- 不读取也不复制资源池绑定、库存快照、成本快照、Provider 补全/币种/候选决定、商品当前版本指针、源发布状态和上游来源指纹。复制完成后必须重新绑定履约资源并经过统一发布门禁。
- 商品、版本、全部子图和业务审计位于同一事务。审计失败、重复公开 slug、类型冲突、越界或子图不一致都会整体回滚。

## 任务级审查

- **已修复**：初版读取器给每张子表各自设置 20,000 行上限，极端情况下会在拒绝前装配约 100,000 行。现改为共享剩余预算，每次查询最多读取剩余量加 1，全程内存规模严格受总上限约束。
- **已修复**：初版公开 slug 只做事务内预查，并发唯一冲突可能被包装为临时不可用。现根商品和版本使用`INSERT ... ON CONFLICT DO NOTHING`语义并检查精确影响行数，唯一冲突稳定返回目录冲突且事务回滚。
- 已确认源版本在任何子图读取前加锁，目标版本在任何子图写入前加锁；发布重检和未来图修改服务可以依赖相同父行锁序。
- 已确认复制只进行固定数量集合查询和固定批次写入，不存在按选项、兼容边、计费规则或价格的`N+1`访问。
- 已确认所有跨表业务号都重新生成且引用指向目标版本；源选项号、组号、兼容号、计费号和价格号不会出现在目标图中。
- 已确认真实源包含资源池、库存、成本和已物化 Provider 审核证据时，目标仍不产生这些对象；源历史也不会被修改。
- 严重、外部既有阻断：`apps/lina-vben/apps/web-antd/src/views/system/message/notice-preview-modal.vue`引用的 3 个宿主键在`en-US`和`zh-CN`均缺失。当前仓库没有`.contributing`，本任务无权修改宿主目录，不能把仓库级 i18n 门禁标记为通过。

## 影响说明

- **API**：无新增 HTTP API；当前为插件内部服务边界。复制权限会在对应后台 API 和菜单落地时登记，避免提前出现孤立可分配权限。
- **SQL**：无新增迁移；复用现有商品图外键、唯一约束和生命周期约束。真实 PostgreSQL 已验证批次写入、排除项和事务回滚。
- **缓存**：无影响；复制只生成不可售草稿，不刷新公开商品缓存。
- **数据权限**：有影响；复制要求直接活动员工、默认商家、精确复制权限和数据范围 1/2，授权先于源版本存在性查询。
- **i18n**：没有新增用户可见错误码，复用目录管理双语错误；插件消息覆盖通过，仓库级门禁仍受上述宿主既有问题阻断。
- **前端与 Chrome**：无前端改动，不需要页面或 Chrome 验收。
- **Git**：未提交、未暂存、未推送。
