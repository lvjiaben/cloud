# 资源目录完整分页验证

## 交付范围

本轮把供应商容量观测、上游渠道健康、供应商任务、服务器续费候选、资源池和供应商财务最新事实接入准确数字分页；后台服务器服务主目录的`server-services`接口同步返回准确总数，页面接线由流量套餐界面任务完成。

所有列表仍先执行原权限和数据范围校验。总数与数据行使用同一筛选谓词；每次查询固定为一次计数和一次有界页查询，不按返回行逐项读取，不把库存、历史草稿或当前页长度当成总数。既有游标调用保持可用，但调用方不得同时传入页码和游标。

前端正式资源页面使用真实`useVbenVxeGrid`完整分页条，页规模固定为`10/20/50/100`。页规模和筛选变化回到第`1`页；普通`503`或网络失败保留已确认页面，真实`401/403`清空当前授权数据和详情状态，迟到请求不能恢复已撤销数据。表头继续使用主题灰色，数据行、工具栏和分页继续使用白色面板，页面外层不变。

## 数据和性能边界

- 容量观测、渠道健康和任务具有现有租户、状态、创建时间或唯一编号索引；分页前的计数不继承数据列投影，避免生成非法或重复聚合。此次真实数据测试证明结果和边界，不宣称全部查询的执行计划均已实测。
- 资源池具有`idx_plugin_idc_resource_pool_route`，财务最新事实具有`idx_plugin_idc_resource_financial_latest`；后者继续按`渠道 + 类型 + 外部资源引用`选择最新本地事实，不扩大为全部历史。
- 续费候选只读插件自己的服务权益投影，后台服务目录只读`idc-core`拥有的服务、权益和当前产品投影；两者都不调用真实上游。
- 独立数据库测试使用随机隔离`schema`并在测试结束清理，不修改或重置当前开发数据库。
