## 本机 PostgreSQL 盘点（只读）

- `2026-09-04`只读核对当前规范开发入口`6030`的配置，实际数据库为`cloud_preview_19120`；`cloud_codex_e2e`仅为历史 E2E 运行库，不能据旧记录为当前服务准备数据。历史盘点的表数不代表当前数量。两库都不得自动删除或重置。
- `cloud` 不是当前后端运行库。它有 398 张表，但没有 IDC 插件表；`temp/prepare_e2e_database.go` 会把它作为模板克隆出 `cloud_codex_e2e`，所以继续跑 E2E 前不要擅自删除。
- `linapro_idc_codegen` 是 DAO/DO/Entity 代码生成和部分后端迁移测试的专用库，不能删除。
- `cloud_preview_19120_fb52_before_20260826`、`cloud_preview_19120_fb52_08_before_20260826`、`cloud_preview_19120_fb52_browser_20260827` 是 FB-52 迁移/浏览器验证备份；在确认不再需要回溯前保留。
- 其余带 `e2e`、`phase`、`acceptance`、`play`、日期或 `before` 的数据库，大多是历史验证库或快照，但不能仅凭名字自动删除；删除前必须逐个确认没有测试、日志、回溯或其他进程依赖。
- `linapro`、`shops`、`order` 等不带当前 OpenSpec 命名的库含有实际表和数据，无法证明是本轮创建，也不能当作临时库直接删除。
- 当前 PostgreSQL 实例共 71 个非模板数据库。这个数字反映本机历史测试积累，不等于项目源码需要 71 个数据库。
