# 第七阶段支付数据底座验证记录

## 完成内容

- 新增商家支付通道表，只保存不透明秘密引用，不保存商户密钥、证书或私钥明文。
- 新增支付尝试、异步回调接收、主动查询观察、退款尝试、对账批次与差异行、异常款、异步工作项和证据表。
- 金额统一使用整数最小货币单位；支付尝试冻结账单、订单、币种、金额、产品模式和请求摘要。
- 回调、主动查询、对账差异和证据历史只追加，禁止修改或删除。
- 支付与退款分别按本地业务编号、渠道交易号、退款请求号和渠道退款号保持幂等。
- 支付结果只能进入异步工作项，再通过 `billingcap` 交给 core 资金 owner 入账；支付插件不直接写 core 表。
- 已关闭或已过期支付尝试收到真实成功款时进入异常款，不复活订单、不恢复库存、不触发履约。

## 验证

- 真实 PostgreSQL 隔离 schema 连续执行迁移两次通过。
- 验证 `10` 张权威表、外部交易号的非空唯一性、退款结果未知投影约束和回调历史不可变。
- 重复有效回调只创建一个 core 入账工作项，同一工作项只调用一次 `billingcap`。
- 已关闭尝试的迟到成功回调只生成一条待处理异常款。
- `GOWORK=off go test ./...` 在支付插件全量通过。

## 边界

本任务只收口 `7.1` 数据底座。支付通道后台配置、客户支付页面、组合支付、退款流程、对账页面和 E2E 仍由后续任务完成，不能因为底座通过而提前勾选。
