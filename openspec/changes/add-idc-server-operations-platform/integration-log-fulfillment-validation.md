## 根因及修复

- 原生资源接口的冻结证据误按连接器凭据声明校验。现在按资源拥有方的不可变投影核验，兼容运行时由启动期共享适配器提供。

- 领取任务时数据库计数字段未正确映射，且提交预算与状态逻辑不一致。领取显式映射真实计数，数据库与工作器统一查询和提交各十次，达到上限明确失败，保留单调计数。
