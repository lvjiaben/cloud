## 范围与当前状态

日期为`2026-09-05`，对应`FB-113`。本记录覆盖接口统计、财务版及`V10`只读商品目录、管理员显式导入草稿及所需组件适配；实现、当前版本验证和任务级审查已完成，`FB-113`可以关闭。不代表六项真实外部账号门禁已经通过。

用户已确认的规则先同步到用户偏好、设计与商品／供应商增量规范：分类必选，名称默认沿用上游，公开地址自动生成可编辑；加价`10`表示成本增加百分之十，或者管理员直接填写最终售价；只能创建未上架草稿，配置和价格缺项必须明确提示，补齐后仍走原发布校验。未知硬件字段不按名称猜测。

## 实现与修复

- `idc-resource`按当前接口精确发布证据调用只读目录方法。列表有界分页和搜索，准确总数来自可见集合，选中商品后才读取价格与配置；没有上游分页的协议最多接受五百一十二项、一兆字节的完整快照，超限失败关闭，不伪造全部数据。
- 财务版读取`cart/all`及`cart/get_product_config`，`V10`读取商品列表与详情；仅接受可证明的币种、周期和费用，配置附加费不混成基础整机价。财务版无售卖价格与缺安装费不能当零；`V10`起步价不构成完整价格方案。只填写连接器明确声明的上游商品选择，其余配置保持待补。
- 商品拥有方提供`POST /admin/catalog/product-imports`。请求先校验四项精确员工权限，再查询同员工、同提交键的已提交结果，已完成重试不重新请求上游。同键改内容冲突；草稿、价目、配置绑定、不可变来源和审计在同一事务提交，失败全部回滚。
- 金额使用十进制字符串和有理数计算，按币种标准最小货币单位四舍五入，不经浏览器浮点计算。上游完整性不足的加价导入不伪造售价；手填售价独立校验，均不授予上架资格或制造续费价格。
- 读取采用同一不可变资源配置修订的地址、设置和秘密引用。资源拥有方在进程内附加读取证据，动态插件及浏览器不能经`JSON`伪造；读取后、导入准备和提交事务内核对接口、修订和发布证据。候选缓存键包含期望资源修订，配置变化或投影滞后拒绝导入。
- 两个前端交付入口共享真实 Vben 大抽屉和表单。添加／移除手填价目使用官方按钮；失败保留字段及原提交键，成功停留展示草稿结果与中文／英文缺项，不自动发布。关闭、重开、异步返回与重复提交受生命周期保护。
- 浏览器发现多个独立 Vue 应用生成相同对话框标题编号，造成导入抽屉引用父抽屉标题；适配插件为每个应用分配独立编号前缀。另修复下拉框仅箭头宽度和标题说明挤在同行，仅在适配抽屉作用域调整样式，不修改宿主通用组件。
- 真实接口目录另暴露统计编号校验错误：资源拥有方接受安全不透明名称，统计却只接受`CHN_`。开发库四条`demo_resource_channel_*`记录因此导致列表失败。只读统计现已对齐拥有方二百五十六字节安全名称契约，保留员工权限、商家范围、集合上限和参数化查询；不放宽绑定及供应商执行，不修改记录。
- 原生接口目录在`1280×720`真实页面还有分页被页脚遮挡：卡片正文设为整卡高度，再叠加五十五像素标题，分页底部超出页脚十六像素。该页改为纵向弹性卡片，正文只占剩余空间；扫描插件与客户表格相同高度写法，其他命中项是网格高度或无标题卡片，不具有该重复计算根因。新增卡片／页脚边界断言，不能只用元素可见断言代替完整分页可达。
