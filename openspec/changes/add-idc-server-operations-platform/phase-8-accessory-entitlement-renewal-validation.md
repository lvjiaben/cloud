# 第八阶段服务器附属对象权益与续费验证记录

## 验证范围

本记录只覆盖`8.7.b.3`：快照和备份对象的本地权益绑定、独立周期、自动续费、扣款失败保护、补款恢复、删除停止续费与本期不退款，以及流量履约不改变服务器运行状态。客户与后台动作接口、页面、动作专用权限、数据范围和浏览器回归仍属于`8.7.b.4`与`8.7.c`，本轮不把父任务或后续子任务视为完成。

## 已实现内容

- 创建快照或备份前，报价保存资源拥有方当时的同类对象清单、快照编号和观察时间。Provider 明确成功后，托管任务重新读取更新后的目录，只在能唯一识别新增对象时绑定本地权益；没有新对象继续等待，多个候选无法按请求名称唯一确定时转人工核对，不猜测绑定。
- 免费对象和付费对象分别保存创建时的计费身份。商家以后减少免费份数只影响新创建对象，已经绑定的免费对象继续免费。
- 每个付费对象保存自己的起止时间并独立续费。续费时读取商家当前已发布价格，生成新的不可变账单和价格快照，不覆盖过去周期。
- 到期前余额足够时自动扣款并从原周期结束时间顺延。到期后仍未付款时保留待付款账单，状态改为待付款处理，暂停恢复操作，但查看和删除不被权益门禁阻止，也绝不自动删除对象。
- 扣款失败会向当前客户唯一有效的账单联系人写入统一“账单支付结果”通知事件，并创建绑定精确`idc:admin:resource:accessory-renewal:handle`权限的后台待办。该待办是“所有具备该权限的员工均可见”的员工提醒来源；具体列表接口和插件后台页面由`8.7.b.4`暴露，不向`web-antd`写业务代码，也不依赖宿主枚举员工账号。
- 客户补足余额或直接支付原待付款账单后，托管任务自动恢复对象；若付款发生在旧周期已经结束之后，新完整周期从数据库确认付款后的成功处理时间开始，暂停区间不收费。
- Provider 明确完成删除后，权益立即标记删除并关闭自动续费，已开始周期的结束时间保持不变，不产生退款；未付款续费账单仍按已冻结的失败处理规则保留给后台待办处理。
- 流量包仍是一次性履约。派单中、成功、失败或人工核对都保持服务器原运行状态，不自动开机，也不自动解除流量暂停。

## 数据与性能边界

- 新增对象权益、不可变权益事件和权限待办三类插件本地表。对象号只保存资源拥有方给出的不透明编号，不保存 Provider 原始响应、凭据或秘密。
- 绑定和续费作业使用有界批量；续费候选、当前服务续费策略和到期门禁由一次集合查询完成。单个到期对象只执行固定数量的锁定、账单和余额操作，不按员工人数查询宿主或逐人扇出。
- 时间判断统一使用 PostgreSQL 权威时间。资源目录的观察时间只用于新鲜度和对象绑定围栏，不参与同一报价重放的商业摘要，避免等价重读被误判为价格变化。
- SQL 迁移可以连续执行两次；新增约束、外键和部分索引覆盖对象唯一绑定、待绑定扫描、到期扫描及权限待办读取。

## 边界与影响判断

- 未调用真实智简魔方写接口，Provider 创建、删除和目录变化均使用受控测试替身。
- 未修改`web-antd`、`web-customer`、官网或宿主`lina-core`源码；插件根目录不存在额外`AGENTS.md`，因此使用仓库顶层规则。
- `i18n`无新增资源影响：本轮没有新增页面、接口文案、菜单、字典或新的通知模板，客户通知复用已有双语`billing.payment_result`事件；仍执行了全仓`i18n.check`。
- 缓存无影响：权益、账单、余额、待办和续费状态均直接使用本地 PostgreSQL 权威事实，没有新增缓存。
- 数据权限接口无新增影响：本轮只建立服务端状态和权限待办来源，客户与员工读取/操作接口留在`8.7.b.4`按客户归属、精确权限和数据范围实现。
- 开发工具无代码影响：没有修改`Makefile`、`make.cmd`或`hack/`。Windows 没有 GNU `make`，因此使用仓库规定的等价入口`.\make.cmd lint.go dir=apps/lina-plugins/idc-core plugins=1`执行当前插件 lint。
