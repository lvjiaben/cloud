# 第四阶段营销赠送权益财务调整验证记录

## 完成范围

- 新增营销费用账户和赠送权益入账、冲正两类财务调整，金额始终使用原币种最小货币单位整数。
- 申请人不能复核自己的申请。只有另一位具有精确复核权限的有效员工批准后，系统才会在同一事务中写入平衡账本和营销权益状态。
- 入账固定借记商家营销费用、贷记客户赠送账户；冲正精确关联原入账交易并写完整反向分录，不直接改写客户余额，也不在营销表中冒充财务结果。
- 申请、复核和重放都使用稳定请求摘要；相同请求安全复用，内容变化、自审、越权或任一步失败均拒绝并回滚。
- 管理页面和接口由`idc-core`插件自己拥有，未向`web-antd`宿主写入 IDC 页面、路由、接口、状态、多语言或业务依赖。

## 验证结果

- 后端定向单元测试：营销、账单、管理控制器和管理接口包全部通过。
- 真实 PostgreSQL 集成：申请、第二人批准、重放、冲正、账本借贷守恒、营销分桶守恒、审计权限和事务回滚全部通过。
- 插件前端正式构建通过，`web-antd`仅作为插件装载宿主执行源码插件类型检查并通过。
- 仓库多语言门禁通过；新增中文和英文键保持一一对应。
- Playwright 治理检查通过；营销运营工作台`TC003`完整回归`7/7`通过，其中`TC-3g`覆盖入账申请、冲正申请和第二人复核。

## 工具异常处置

控制器生成器不支持当前已分组的控制器布局，试运行时产生了重复占位方法和重复构造函数。已只删除该次生成的重复内容，保留原有手写控制器，并在清理后重新执行控制器测试。后续不得再对该分组目录运行宽泛的控制器生成命令。
