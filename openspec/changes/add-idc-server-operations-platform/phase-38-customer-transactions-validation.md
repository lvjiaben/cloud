# 客户交易衔接与目录币种验收

## 实现范围

继续已有变更补齐后台业务断点。公开目录统一关联启用且未删除货币，基础售价排除配置加价，详情、候选、游标与数字分页保持同一过滤条件，历史价格保留。官网购买提示同步中英文。

客户订单和账单保留编号复制，增加详情入口；入口和直达链接均要求对应列表与详情两项权限，按准确编号重读拥有方数据。订单原先将错误留在被遮住的列表，现抽屉内展示错误并允许原地重试。账单同样可重试；两类详情关闭或卸载使旧请求失效。缺少完整风控材料时继续禁用批准、驳回，并解释原因，不伪造证据。
