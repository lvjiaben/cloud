# 第四阶段公开营销活动与曝光验证记录

## 完成范围

- 公开官网只读取当前有效、时间命中、不含客户分群目标、商品范围命中且当前币种存在有效权益的活动；每次最多返回 64 条，不向公开响应暴露客户、内部商品、成本或资源池事实。
- 曝光只保存用途隔离后的设备摘要，原始浏览器编号只在内存中参与`HMAC`。同一设备摘要、活动和币种在滚动 30 分钟内只记录一次；普通刷新不重复，币种不同则独立记录。
- 指定客户分群的活动从公开接口失败关闭，不会在未登录官网泄露；后续客户资格投影不得复用本公开接口绕过登录与资格核对。
