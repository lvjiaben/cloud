# 第十一阶段工单、内容与通知验收记录

## 1. 结论

第十一阶段已完成。工单、知识库与公开内容、多渠道通知、共享验证码与站内信、员工业务资格、旧魔方财务上游工单通道均已形成真实实现，不是空壳页面或临时模型。

本阶段严格遵守前端归属：

- 后台工单、内容和通知页面位于各自插件的`frontend/`，通过源码插件机制加载。
- 登录后客户工单、通知和匿名售前入口位于`apps/lina-vben/apps/web-customer/`。
- 公开新闻、公告、知识库、下载和帮助页面位于`apps/lina-websites/sites/default/`。
- `apps/lina-core/`和`apps/lina-vben/apps/web-antd/`没有第十一阶段业务改动。

## 2. 交付范围

### 2.1 工单与员工资格

`idc-core`已经交付售前、客户和内部工单，问题分类与部门路由、公共和部门队列、人工领取、轮流分配、最少未解决分配、转派、状态、关闭、重开、评价、合并、拆分、升级、内部备注、附件、SLA、自动化、预设回复和上游转发。自定义字段支持七种固定类型、双语选项、适用范围、必填、停用、不可变快照和客户服务器服务关联。

`staff-access`作为独立通用插件管理客服、负责人、审批人和内部通知收件人等员工业务资格。它不修改宿主、不读取宿主表，并以版本化能力供其他插件使用。保存操作执行严格乐观版本检查，新建只能使用版本`0`，并发和陈旧写入失败关闭。

旧魔方财务上游工单由工单域自有独立通道处理，拥有独立端点、认证模式、秘密引用、部门映射、服务`dcimid`映射、状态和版本，不复用魔方云管理员 Provider。上游发送只允许人工选择客户可见内容并预览确认；结果不明时只能查询或人工核对。

### 2.2 内容与下载

新闻、公告、知识库和下载中心支持草稿、直接发布、修改、下线、再次上线和直接删除，不设置审核、定时发布、关键词或手工规范链接。后台录入内容按原值展示，不因界面语言翻译。公告不使用分类；新闻、知识库和下载允许未分类。

下载实现稳定公开地址、SEO 回退、可见范围、文件哈希、候选文件、断点续传、短期票据、权限修订和强制作废。危险文件使用当前安装实例自己的`ClamAV clamd`流式扫描，并包含`7Z`加密归档预检、扫描超时、租约和迟到结果围栏。真实 PostgreSQL 测试覆盖内容状态、票据、候选文件、并发、撤权和扫描状态。

### 2.3 通知与匿名验证

`idc-notify`已经交付站内信、SMTP 邮件、阿里云短信、腾讯云短信、短信宝、微信公众号和企业微信，自有账号配置不回显秘密。渠道停用、重新启用、清除配置、结果不明确查询、人工结案、自动重试和人工重发都使用数据库权威时间、版本和并发围栏。

模板执行变量白名单、中文和英文预览、免打扰、营销退订及强制安全通知规则。人工重发限制为同一通知链最多三次、相邻成功创建至少十分钟，且需要最近五分钟完整登录、当前权限、业务数据范围和服务商明确未接收证据。

`shared-services`独立提供用途绑定、短期单次、防重放的人机验证能力和幂等站内信能力。匿名售前链接固定两小时，短信验证码固定六位、十分钟、最多输错五次，并执行目的地、账号、浏览器、IP、模板和安装实例费用频控。

## 3. 页面与用户可见结果

- 插件后台：工单工作台、工单设置、自定义字段、内容管理、通知渠道、模板、投递记录、企业微信绑定和员工业务资格管理均能独立构建并由插件机制加载。
- 客户后台：客户工单创建、服务关联、详情、回复、关闭、重开、评价、通知列表和通知偏好已直接进入`web-customer`。
- 匿名售前：验证码创建、短期链接查看和回复、关闭、重开及评价已落在客户应用入口。
- 独立官网：公开内容列表、详情、搜索、下载和帮助页只消费公开接口；下线或删除内容显示固定的中英文“内容不存在”结果，不泄露原标题、正文或原因。
