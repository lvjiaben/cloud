# 第四阶段逐币种显式价格验证记录

> **`FB-52`部分失效声明：**逐币种明确价格和缺价失败关闭仍然有效；Provider 草稿审核与独立发布路径已经废止。下文相关测试只用于迁移对账，不能证明当前通用商品发布完成。

## 结论

`4.4`的插件内实现已经完成。一个币种只有在当前商品版本的每个启用计费规则下同时具备显式基础价、全部必需配置项价格和合法完整阶梯时才可展示或销售。价格索引只做精确币种匹配，不接受汇率、不读取其他币种兜底，也没有浮点金额入口。

统一商品发布与 Provider 草稿审核已经改为复用同一价格索引。插件后端、真实 PostgreSQL、代码质量和插件治理门禁均通过；插件新增错误消息覆盖通过。仓库级`make.cmd i18n.check`仍仅被无权修改的宿主通知预览页 6 个既有缺失键阻断，因此任务暂不勾选。

## 实现范围

- `CurrencyPricingIndex`一次接收有界计费规则和价格集合，按“计费规则 + 大写三字母币种 + 基础/选项”建立内存索引；同一版本后续检查多个币种或配置选择不再重复扫描数据库。
- 币种代码必须精确匹配`^[A-Z]{3}$`。`cny`、带空格币种、模糊代码和隐式大写转换均拒绝，防止请求与已发布快照语义不一致。
- 每个请求币种逐一检查所有计费规则的基础维度和每个必需选项维度；缺少价格返回`missing`，阶梯有缺口、重叠、续费价缺失或其他规则错误返回`invalid`。
- 后台可使用有界问题列表定位具体计费规则、基础价或选项价；公开商品列表使用`SellableCurrencies`只返回完整币种，不暴露内部缺失维度。
- `ExplicitSchedule`只返回精确命中的合法日程。请求`USD`选项价格时，即使`CNY`完整也返回不存在，不执行跨币种回退。
- 一个草稿可以在后台预览完整的`CNY`同时看到`USD`不完整；正式发布会遍历所有已配置币种，只要其中一个不完整就拒绝，不能通过隐藏问题币种绕过门禁。
- 索引在构造时深复制续费金额、阶梯上界和规则策略指针，对调用方输入和输出都提供不可变快照；外部后续修改不会静默改变可售结论或报价日程。
- 单版本最多接收 256 条启用计费规则、100,000 条启用价格、20,000 个必需选项，并在问题维度超过 100,000 前失败关闭。检查是集合内索引访问，不存在按规则、币种或选项查库的`N+1`路径。
- 金额继续只使用`int64`最小货币单位。任务范围静态检索不存在`float32`、`float64`、`REAL`、`DOUBLE PRECISION`、汇率字段或实时汇率调用。

## 任务级审查

- **已修复**：发布和 Provider 审核最初各自维护一套逐币种维度判断，未来容易发生一处允许、另一处拒绝。现二者都调用唯一的`CurrencyPricingIndex.Evaluate`，阶梯和币种完整性只有一份事实规则。
- **已修复**：索引初版直接保存 Entity 中的可空金额和边界指针，并把浅复制日程返回调用方，外部修改可能污染后续结果。现构造与读取两侧均深复制，测试已验证输入和输出突变不会改变索引。
- **已修复**：精确日程读取初版只拒绝全空白编号，会容忍前后空格并形成难以诊断的未命中。现计费规则和选项编号必须已经规范化，任何隐式修剪都拒绝。
- 已确认一个币种的畸形阶梯不会污染另一个完整币种的后台预览；但正式发布遍历所有已配置币种，因此问题不会进入公开销售。
- 已确认`SellableCurrencies`只返回完整币种，`ExplicitSchedule`不会从其他币种回退；不存在汇率参数、汇率数据源或浮点金额类型。
- 已确认最大规则、价格、选项和问题规模均有硬上限；价格在固定集合中索引，后续购物车可按版本批量装配后复用，不需要逐项数据库查询。
- 严重、外部既有阻断：`apps/lina-vben/apps/web-antd/src/views/system/message/notice-preview-modal.vue`引用的 3 个宿主键在`en-US`和`zh-CN`均缺失。当前仓库没有`.contributing`，本任务无权修改宿主目录，不能把仓库级 i18n 门禁标记为通过。

## 影响说明

- **API**：无新增 HTTP API；提供内部价格索引、后台问题投影和公开可售币种投影，后续后台/门户 API 必须复用该边界。
- **SQL**：无新增迁移；复用逐币种最小货币单位价格表及现有组合索引。
- **缓存**：无新增缓存；索引是一次请求或不可变版本快照内的内存投影，不建立跨请求权威状态。
- **数据权限**：无新增用户数据读取或动作入口；后台预览 API 落地时仍需权限与数据范围，公开 API 只能返回可售结论，不能返回后台问题明细。
- **i18n**：新增逐币种价格请求错误的中英文消息；插件覆盖通过，仓库级门禁仍受上述宿主既有问题阻断。
- **前端与 Chrome**：无前端改动，不需要页面或 Chrome 验收。
- **Git**：未提交、未暂存、未推送。
