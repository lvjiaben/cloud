## 交付结论

`4.7.a`已完成。匿名访客现在可以在独立 Portal 浏览和筛选已启用商品的当前正式版本、查看同一安全投影的详情与本地库存结论。该切片只负责发现商品，不生成报价；在配置图、兼容校验和权威价格构成进入后续切片前，页面始终明确提示“配置后确认准确价格”。

## 公开契约与安全边界

- `GET /public/catalog/products`支持服务器类型、启用分类、明确大写币种和双语名称字面前缀筛选，每页默认 12 条、最多 24 条，使用绑定全部筛选和页大小的 AES-256-GCM keyset 游标。
- `GET /public/catalog/products/{publicSlug}`按公开 slug 返回与列表相同的安全投影；非法 slug 与不存在或未发布商品均失败关闭。
- 匿名 DTO 只包含公开 slug、服务器类型、配置模式、双语分类/名称/摘要、完整可售币种、本地库存结论和库存时间，不包含数据库主键、商品/版本内部编号、成本、资源池、Provider 身份、凭据或快照指纹。
- 公开接口与后台接口使用独立控制器和中间件组；公开接口不要求登录，后台接口仍保留认证、商家上下文和精确权限门禁。
- 名称前缀中的`%`、`_`和反斜杠按字面匹配，NUL、非法枚举、非法币种、篡改游标及跨筛选游标均被拒绝。

## 数据与性能证据

- `017-catalog-public-read-indexes.sql`为公开稳定排序、服务器类型和分类筛选增加部分索引；迁移可重复执行。
- 列表固定使用一次商品集合投影、一次分类候选查询和一次币种候选查询，不随返回商品数增加数据库查询次数，也不调用 Provider。
- 商品集合在 SQL 内聚合当前版本可售币种与资源池最新本地库存；币种只有覆盖当前正式版本全部启用计费规则时才进入匿名候选，完整配置价格继续依赖不可变正式版本的统一发布门禁。
- 单页最多 24 个商品、500 个分类、64 个币种且编码后不超过 1 MiB；分类和币种候选均有独立硬上限。
- `TestCatalogFoundationMigrationPostgreSQL -count=20 -shuffle=on`在隔离 PostgreSQL schema 中连续通过，覆盖迁移幂等、索引、安全投影、库存结论和“不完整 USD 不得公开”。
