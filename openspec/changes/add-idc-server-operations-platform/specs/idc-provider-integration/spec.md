## Purpose

定义服务器资源供应商的专业能力契约、多渠道资源池与异步执行安全规则，使智简魔方公有云和后续服务器上游都能在不改核心业务模型的前提下接入。该`Provider`只属于服务器履约家族，不是平台全部商品的通用自动化接口，也不得限制后台可创建的商品种类。

## ADDED Requirements

### Requirement: 服务器 Provider 不得充当商品种类总表
服务器`Provider`契约`MUST`只负责服务器资源能力。核心商品目录`MUST NOT`因为服务器`Provider`仅声明云服务器和裸金属而拒绝创建`SSL`、`CDN`或其他商品；其他商品通过各自自动化插件接入通用商品自动化契约。

#### Scenario: 安装新的商品自动化插件
- **WHEN**商家安装并启用一个`SSL`、`CDN`或其他非服务器自动化插件
- **THEN**系统从该插件取得其接口、配置和开通能力，不要求给服务器`Provider`增加证书、域名或`CDN`动作

### Requirement: 版本化 Provider 能力契约
系统`MUST`通过版本化`Provider`契约表达认证、能力发现、容量观测、开通、查询、启动、关机、重启、暂停、恢复、续期、重置密码、控制台、重装、进入/退出救援、变配、换`IP`、快照、备份、安全组、`NAT`、虚拟介质、流量包、上游工单和终止等能力，并允许适配器逐项声明支持级别、参数约束和不支持原因。

#### Scenario: 资源池绑定适配器
- **WHEN**管理员把资源池绑定到某个适配器版本
- **THEN**系统校验商品所需能力均被支持，否则阻止发布并列出缺失能力

#### Scenario: 适配器只支持部分生命周期动作
- **WHEN**一个裸金属适配器不支持即时重装或快照恢复
- **THEN**能力发现明确返回不支持，门户与后台不展示虚假自动化入口并提供人工工单路径

#### Scenario: Provider 契约升级
- **WHEN**适配器升级到新的契约版本
- **THEN**系统先执行向后兼容与能力契约测试，再允许新任务使用该版本；已有任务仍按创建时的契约版本解释

### Requirement: 源码 Provider 的声明与启动装配
源码适配器`MUST`通过`resourcecap/spi`公开的声明期 registrar 注册版本化工厂，并由`idc-resource`在宿主路由和作业启动回调中冻结声明快照、构造最小`ProviderEnv`并把 Provider 接口显式注入资源编排；registrar 不得提供运行期服务定位或业务调用。

#### Scenario: 可信源码适配器参与启动装配
- **WHEN**所有源码插件完成`init`且宿主开始注册`resource`路由和作业
- **THEN**`resource`从不可变声明快照取得可信源码适配器工厂，校验插件依赖和契约版本，并用回调提供的宿主能力构造受限环境后注入编排服务；该通用装配能力不得作为智简魔方公有云连接器的源码兼容路径

#### Scenario: 声明键冲突或契约不兼容
- **WHEN**两个工厂使用相同`pluginID + providerID + contractVersion`，或声明了不支持的主版本
- **THEN**启动装配明确失败并报告冲突键，不按 Go `init`顺序覆盖或随机选择实现

#### Scenario: Provider 内部开关关闭
- **WHEN**管理员安全关闭一个 Provider 渠道
- **THEN**系统保留工厂声明与历史数据，但不惰性创建新客户端、不接受新任务，排空后只允许历史查询与恢复启用

### Requirement: 多渠道与资源池
系统`MUST`允许商家启用多个资源渠道并建立资源池、路由优先级、容量阈值和故障转移策略，且不判断或限制资源所有权来源。

#### Scenario: 首选资源池不可售
- **WHEN**新订单的首选资源池本地快照不可售且存在兼容备用池
- **THEN**系统按已发布路由规则选择备用池并记录选择依据

#### Scenario: 已开通服务的渠道变化
- **WHEN**管理员调整商品的新单路由
- **THEN**现有服务仍固定绑定原适配器、资源池和上游资源编号

### Requirement: 智简魔方公有云托管动态服务器连接器
首版系统`MUST`以`dynamic + managed`交付智简魔方公有云版本化`v1`服务器连接器，使用其登录令牌、`access-token`鉴权和任务查询语义，不得与魔方财务上下游接口的认证或状态语义混用。该连接器`MUST NOT`以内置源码插件交付，也`MUST NOT`保留`source + builtin`注册、目录、清单、路由或运行时兼容层。

任何依赖供应商秘密的连接器方法启用前，系统`MUST`先完成宿主管理出站代理或等价专用保密通道的设计、独立安全审查与验证。该通道`MUST`把调用绑定到精确插件、发布版本、接口实例、作用域、秘密字段、用途、方法和短时上下文，由宿主代用秘密完成上游请求；普通 owner invocation、普通请求响应载荷、`WASM`内存、日志、任务证据和数据库均`MUST NOT`取得秘密明文或可自行读取的秘密句柄。跨插件、跨接口实例或过期上下文的调用`MUST`失败关闭。

#### Scenario: 获取短期令牌
- **WHEN**托管动态连接器需要访问魔方云且当前令牌缺失或即将过期
- **THEN**宿主管理出站代理在已绑定且未过期的授权上下文内代用接口秘密获取或刷新短期令牌，只向连接器返回该方法允许的脱敏结果；秘密和令牌不得进入`WASM`内存、普通请求响应载荷、日志或任务证据

#### Scenario: 保密出站能力尚未通过安全审查
- **WHEN**托管动态连接器调用一个依赖供应商秘密的方法，但宿主管理出站代理或等价专用保密通道尚未完成独立安全审查，或无法确认明文零泄露
- **THEN**系统拒绝该方法且不得回退到源码插件、内置插件、普通网络桥或任何兼容调用路径

#### Scenario: 上游返回任务编号
- **WHEN**魔方云写操作受理并返回任务编号
- **THEN**系统保存任务编号、业务幂等键和目标资源，随后通过任务查询推进状态

#### Scenario: 只读响应夹带凭据
- **WHEN**魔方云区域、节点、镜像、存储或实例查询响应包含密码、密钥、认证串、内部路径或管理地址
- **THEN**适配器在网络响应边界按字段白名单投影，只把规范化公开事实和允许的秘密引用返回给`resource`，不得把原始响应写入日志、证据、任务载荷或数据库，并在投影后立即清除原始敏感字段

#### Scenario: 创建库存合并嵌套图与顶层存储
- **WHEN**资源拥有方同步魔方云可用于开通的计划库存
- **THEN**适配器每页只读取一次`GET /clouds/create_page`和一次`GET /stores?list_type=all&enable=1`，在同一全局上限内按字段白名单合并、去重并计算覆盖双源的内容指纹；不得按节点循环请求存储，任一来源畸形或跨页变化都拒绝发布该页

#### Scenario: 使用实例全量详情核对资源
- **WHEN**资源拥有方通过`QueryResource`核对魔方云实例状态和`IP`数量
- **THEN**适配器调用`GET /v1/clouds/:id`读取全量详情，只投影白名单状态和`IP`数量，并在投影后立即清除包含`rootpassword`、`password`、`osuser`等字段的原始详情

#### Scenario: 已验证版本不提供成本与到期能力
- **WHEN**已安装版本的管理员`v1`契约未提供上游成本、账户余额、资源到期或续期接口
- **THEN**适配器明确声明对应能力`unsupported`，系统使用商家维护的本地成本与本地服务期限，但不得伪造上游快照或到期对账

#### Scenario: 开通前收敛上游用户映射
- **WHEN**一个本地客户首次通过某个魔方云渠道开通服务且尚无已确认的渠道用户映射
- **THEN**资源拥有方先以秘密句柄提供确定性匿名用户名调用`POST /user/check`精确查重，只有响应明确返回`id=0`才能调用一次`POST /user`；创建响应携带的编号仍须由后续精确查重确认后才发布为本地映射，用户名和随机密码不得进入普通参数、日志、证据或资源数据库明文

#### Scenario: 上游用户创建结果未知
- **WHEN**`POST /user`发生超时、连接中断、租约过期或响应无法证明是否已经创建
- **THEN**资源拥有方永久禁止自动重放该次创建，只继续调用精确用户名查重；确认存在后建立映射，持续无法确认则先撤销随机密码、保留仅供操作员核对的不透明用户名句柄并进入人工处理

#### Scenario: 上游用户随机密码幂等生成
- **WHEN**并发请求或进程恢复以同一上游用户任务键申请随机密码
- **THEN**秘密拥有方在加密边界内按固定 256 位策略只生成一次并返回同一不透明句柄，业务调用方不得取得随机明文或用新的随机值碰撞同一幂等键

#### Scenario: 已认证写请求收到未授权响应
- **WHEN**任意 Provider 写请求已经发送并收到`401`
- **THEN**适配器只失效缓存令牌并把本次写入视为结果未知，不得在同一次调用中刷新令牌后重发；后续由拥有方通过只读查询或新的有证据流程决定处置

#### Scenario: 快照与备份动作取得任务证明
- **WHEN**资源拥有方向智简魔方云提交快照或备份的创建、删除或恢复动作
- **THEN**创建只接受`disk_ref + name`并在实例详情中核对磁盘唯一归属后映射为`POST /disks/:disk_ref/snapshots`，删除与恢复只接受`snapshot_ref`并在实例快照列表中核对对象唯一归属及类型后分别映射为`DELETE /snapshots/:snapshot_ref`和带当前资源`hostid`的`POST /snapshots/:snapshot_ref/restore`；归属缺失、重复、类型不符或列表畸形时不得发送写请求，只有响应携带真实`taskid`才判定已受理，空响应、普通成功标记、`401`、超时或连接歧义一律保持未知且不得自动重放

#### Scenario: 安全组关系只按实例归属和回读证据收敛
- **WHEN**资源拥有方向智简魔方云提交当前实例的安全组绑定或解绑动作
- **THEN**适配器只接受`attach + security_group_ref`或无附加字段的`detach`，绑定前读取实例的上游用户、实例类型和当前安全组，要求当前未绑定，再以`list_type=all + user + type`一次性读取该用户安全组并要求目标编号唯一且类型一致；替换已有绑定必须先显式解绑。解绑前要求实例当前存在有效绑定。绑定映射为`POST /security_groups/:security_group_ref/links`并提交`cloud + type=1`，解绑映射为`DELETE /clouds/:resource_ref/security_groups`，不得开放删除共享组、删除规则、批量或`force`字段。真实`taskid`可以证明已受理；无任务号的同步普通成功、空响应、`401`或传输歧义必须通过只读实例详情精确证明`security`达到目标关系后才能成功，否则保持未知且禁止重放写入

#### Scenario: 实例 NAT 端口转发只按实例列表和精确后置状态收敛
- **WHEN**资源拥有方向智简魔方云提交当前实例的 NAT 端口转发创建或删除动作
- **THEN**适配器创建只接受`name + external_port + internal_port + protocol`并要求外部端口明确、范围合法且不为`22/80/443`，协议只接受`tcp/udp/tcp_udp`；删除只接受正整数`nat_ref`。写前以`GET /clouds/:resource_ref/nat_acl?list_type=all`一次性读取不超过 10,000 条实例转发，创建拒绝外部端口与协议重叠，删除要求编号唯一存在。创建映射为`POST /clouds/:resource_ref/nat_acl`的`name/ext_port/int_port/protocol=1|2|3`表单，删除映射为`DELETE /nat_acl/:nat_ref?hostid=:resource_ref`；不得开放自动外部端口、NAT 网关、建站转发、批量或`force`字段。真实`taskid`可以证明已受理；无任务号的同步普通成功、空响应、`401`或传输歧义必须通过只读实例 NAT 列表精确证明目标转发唯一存在或目标编号消失后才能成功，否则保持未知且禁止重放写入

#### Scenario: ISO 虚拟介质只按实例节点归属和详情后置状态收敛
- **WHEN**资源拥有方向智简魔方云提交当前实例的 ISO 挂载或卸载动作
- **THEN**适配器只接受`mount + image_ref`或无附加字段的`unmount`。挂载前读取`GET /clouds/:resource_ref`取得`node_id`和当前`iso`，要求当前`iso=0`，再以`GET /node_isos?id=:node_id&type=node`一次读取有界分组并要求目标编号唯一；替换已有介质必须先显式卸载。卸载前要求实例当前`iso`为正整数，调用方不得提交介质编号，适配器只把当前实例编号映射为`iso`。挂载和卸载分别以`POST/DELETE /clouds/:resource_ref/iso`提交`iso=:image_ref/current_iso`，不得开放未知字段或`force`。真实`taskid`可以证明已受理；无任务号的同步普通成功、空响应、`401`或传输歧义必须通过只读实例详情精确证明`iso`达到挂载目标或卸载后的`0`才能成功，否则保持未知且禁止重放写入

#### Scenario: 临时流量包只按冻结增量和实例详情后置状态收敛
- **WHEN**资源拥有方向智简魔方云提交当前实例的临时流量增加动作
- **THEN**适配器只接受`action=add + traffic_gb`，数量必须为 1 至 1,000,000 的规范正整数。写前读取`GET /clouds/:resource_ref`并要求`traffic_quota`和`tmp_traffic`均为非负整数、`traffic_quota>0`，以`before_tmp_traffic + traffic_gb`冻结精确期望值并拒绝溢出；不得开放覆盖、减少、无限流量、未知字段或`force`。写入只发送一次`PUT /clouds/:resource_ref/temp_traffic`并提交`traffic=:traffic_gb`。真实`taskid`可以证明已受理；无任务号的同步普通成功、空响应、`401`或传输歧义必须通过只读实例详情精确证明`tmp_traffic`等于冻结期望值后才能成功，否则保持未知且禁止重放。支付、账单、权益、暂停恢复与流量重置不属于 Provider 适配器动作

#### Scenario: 魔方云管理员 v1 不承载上游工单
- **WHEN**系统发现智简魔方云管理员`v1`适配器能力或请求执行`server.upstream-ticket`
- **THEN**适配器必须以“冻结契约中没有工单端点”为原因明确返回`unsupported`且不发起任何网络请求；旧财务系统使用的财务/资源渠道登录和`/ticket/*`协议必须由工单域通过独立渠道契约接入，不得混用管理员`v1`认证、客户编号或资源编号

#### Scenario: 上游明确拒绝用户创建
- **WHEN**魔方云以已冻结的明确未接受状态拒绝用户创建
- **THEN**资源拥有方先回到只读核验并再次证明用户名仍不存在，才能在总写入预算内重新创建；任意两次创建之间都必须存在一次新的精确查重，超过预算进入人工处理

#### Scenario: 服务器业务拥有方按冻结契约执行续期
- **WHEN**长期权益冻结的服务器业务拥有方契约明确要求 Provider 确认续期，并把续费操作交给资源拥有方
- **THEN**资源拥有方按该服务器权益冻结的渠道与资源池返回确切能力证据，明确支持时创建并观察真实资源任务，缺失、未知、条件不满足或证据失效时拒绝执行；Provider 返回`unsupported`本身不能授权核心改为本地权益续费，本地期限管理必须已经由冻结插件契约明确声明

### Requirement: 写操作幂等与查询优先
所有`Provider`写操作`MUST`携带本地唯一业务幂等标识；发生超时、连接中断或未知响应后，系统必须先查询目标资源和上游任务，再决定是否重试。

#### Scenario: 开通请求响应超时
- **WHEN**系统无法确认上游是否已受理开通
- **THEN**系统标记结果未知、查询任务与资源，不直接发送第二次开通请求

### Requirement: 每操作秘密通道与安全错误边界
系统`MUST`使用当前操作绑定的不透明`secretcap.Handle`和回调限域访问传入密码等动态秘密，`Provider`请求的普通`JSON`参数不得包含明文秘密。上游返回的重装凭据、控制台令牌或密码必须在网络响应边界通过拥有方注入的安全写入器立即加密，`Provider`结果只返回拥有方签发的`Handle`和非秘密策略元数据。原始错误必须在进入日志、证据、持久化或重试决策前归一化为无自由文本的稳定错误；未识别原始错误默认为结果未知且不可直接重试。

#### Scenario: 重置密码使用当前操作秘密
- **WHEN**资源编排向适配器提交一次重置密码或重装操作
- **THEN**请求只携带当前操作授权的秘密句柄，适配器通过回调在最小时间窗内使用明文，不把它放入`Parameters`、错误、日志或证据

#### Scenario: 重装生成一次性凭据
- **WHEN**上游重装响应返回系统用户、密码和端口
- **THEN**适配器通过只能生产一次明文的安全写入回调保存完整凭据；写入失败时不返回`Handle`，回调结束后提供方缓冲必须清零并视为失效

#### Scenario: 开通使用本地生成的动态密码
- **WHEN**资源拥有方发起智简魔方云单台`Provision`
- **THEN**拥有方先生成并加密保存高强度系统密码，将宿主`secretcap`动态句柄绑定为当前操作名称固定为`password`的`SecretBinding`；适配器一次性读取并以上游`rootpass`字段提交，不把明文放入普通参数、日志、错误或证据

#### Scenario: 开通响应夹带凭据字段
- **WHEN**智简魔方云单台开通返回资源编号和任务编号，并夹带`rootpassword`、`password`、`osuser`或其他密码类字段
- **THEN**适配器丢弃响应中的全部凭据字段；只有任务与资源均成功核对后，资源拥有方才按一次性秘密交付策略向客户展示本地加密凭据，结果为`unknown`时禁止展示并进入对账或人工处理

#### Scenario: 进入与退出救援模式
- **WHEN**资源拥有方要求智简魔方云资源进入`linux`或`windows`救援模式
- **THEN**请求普通参数只携带规范化系统类型，临时密码仅通过名称为`temporary_password`的当前操作秘密句柄读取并映射为上游`temp_pass`；进入与退出操作都必须返回任务编号，缺失任务编号、超时或歧义响应保持结果未知且不得自动重放

#### Scenario: 控制台响应包含短期秘密
- **WHEN**上游控制台或`VNC`响应包含地址、令牌或密码
- **THEN**适配器把完整票据加密为带显式到期时间的短期秘密，普通`OperationResult`、`Evidence`和`Data`只能保留不透明`Handle`或非秘密摘要

#### Scenario: 适配器返回未受信错误
- **WHEN**适配器返回未声明的原始错误或包含上游响应的错误链
- **THEN**拥有方丢弃原始文本并返回结果未知、不可直接重试的通用稳定错误，原文不得进入日志、指标、证据或客户响应

### Requirement: 状态映射与证据保留
适配器`MUST`把上游状态、错误和任务进度映射为稳定业务语义，同时保留脱敏后的原始状态、响应摘要和时间线供排障与对账。没有上游任务号的未知写结果只能按当前活跃资源映射执行只读资源查询；观察快照必须晚于本次观察租约，且只有能从资源目标状态充分证明的幂等能力可以结案。任务结案与拥有方目标状态证据、脱敏 Provider 证据必须同事务持久化。

资源观察租约`MUST`把领取时的 PostgreSQL 时间保存为独立业务字段并原样返回给执行协调器；与该领取时间相等或更晚的 Provider 快照视为本次租约内的新鲜快照。系统不得使用自动维护的`updated_at`代替领取时间，否则 ORM 更新时间与返回时间之间的微小偏差会误拒绝有效观察。

#### Scenario: 领取后立即完成资源查询

- **WHEN**资源观察任务领取后立即完成`QueryResource`，且快照观察时间等于本次领取返回的`ClaimedAt`
- **THEN**系统接受该快照进入身份、目标状态和专用结果证据核对，不因自动维护的任务更新时间稍晚而拒绝

#### Scenario: 出现未知上游状态
- **WHEN**上游返回当前适配器版本未识别的状态值
- **THEN**系统不猜测成功或失败，进入未知状态并通知管理员更新映射或人工处理

#### Scenario: 上游报告取消、终止或任务进度
- **WHEN**上游任务返回取消、终止或百分比进度
- **THEN**适配器把进度限制在`0..100`并把取消、终止映射为明确终态；未知状态仍保持可对账而不得误判为终态

#### Scenario: 没有上游任务号的未知启动结果
- **WHEN**启动写请求结果未知、没有上游任务号，但当前活跃映射对应的资源在本次观察租约后被查询为运行中
- **THEN**系统把拥有方运行状态证据与脱敏 Provider 证据和任务成功状态同事务持久化，不重复启动写请求

#### Scenario: 参数型操作只有通用运行状态
- **WHEN**重装、变配、换`IP`、重启或重置密码的未知结果只能查询到资源仍在运行
- **THEN**系统不得用该通用状态猜测操作成功，任务继续对账或进入人工处理

#### Scenario: 换 IP 未返回上游任务号
- **WHEN**换`IP`写结果未知且没有上游任务号，资源详情在本次观察租约后返回白名单投影的实际`ip_count`
- **THEN**系统仅在实际数量与任务规范化参数中的期望`ip_num`精确一致时结案，并把实际数量作为不可变拥有方证据同事务保存；数量缺失或不一致时保持未知且不重复写入

#### Scenario: 开通同步或异步成功
- **WHEN**开通直接返回成功，或其上游任务被权威查询为成功，并返回唯一上游资源编号
- **THEN**资源拥有方在同一事务中建立或激活精确渠道与资源池下的资源映射、保存脱敏证据并结案任务；映射冲突或缺少资源编号时整体回滚且不得对外报告成功

### Requirement: 供应商容量只作为资源插件观测

系统`MUST`允许服务器资源插件通过后台持久任务批量刷新供应商区域、线路、规格、镜像和容量观测，记录完整观测的新鲜度。该观测只帮助管理员判断上游交付条件，`MUST NOT`写入或替代商品库存、自动创建商品草稿、改变商品发布状态，也不得让客户报价请求直接调用上游。

#### Scenario: 容量刷新部分失败

- **WHEN**一个供应商容量类别的部分分页失败、重复、跳页或返回畸形内容
- **THEN**系统保留上一份完整观测并按有界规则重试，不把半完整结果显示成当前完整容量，也不改变商品、订单或履约事实

#### Scenario: 容量分页在终页形成完整观测

- **WHEN**资源拥有方依次收到一次容量刷新的全部合法分页
- **THEN**系统持久保存固定页大小、精确下一游标和页计数并按页批量暂存白名单投影，只有终页事务可以形成新的完整观测并把上一份完整观测转为历史

#### Scenario: 管理员请求刷新供应商容量

- **WHEN**具备供应商容量刷新权限的直接员工为一个启用渠道和明确容量类别请求刷新
- **THEN**系统只创建本地异步任务，HTTP请求不等待上游，也不接受手工库存数量、Provider游标或原始载荷

#### Scenario: 管理员查看供应商容量

- **WHEN**具备供应商容量查看权限的员工按渠道、容量类别或稳定状态筛选记录
- **THEN**系统以有界列表返回渠道名称、可读状态、条目数、更新时间和可读失败原因，不返回内部编号、Provider续传游标、指纹、凭据、端点或原始错误；查看权限不能触发刷新

#### Scenario: 容量观测不能生成商品

- **WHEN**供应商返回新的区域、规格、镜像或容量内容
- **THEN**资源插件只更新自己的容量观测，不调用商品创建、商品版本、库存或发布接口；商家仍在商品管理中自行建立分类、商品和版本

### Requirement: 资源管理入口归入订单与客户产品

系统`MUST`把有明确归属的服务器、魔方云服务器、`SSL`证书和自动化任务管理放在对应订单或客户产品的管理上下文中，不再为这些能力贡献独立业务管理页面或动态管理 surface；允许通过导航快捷入口跳转到现有客户产品及接口配置上下文。本条取代原“简明的服务器与供应商工作台”对独立服务器管理和供应商运维菜单的要求。菜单收拢`MUST NOT`移除业务执行能力、改变收费或放宽精确操作权限。未安装或停用拥有方插件时相关入口`MUST`完全隐藏。

#### Scenario: 服务器与资源快捷导航

- **WHEN**员工从“服务器与资源”选择服务器管理或供应商运维
- **THEN**服务器管理进入原客户管理并提示选择客户，打开该客户详情时直接选择产品页签；供应商运维进入原供应商接口配置并选择获权运维页签
- **AND**附属资源续费待办保留，快捷入口不新建业务目录、授权或执行链路，不恢复退役全局查询，不改变订单和产品归属
- **AND**只读取当前页签所需数据，无权内容仍由原精确权限和服务端数据范围限制

#### Scenario: 员工管理客户名下服务器

- **WHEN**员工从客户产品行打开服务器管理
- **THEN**系统在当前管理抽屉中固定当前服务编号，只读取该服务器详情和关联任务，不挂载全局服务器目录或提供切换其他客户产品编号的输入；详情和执行接口继续重验员工权限与对象可见性

#### Scenario: 员工管理真实动态服务器权益

- **WHEN**客户产品来自资源拥有方的`service_entitlement`，交付类型为`entitlement`
- **THEN**管理入口按真实权益归属读取详情和已有续费能力，不把权益编号当作旧`service_instance`服务器编号，也不因移除动态独立页面而失去管理入口

#### Scenario: 管理上下文切换期间响应晚到

- **WHEN**员工关闭管理抽屉、切换产品或页签，或者操作权限被撤销，而此前请求尚未结束
- **THEN**旧上下文响应不得重新打开预览或确认弹窗，也不得覆盖后来打开的产品；执行前重新检查当前产品和操作权限，失效确认不发送执行请求

#### Scenario: 插件目录暂时读取失败

- **WHEN**客户产品页面未能读取拥有方插件的安装状态
- **THEN**页面不将读取失败缓存为永久未安装，重试成功后按当前真实安装状态恢复有权管理入口

#### Scenario: 员工管理客户名下证书

- **WHEN**员工从客户产品行打开`SSL`证书管理
- **THEN**系统仅请求当前证书详情，并在当前产品管理上下文提供已有同步、验证、取消与下载能力；每个动作仍要求对应权限，不跳转到跨客户证书列表，也不向页面暴露供应商秘密

#### Scenario: 证书状态刷新后动作不再可用

- **WHEN**刷新证书详情后，原本打开的验证方式修改动作已被当前状态撤回
- **THEN**页面收起旧操作表单，并在执行入口重新核对当前允许动作；不提交过期状态下的修改请求

#### Scenario: 服务器任务按归属分页

- **WHEN**请求携带完整的服务编号读取自动化任务
- **THEN**服务端通过资源拥有方的持久化服务归属投影，将开通任务、服务编号操作和已绑定本地资源操作关联到同一产品，在数据库中应用关联条件后再计算总数与分页；不存在归属的服务返回空结果，不退回全局任务

#### Scenario: 产品没有可证明关联的对接日志

- **WHEN**当前日志只有接口级事实，没有可证明的产品或任务归属
- **THEN**产品管理明确提示暂无可关联日志，指引员工查看供应商接口配置；不得按相同接口、相近时间或浏览器过滤把其他客户的调用日志冒充当前产品记录

### Requirement: 供应商全局运维归入接口配置

系统`MUST`把供应商概况、容量采集、健康保护和全局运维任务收拢到供应商接口配置页，不再独立贡献“供应商运维”“自动化任务队列”或“对接日志”业务页面；允许快捷菜单导航到原配置页签，不建立独立业务目录或执行链路。接口详情内的任务与日志`MUST`固定当前接口编号，由后端在计数与分页前精确过滤；配置页中的跨接口概览仍须具备原有精确权限。页面只挂载当前获权页签，不提前读取其他页签。

#### Scenario: 员工查看接口运维

- **WHEN**员工在供应商接口配置中打开运维、容量或健康页签
- **THEN**系统按原权限展示本地观测和保护状态，不改变商品库存、发布、价格或客户期限，也不因查看而调用上游写接口

#### Scenario: 仅有运维或日志权限的员工进入配置容器

- **WHEN**员工有任务、健康或调用日志权限，但没有接口配置读取权限
- **THEN**仍可进入供应商接口配置容器中的已授权能力，不读取接口配置、密钥或无权候选项；原独立入口只保留必要授权节点，不继续贡献独立业务路由

#### Scenario: 员工查看某个接口任务和日志

- **WHEN**员工打开某个供应商接口详情的操作记录或对接日志页签
- **THEN**列表请求固定该接口编号，服务端用同一接口过滤计算记录和总数；更改页面筛选不能把查询扩大为其他接口

#### Scenario: 未知结果与接管边界保持

- **WHEN**员工从接口配置或客户产品管理查看未知自动化任务并提交人工接管
- **THEN**系统继续要求已有精确权限、任务版本与不可变证据，不产生上游重放或“强制成功”行为

### Requirement: 成本与到期同步
对明确声明并返回成本、余额或到期数据的`Provider`，系统`MUST`按资源和周期保存对应上游数据及同步时间，并把成本快照用于利润分析、把到期差异用于对账，不得直接覆盖客户订单金额或本地服务期限。未提供这些数据的`Provider`必须显式返回`unsupported`，不得用配额、应用商店余额或本地期限冒充上游事实。

#### Scenario: 上游到期时间与本地不一致
- **WHEN**同步发现同一资源的上游到期时间与本地服务期限不一致
- **THEN**系统创建差异记录并要求按规则或人工核对，不静默修改任一侧

### Requirement: 上游连接安全
系统`MUST`对上游地址执行协议、主机、端口和网络白名单，限制重定向与响应大小，秘密字段必须加密、脱敏且只能由服务端访问。按商家已确认策略，插件出站`HTTPS`不验证证书链、有效期、证书主机名或历史证书指纹；不能因此放宽目标地址、鉴权、回调签名和秘密权限。

#### Scenario: 管理员配置不安全地址
- **WHEN**上游地址使用非允许协议、解析到禁止网络或请求越过允许目标
- **THEN**系统拒绝启用连接并记录安全原因

#### Scenario: 上游证书无效但目标合法
- **WHEN**上游使用自签名、过期或与地址不匹配的证书，且请求目标及鉴权满足配置
- **THEN**插件按商家策略继续建立加密连接，不将证书原因报告为接口不可用，仍禁止任意重定向

### Requirement: 健康检查与人工接管
系统`MUST`持续记录适配器认证、查询、写任务、容量观测的健康度和错误率，并在达到阈值时暂停不安全自动写入、允许人工接管。

#### Scenario: 上游连续异常
- **WHEN**写操作错误率或未知结果达到商家设定阈值
- **THEN**系统打开保护状态、停止新的自动写任务并通知管理员，但保留只读查询与对账入口

#### Scenario: 多节点共同执行写任务
- **WHEN**任一应用节点提交的写健康观察使渠道进入保护状态
- **THEN**所有节点从数据库权威状态停止领取该渠道的新写任务且不消耗任务尝试次数，并继续执行精确任务与资源对账

#### Scenario: 批量核对渠道保护状态
- **WHEN**worker 领取一个有界写任务批次
- **THEN**系统使用一次有界集合查询核对全部渠道保护状态，不按任务或渠道产生动态数据库查询

#### Scenario: 采集只读与库存健康
- **WHEN**系统实际调用 Provider 的精确任务查询、精确资源查询或容量观测分页，并已经持久化本地结果或重新调度
- **THEN**系统追加不含原始响应和错误文本的操作类别、规范结果、耗时、稳定摘要码与数据库观察时间，且只读观察不推进写熔断窗口

#### Scenario: Provider 返回认证分类失败
- **WHEN**任一写入、查询或库存调用返回规范化认证失败
- **THEN**系统在同一事务中分别记录原操作与认证两个健康维度，任一快照失败时两者都不提交

#### Scenario: 管理员查看 Provider 健康
- **WHEN**具有健康列表精确权限的后台员工打开 Provider 健康页
- **THEN**系统使用一次有界本地联表查询返回最多一百个渠道的认证、查询、写入、库存、样本窗口与保护状态，不调用 Provider 且不返回端点、凭据、原始错误或历史快照

#### Scenario: 商家更新自动写保护策略
- **WHEN**具有健康策略写权限且可访问目标渠道的后台员工按最后读取版本提交范围合法的阈值
- **THEN**系统锁定渠道与健康状态，使用乐观版本更新策略并在同一事务追加业务审计；收紧策略命中当前窗口时立即保护，审计失败时策略写入回滚

#### Scenario: 放宽策略不能绕过当前保护
- **WHEN**渠道已有尚未到期的自动写保护且员工提交更宽松阈值或更短保护时长
- **THEN**系统保留已开启状态与不早于原值的保护期限，不提供手工解锁、强制成功或直接上游写操作

#### Scenario: 管理员查看待处理 Provider 任务
- **WHEN**具有任务列表和详情精确权限的后台员工查看 Provider 任务及某一任务证据
- **THEN**系统仅以有界本地查询返回任务、渠道、最新上游绑定和最多五十条脱敏不可变证据，不调用 Provider，也不返回任务写参数、秘密绑定、凭据或原始载荷

#### Scenario: 以既有证据接管未知任务
- **WHEN**具有人工接管独立权限且可访问目标任务的直接员工，按最后读取版本、受约束原因码和属于该任务的 1—16 条既有证据提交接管
- **THEN**系统在同一事务把`accepted/running/result_unknown`任务置为封闭的`manual_takeover`、追加不可变接管记录与业务审计并使观察租约失效，且整个请求不调用 Provider

#### Scenario: 人工接管不能裁决上游结果
- **WHEN**调用方尝试通过人工接管提交成功、失败、重试、强制状态、任意操作人、自由文本或不属于目标任务的证据
- **THEN**系统拒绝请求且不修改任务，不提供任何“强制成功”或重新执行上游写入的替代入口

### Requirement: 隔离生产测试
生产上游验证`MUST`只允许作用于本次测试明确创建、带专用标识且再次核对的测试对象，禁止对既有用户或既有实例执行任何写操作。

#### Scenario: 测试目标不是本次创建对象
- **WHEN**验证流程无法证明目标资源由本次测试创建
- **THEN**系统或操作人员停止写操作，不通过名称猜测、模糊查询或批量选择继续

### Requirement: 资源池创建使用可验证事务
资源拥有方创建资源池时`MUST`在同一数据库事务内验证渠道存在且属于当前安装实例、写入资源池并留下审计结果；SQL 参数和列数`MUST`由自动化 PostgreSQL 测试覆盖。目标不存在、越权、重复或审计失败时`MUST`整体回滚并返回具体稳定错误，不得统一显示“上游配置服务暂时不可用”。

#### Scenario: 管理员为有效渠道创建资源池
- **WHEN**有权管理员为当前安装实例中可访问的渠道提交合法资源池
- **THEN**系统原子创建一条可读取资源池；不存在或不可访问的渠道不产生任何记录

### Requirement: 服务器接口统计区分实例与商品

服务器自动化接口详情`MUST`区分本系统服务器实例与本系统商品。用户可见“API 产品数量（已激活／总量）”`MUST`统计本系统通过该接口开通的服务器实例，`MUST NOT`以远端商品种类数替代；“已设置”`MUST`表示本系统使用该接口对接的商品数量。所有统计`MUST`保留当前员工的数据可见范围，不得通过数量泄露范围外记录。

#### Scenario: 管理员查看接口关联数量

- **WHEN**有权管理员查看一条服务器自动化接口
- **THEN**实例数量与商品数量分别展示，各自使用权威本地数据，不使用已加载页长度或上游商品数冒充

#### Scenario: 统计当前归属和历史版本

- **WHEN**接口有关机或已终止服务器，或商品曾经变更接口绑定
- **THEN**总台数包含当前绑定该接口的已终止服务器，已激活按权益状态判断而不按开关机状态判断
- **AND**已设置商品仅按当前使用该接口的商品去重计数，不累计旧版本或已不再使用该接口的历史绑定

### Requirement: 管理员显式读取并导入上游商品

服务器自动化接口详情`MUST`通过当前接口实例绑定的连接器有界读取可导入上游商品，并允许具备接口查看、商品创建与履约绑定权限且处于当前数据范围内的直接员工主动选择商品导入。连接器只返回白名单销售资料、上游价格和其声明的产品配置，`MUST NOT`取得商品写权限；资源拥有方`MUST NOT`直写商品私表，而应通过商品拥有方公开契约创建未上架草稿并冻结连接器、接口实例修订和声明配置。该流程与供应商容量观测完全分离，定时任务、容量刷新和列表读取`MUST NOT`自动触发导入。

#### Scenario: 管理员浏览上游商品

- **WHEN**有权管理员在服务器接口详情按关键字和页码浏览上游商品
- **THEN**系统通过当前接口实例执行一次有界只读查询，返回准确总数或连接器契约允许的有界继续信息以及可理解的商品、配置和上游价格投影
- **AND**列表不得返回凭据、秘密、任意原始载荷、内部数据库编号或需要前端逐商品补查的残缺数据

#### Scenario: 管理员选择上游商品导入

- **WHEN**有权管理员主动选择一个上游商品并提交导入
- **THEN**商品拥有方创建新的未上架草稿，自动填写连接器、当前接口实例与配置声明值，导入动作不改变当前在售版本
- **AND**管理员必须进入商品管理核对销售资料和价格后再手动发布，导入不得自动上架
- **AND**导入必须选择本地分类，名称默认采用上游名称，公开地址标识自动生成并允许随后编辑

#### Scenario: 容量观测不能触发商品导入

- **WHEN**供应商容量刷新、定时同步或只读接口详情完成
- **THEN**系统不创建、不修改任何商品或商品草稿，也不改变商品库存和销售状态

#### Scenario: 读取上游期间接口配置发生变化

- **WHEN**读取商品后，当前接口配置修订或连接器发布证据发生变化，或商品侧投影尚未与读取时的资源修订一致
- **THEN**导入失败关闭且不创建草稿；读取必须使用同一不可变修订的地址、账号和秘密引用，不能混用当前值
- **AND**读取证据由资源拥有方在进程内产生，不接受浏览器或动态插件伪造；商品拥有方在提交事务内再次核对修订与发布证据

#### Scenario: 上游配置不能完整识别

- **WHEN**上游商品未明确提供某些配置的字段映射或完整价格
- **THEN**允许创建未上架草稿并列出缺项，管理员补齐且通过既有完整性校验后才能发布
- **AND**系统不得按名称猜填处理器、内存等字段，不得把起步价或未含附加费的基础价当整机完整价格
