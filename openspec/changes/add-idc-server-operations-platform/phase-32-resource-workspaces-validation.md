# 服务器与资源入口简化验证

## 问题与结果

原菜单把日常服务器管理和供应商诊断工具平铺在同一层，名称偏技术，普通员工难以判断用途。本轮按用户授权自主简化，在现有变更中补充“简明的服务器与供应商工作台”要求。

截图中的八个入口收拢为四个：服务器管理含服务器、续费；供应商运维含概况、连接状态、操作记录、资源更新；魔方云服务器管理、SSL证书继续由各自插件提供。提示、状态和确认文字同步简化，日期不再使用大号数字组件，续费确认框在桌面完整展示费用与到期时间，在窄屏限制在窗口内。

## 本次范围与审查

依据`lina-review`审查本任务范围，来源包括任务前快照、当前差异及未跟踪文件。资源插件根目录不存在`AGENTS.md`，继续遵守项目入口与对应领域规则。

- 新增`provider-operations.vue`、`server-management.vue`；调整`resource-overview.vue`和`server-batch-renewal.vue`的说明、日期及弹窗宽度。
- 修改`idc-resource/plugin.yaml`的菜单归属、隐藏子路由及插件版本，同步中文、英文的`plugin.json`和`menu.json`。
- 新增插件内`TC015`、页面对象和菜单夹具，更新`TC002`、`TC003`、`TC004`、`TC008`、容量测试及相应页面对象。
- 同步资源偏好、相关完整要求、任务与[用途说明](../../../localdocs/server-resource-workspace-guide.md)。

工作区任务前已有后端、宿主及其他插件改动，均不纳入本轮审查或回滚。没有修改`apps/lina-core/`、`apps/lina-vben/`或根`hack/`文件；构建二进制和截图写入项目根`temp/20261011/`。

审查读取上下文、偏好、宿主边界、前端、测试、多语言、插件、文档和规范流程相关规则，核对新增完整要求及供应商资源、未知操作处理条款。未发现阻塞问题。

原六个页面保留菜单键、路径及精确权限，移动到所属工作台下作为隐藏子路由，通过公开`query_param`选择工作台和页签。工作台不新增数据授权，页签只按原查看权限显示并仅挂载当前页面；写权限继续独立判断。原续费链接可正确打开续费页签。

本轮没有新增后端接口、数据库写入、计费规则、数据范围、业务缓存或运行期依赖注入。供应商资源更新不改变商品库存和价格；未知结果不重放，人工处理不替代成功或失败裁决。

魔方云入口由`idc-zjmfcloud`的`admin.resource-operations`挂载面提供，证书入口由`yunsu-ssl`的同名插槽提供。通用工作台不硬编码两项菜单；缺少对应挂载面时测试断言不会出现虚假入口。
