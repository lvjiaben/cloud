# 第二十一阶段业务后台与客户控制台收口记录

日期：2026-09-03  
对应任务：`FB-63`至`FB-73`

## 用户反馈与根因

本轮反馈集中在“功能已经存在，但普通运营人员找不到、看不懂或无法稳定使用”。复核确认的根因不是单一页面，而是菜单按技术模块堆叠、配置入口分散、部分动态插件没有完整页面投影、后台与客户侧视觉令牌不一致，以及旧页面仍夹杂原生控件和无界内容区。

## 三轮复审

### 第一轮：菜单、流程和普通用户可理解性

- 对照用户给出的魔方财务截图逐项复核管理菜单、客户菜单、配置归属、按钮含义和失败提示。
- 修复迁移无效入口、下游渠道权限投影、工作台错误跳转和中文界面的英文菜单。
- 把分散配置收拢到系统配置，同时保留插件所有权和精确权限，没有把业务秘密或写操作移到宿主前端。

### 第二轮：组件、视觉和大数据量

- 支付、迁移和客户概览的表单、表格、弹窗迁移到 Vben/Ant 官方组件；辅助报价、外部菜单、通知公告等列表使用固定高度内部滚动。
- 扫描大字号、大圆角、大留白、双层 Card、整页无限堆叠、原生表单、可见内部字段和表格自动高度；控制台作用域统一压平装饰性圆角，头像、单选和开关等有语义的圆形控件保留。
- 复核分页上限、批量装配、服务依赖和索引；客户概览、工作台、外部菜单和支付候选均采用有界读取，没有随行数增长的前端瀑布请求或后端`N+1`。

### 第三轮：从重启后的真实运行态复验

- 正常停止并重新启动`6030`、`6031`和`6032`，未执行插件安装；关键动态插件仍为已安装、已启用、运行正常，证明普通重启不会卸载插件。
- 真实 Chromium 验证系统配置、四类支付配置、迁移、通知公告、客户外部菜单、用户中心桌面/移动双语、管理首页、运营工作台、销售营销和五类服务器连接器。
- 重新执行类型、生产构建、全量 Go 测试、Go lint、WASM 构建、i18n、插件治理、E2E 治理、服务依赖治理、空白检查和 OpenSpec 严格校验。

## 外部条件边界

- 腾讯电子签和诺诺仍按用户要求暂停；不补写未确认接口，不把本地假服务当作真实验收。
- 真实魔方云最小成本对象、真实支付商户、上游、实名、合同、发票和通知供应商的证书、回调、费用及安全联调仍需要用户提供外部条件。
- 因此任务`9.7`、`10.4`、`10.8`、`10.10`、`10.11`和`18.4`继续保持未勾选。
