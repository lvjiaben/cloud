## 规则域结论

- 身份与权限：通过。可选认证只作用于公开发现，携带无效身份不会降级为匿名成功；页面声明来自已生效快照。客户签票复用原拥有方权威身份，必须匹配认证主体，不给客户加后台角色，不接受浏览器伪造身份。后台权限、租户、有效版本、方法、路径、能力及短期票据约束不变；真实请求仍重新检查对象归属。
- 隔离与缓存：通过。不添加`allow-same-origin`，不将访问令牌传给插件页面；无新增共享缓存、新服务图或逐行身份查询。仅复用启动期已有服务引用，签票每次校验，不缓存授权结论。
- 接口与数据：首批通过。准确计数与行查询同授权、同筛选、有界查询；关联数据按页批量装配，无全量游标遍历和逐行数据库请求。费用、审批、支付和供应商契约不变。SQL仅新增索引，但生产实例部署仍是开放项。
- 组件与交互：通过。正式和独立表面使用真实Vben；灰表头、白色普通行与分页，外层背景不变，暗色及悬停选中反馈保留。身份拒绝清空旧授权数据，临时故障保留已确认页，迟到响应不得回填；未擅自转换十三个卡片式记录文件。
- 国际化：通过。保留原业务状态含义，分页使用官方语言资源；新增API描述按拥有方维护，身份帮助函数不引入用户文案。
