# 阶段 6.4 账单变换与复核调账验证

## 交付边界

- 支持同客户、同币种且未发生资金活动账单的合并，以及按完整账单明细拆分。
- 支持线下人工收款按账单入账或按客户余额入账，并保留收款证明、收款账户、业务用途和原因。
- 支持账单减免独立入账，不把减免伪装成客户付款。
- 支持逐币种、不可变版本的复核阈值；未配置币种策略时全部进入双人复核。

## 核心不变量

- 合并和拆分保留不可变来源账单、来源明细及逐项派生证据，金额必须守恒。
- 合并账单使用全部来源账单中最早的到期日；拆分只能按完整明细分组。
- 人工收款必须携带可核验的收款证明、收款账户、用途、原因和证据摘要。
- 减免借记减免费用、贷记应收账款，并与实付金额分别累计；退款上限只来自真实付款。
- 高额判断只在同一币种最小货币单位内进行，不执行隐式汇率换算。
- 待复核或已驳回申请不得改变账本、余额、付款、减免或账单状态，申请人与复核人必须不同。
- 原始幂等键不入库；同键同请求稳定重放，同键异请求拒绝。
