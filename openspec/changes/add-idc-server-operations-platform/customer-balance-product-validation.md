# 客户余额、商品价格维护与购物车反馈验收

## 本次范围与确认

本次采用`lina-feedback`定位和修复，并用`lina-review`审查本轮余额管理、商品修改草稿、金额展示、上下架、官网核价竞态和只读绑定摘要。包含本轮新增的未跟踪文件；不把工作区其他既有改动自动纳入本次完成结论。不提交、不推送、不创建PR，未修改宿主禁止路径。

用户确认支持人工充值与赠送，分开记录；扣减只用可用现金余额，余额不足拒绝，不影响冻结。用户最新明确“不用你调整价格”，本轮未调整实际商品价格、内存可售范围、历史账单或客户资金。

## 根因与实现

- 配置金额格式化失败的原回退会把整数分直接当元显示。现在使用精确十进制字符串转换，覆盖CNY、JPY、最大整数和无全局BigInt构造器情形。
- 已发布价格缺少修改入口；增加原商品修改草稿，复制配置与价格，保留原发布版本及历史交易，提供配置价格编辑、删除。有限库存的新草稿不增加存量，需商家重新确认。
- 补齐商品下架及重新上架；当前在售版本与编辑草稿明确分离，使用商品乐观版本、独立发布权限和事务审计。下架不依赖供应商在线；重新上架仍验证完整性和有效交付准入。
- 新增客户详情余额操作，人工充值复用实收链路，赠送进入独立赠送账户，扣减进入现金调账。保留精确权限、一次性意图绑定凭证、阈值独立复核及同事务审计；申请和入账阶段均重验可用余额。
- 官网旧校验只在延时任务开始时失效，会覆盖更晚的输入。现在输入即使旧请求失效，加购捕获同一份配置、周期和报价，购物车展示选择及原核价，结算展示逐项权威金额与差异。
- 历史插件证据暂不可核验时，原商品详情整页失败。现在安全绑定摘要返回未核验状态，不伪造契约能力，跳过依赖该证据的配置表单读取；配置写入、发布、恢复销售及执行门禁继续严格校验。
