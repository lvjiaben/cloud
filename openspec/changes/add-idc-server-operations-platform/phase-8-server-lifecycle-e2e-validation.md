# 第 8 阶段服务器生命周期浏览器验证记录

## 范围

本记录对应任务 `8.12` 和 `TC001-server-lifecycle.ts`。浏览器用例运行在真实的 `web-customer`、管理后台宿主和 Chromium 中；为保证测试不会创建真实订单或操作真实服务器，外部业务响应使用用例内的确定性接口替身。真实状态机、并发、数据库约束、Provider 收敛和部分回收残留资源另由第 8 阶段 PostgreSQL 回归证明，不拿浏览器替身代替后端证据。

## 2026-08-23 真实 Chromium 结果

- `TC-1a` 通过：余额付款后先展示“开通中”，权威状态刷新完成后才展示“已完成”。
- `TC-1b` 通过：客户关机后可恢复开机，页面读取最新运行状态。
- `TC-1c` 通过：重装提交后同一服务器的重启、换 IP 等写操作被锁住。
- `TC-1d` 通过：免费换 IP 经过影响确认和报价确认，旧地址被新的安全地址投影替换。
- `TC-1e` 通过：部分回收结果不明时不重发 Provider 写请求，员工选择证据和固定原因后形成不可变人工接管记录。

用例同时保留关键步骤截图，分别覆盖付款后异步开通、重装互斥和部分回收人工接管。测试文件归属资源插件，客户页面仍位于 `@lina/web-customer`，没有向 `web-antd` 写入 IDC 业务页面、接口、路由或多语言资源。

## 结论

`TC001-server-lifecycle.ts` 要求的五条用户可观察链路已经全部通过真实 Chromium。该结论只关闭任务 `8.12` 的浏览器门禁；第 8 阶段父任务仍须等待独立 PostgreSQL 回归矩阵和其余页面验证完成。
