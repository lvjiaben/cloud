# 内容管理标准页面重做验收

首轮记录对应`CONTENT-UI-1`；最新补修结论以文末`CONTENT-UI-2`章节为准。

## 范围与结果

本次按`openspec-existing`修复内容管理的自绘工作台、原生表单与弹层问题，归属`CONTENT-UI-1`。新闻、知识库和下载采用同页左侧分类、右侧`Vben Vxe`表格；官网配置提供精确权限入口，原侧栏内容页面隐藏。新建、修改和分类新增使用`Vben`表单抽屉，正文使用现有`TiptapEditor`，面板与编辑器统一圆角。

移除独立`SEO`编辑设置，仅维护标题、描述和正文。公开元数据直接使用标题和描述，稳定公开网址保持不变；三套官网安全渲染富文本，默认与简洁官网继续保留旧纯文本换行。公告类型按本轮已确认的`FB-118`独立规则处理，本次不重复领取公告迁移与通知清理目标。

同时补齐服务端页码与准确筛选总数，修复关键词查询的`PostgreSQL ESCAPE`错误、原生内容页读取压缩登录存储导致缺少认证头的问题，以及删除前详情失败时可能误用上一条内容的问题。删除回执不再重新打开墓碑记录，普通管理详情拒绝已删除内容。
