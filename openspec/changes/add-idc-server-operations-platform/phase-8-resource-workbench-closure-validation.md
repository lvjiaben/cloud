# 第 8 阶段资源与服务器工作台收口验证记录

## 范围

本记录对应任务 `8.10`。资源运营、健康和 Provider 任务后台页面都属于 `idc-resource/frontend/`，通过插件装载到管理后台；客户服务器详情与操作属于 `@lina/web-customer`。`web-antd` 仍只是 LinaPro 管理后台宿主，没有 IDC 业务源码或依赖。

## 页面闭环

- 资源运营总览同时展示资源池、库存观察时间、成本、供应商余额、到期差异、任务数量和健康摘要；读取失败时只允许刷新本地安全事实，不从浏览器直连 Provider。
- Provider 健康页面提供只读健康事实和受控策略维护；没有“手工改健康”或绕过熔断的按钮。
- Provider 任务页面提供安全证据、结果未知状态和有权限的人工接管；接管不会再次发送 Provider 写请求。
- 客户服务器详情展示运行状态、配置、IP、附属能力和当前可用动作；危险动作、报价、互斥、一次性密码和短期控制台票据均沿用服务端权威门禁。
