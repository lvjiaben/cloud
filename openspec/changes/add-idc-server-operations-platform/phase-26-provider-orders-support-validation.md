| 反馈 | 复现和根因 | 修复 |

- 接口配置继续一次批量读取秘密绑定、一次批量读取精确发布证据。回归用`100`条记录混入两条缺失记录，确认剩余`98`条独立保留，未新增逐行查询或当前版本回退。

- 测试使用隔离数据库模式或当次唯一工单编号，清理只针对测试自己创建的行。没有重置数据库、清空业务数据、重装插件、修改真实供应商配置、提交、推送或创建`PR`。
