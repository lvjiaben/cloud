# 第 8 阶段客户服务器操作验证记录

## 完成范围

本记录证明 `8.6.a`、`8.6.b` 及父任务 `8.6` 已完成，不代表客户服务器完整页面任务 `8.10`、服务器生命周期 E2E `8.12` 或第 8 阶段已经全部完成。

- 商家可以在插件后台配置是否要求客户对高风险服务器操作再次确认，默认开启。
- 高风险确认只要求客户在当前登录会话中再次点击，不要求重新输入密码，也不检查最近完整登录时间。
- 确认凭证精确绑定当前客户、当前会话、服务器、动作、参数和请求号，只能使用一次。
- 重装必须从服务所属渠道最后一个完整且新鲜的镜像快照中选择可用镜像。
- 登录端口、格式化数据盘和系统盘大小放在折叠的高级设置中；客户不填写时不会向后端发送这些参数。
- 重装成功后不会自动弹出密码。客户需要主动点击“查看新密码（仅一次）”，再次确认后才能查看；关闭后永久不能再次查看。
- 一次性密码明文不会作为普通 service 返回值传递。资源插件先原子核销领取资格，再通过回调把明文直接写入本次禁止缓存的 HTTP 响应；普通服务对象、日志、数据库、审计和缓存不保存明文。
- 控制台使用两分钟短期票据并复用同一条精确绑定、到期校验和原子核销链；页面只打开经过适配器校验的 HTTPS 控制台地址，不缓存票据。
- 同一服务器的未结束操作由 core 权威互斥；普通开机直接提交，普通关机和重启先展示影响，强制模式与重装等高风险动作执行两层明确确认。
- Provider 写入结果不明时禁止重放，资源拥有方只按本次观察租约后的权威任务或资源快照收敛；仍不能确定时保持冻结并进入独立权限、数据范围和审计保护的人工接管。

## 边界与装配

- 客户页面、接口客户端、路由和双语文案位于 `apps/lina-vben/apps/web-customer`。
- 商家安全策略页面继续位于 `idc-core/frontend`，通过插件机制装入管理后台；`web-antd` 没有 IDC 业务页面、接口、路由、状态或多语言资源。
- 一次性输出由 `idc-resource` 作为资源拥有方核销；加密秘密仍由 `idc-core` 的秘密服务拥有。
- 启动时由插件装配层创建并绑定共享秘密服务实例，再把渠道作用域访问器交给资源服务；运行时没有全局查找或临时创建另一套秘密服务。
- 镜像目录固定使用两次数据库查询：一次读取服务与渠道映射，一次读取最后完整镜像快照及其项目。查询次数不随镜像数量增加，不存在逐镜像查询。
- 本轮没有修改 SQL、DAO、DO 或 Entity；数据库规则无新增影响。

## 安全说明

所有 PostgreSQL 测试都只创建带固定前缀的随机临时 schema，并在测试结束后删除自己的 schema。Chrome 自动化使用本地页面和模拟接口。本轮没有读取、修改或触发任何现有魔方用户、实例或真实上游写操作。

## `8.7`客户附属资源页面迁移基线

`web-customer`现已直接读取后端返回的附属资源安全目录和可用动作，展示当前`IP`、磁盘、快照、备份、安全组、`NAT`与虚拟介质安全投影。页面只按服务端返回的能力动作开放按钮；目录过期或没有动作时保持只读并引导联系商家，不把换`IP`或磁盘变更混入本页面。

快照、备份、安全组、`NAT`、虚拟介质和流量写入都展示具体影响并进行普通确认；快照和备份恢复要求输入当前唯一服务编号。快照创建、备份创建和流量购买先请求服务端权威报价，再按服务端结算结果进入账单付款或直接创建免费操作。页面不计算免费额度、价格或税额，也不直接提交 Provider 编号。

当前验证包括`web-customer`类型检查、双语键检查、生产构建、API 单元测试`4/4`和 Chrome `TC015` `6/6`，并追加完成不支持动作隐藏与提交工单降级回归。最新中文桌面截图覆盖资源目录、创建表单、权威报价和恢复编号拒绝；英文手机页面无横向溢出。资源插件员工入口、逐动作权限、数据范围、员工审计和 Chrome `TC005` `5/5` 也已完成，完整证据见[服务器附属能力操作验证记录](phase-8-server-accessory-operations-validation.md)。
