# 服务器与资源快捷导航反馈验收

## 结论与范围

用户确认保留当前业务归属，仅补明显快捷入口。按`lina-feedback`纳入`RESOURCE-SHORTCUT-1`，并按`lina-review`限定审查本次导航、页签选择及关联测试，不覆盖其他对话的业务实现。

根因是已确认的资源入口收拢使独立服务器及供应商运维业务页面退役，三个配置路径又被现有菜单组织器隐藏到系统配置。续费待办移入后，这个分组因此只剩一个可见入口；插件管理过滤器仅隐藏原插件管理菜单，没有过滤资源菜单。

新增两个纯导航页面及对应清单菜单：服务器管理跳到原客户管理，显示简短指引，选择客户后直接打开该客户的产品页签；供应商运维跳到原接口配置并选中获权运维页签。快捷页面不读业务数据，跳转后移除自身临时标签，不创建全局服务器目录、独立任务或日志执行链路。原续费待办保留。供应商只加载当前页签，接口目录刷新仅在配置页签出现，避免运维入口触发无关查询。

生产改动仅在`idc-core`和`idc-resource`插件：两个清单、两个新导航组件、客户管理及详情的默认产品页签、供应商配置的初始页签和按需加载、双语菜单及一条提示资源。同步两插件中英文README、偏好13、当前规范与任务。无宿主、HTTP、数据库、缓存、数据权限或运行期DI服务图变更，无N+1请求。清单标准同步菜单仍由原宿主生命周期执行；新菜单复用原只读权限，不增加业务授权或写权限。主框架插件能力未改变，无需修改宿主README。
