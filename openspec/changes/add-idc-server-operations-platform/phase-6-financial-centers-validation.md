# 阶段 6.7 客户财务中心与后台财务工作台验证

## 交付结果

本切片已经交付独立 Portal 客户财务中心和 LinaPro 后台财务工作台。客户可以按币种查看余额、账单、账单明细、账户流水和可续费服务，并执行同币种余额支付、未发生资金活动账单合并和自动续费策略更新。后台可以查看应收概览、账单、交易和调账事实，并通过受保护流程发起人工收款、账单减免、调账复核和逐币种复核策略修改。

`idc-core`版本提升到`v0.1.46`，`idc-portal`版本提升到`v0.1.5`。插件范围后端、真实 PostgreSQL、静态检查、插件治理、前端类型检查、Vben 与 Portal 生产构建、Windows/Linux amd64 交叉构建和 OpenSpec 严格校验均已通过。

仓库级多语言门禁仍只被禁止在业务插件任务中修改的宿主通知预览页 6 个既有缺键阻断；宿主三个控制器的既有重复声明还会阻止 LinaPro 后端启动，因此本切片只确认新增 Playwright 用例能够被发现和编译，没有伪称实际浏览器链路已经运行。`6.7.a`至`6.7.c`可以勾选，`6.7.d`和顶级`6.7`继续保留未勾选。

## 客户财务边界

- 客户 API 不接收也不返回`customerNo`，所有余额、账单、流水和服务所有权都从当前活动客户主体派生。后台与客户入口使用相互独立的授权器和读模型。
- 余额按币种形成最多 128 项的固定上限集合；账单、账单明细、客户账户流水和可续费服务分别使用与筛选摘要绑定的加密 keyset 游标，拒绝篡改、跨列表复用和超长游标，不返回昂贵总数。
- HTTP 金额统一返回十进制最小货币单位字符串，前端使用`BigInt`和字符串输入保持精度；时间点统一返回 Unix 毫秒。前端不会把大金额先转换为 JavaScript`Number`。
- 余额支付复用既有原子账本结算服务，账单合并复用不可变账单派生服务，续费策略复用服务续费 owner；页面没有第二套账本、账单或续费状态机。
- 充值入口明确显示支付能力尚未接入，既不创建本地充值事实，也不直接增加余额。真实充值意图及支付确认继续由后续支付 owner 负责。

## 后台财务与危险操作

- 应收概览、账单列表/详情、交易列表/详情、调账列表/详情分别校验精确权限；授权只接受直接员工、默认商家、非模拟身份和可表示的数据范围，不用宽泛财务权限替代具体动作权限。
- 列表先按稳定时间与主键取有界候选，再对候选集合装配关联事实；账单明细和交易分录同样有硬上限，不存在前端逐行补查或随返回行数线性增长的数据库查询。
- 人工收款、账单减免、调账复核和策略修改使用独立权限。签发阶段把完整规范化预览摘要绑定到直接员工、当前会话、默认商家和高价值资金用途；执行阶段重新授权并消费一次性短期凭证，修改预览、替换员工或跨会话使用都会失败关闭。
- 人工收款只接受私有凭证对象引用、商家收款账户引用、业务用途和证据摘要，不持久化重新认证凭证或原始证明材料。页面不能直接提交已支付状态、账本交易号、余额或任意借贷分录。
- 调账继续复用既有按币种不可变策略快照和双人复核，申请人与复核人强制分离。业务事实与审计写入同一权威事务；真实 PostgreSQL 测试证明审计追加失败时人工收款申请整体回滚。

## 页面与多语言

- Portal 财务中心提供逐币种余额概览、账单、流水、续费服务、账单详情，以及余额支付、账单合并和自动续费策略动作。桌面端使用清晰的财务信息层级，小屏降级为卡片和可滚动操作区。
- Vben 财务工作台提供应收指标、账单、交易和调账四个工作区，以及人工收款、减免、复核和策略配置弹窗。按钮资格来自服务端结果与精确权限，失败态、空态和游标翻页均有明确反馈。
- 两个端的新增运行时文案均提供`zh-CN`和`en-US`镜像。423 个财务 API 元数据键均由自动化测试验证存在中文翻译；插件`en-US` API 文档保持源文案回退策略。
- Playwright 新增`TC006-financial-management.ts`，覆盖超过 JavaScript 安全整数的大金额显示、密封游标续页、人工入账先签发精确预览凭证，以及执行请求不得直接写资金状态或携带原始证据。

## 影响审查

- 数据权限：客户接口只使用活动客户主体，不暴露或接受客户编号；后台接口逐操作检查直接员工、默认商家、非模拟身份、精确权限和可表示数据范围。所有详情在授权后读取，不用资源不存在与越权差异泄露存在性。
- API：客户和后台 DTO、路由及权限标签保持分离。金额、时间、游标和固定集合上限已写入契约并有测试；详情接口一次返回所需明细，页面不进行`N+1`补查。
- 数据库：`033`只新增`CREATE INDEX IF NOT EXISTS`索引，无 Seed、Mock、软删除或破坏性变更。索引覆盖客户/后台账单、交易、调账和续费服务的所有稳定时间排序入口。
- 性能：列表硬限制候选数量并使用 keyset 游标；详情的明细或分录同样有持久化与读取硬上限；交易关联事实只对已限制候选使用集合化 LATERAL 投影。概览按最多 128 个币种聚合，不复制跨币种总额。
- 缓存：无影响。余额、账单、流水、调账、服务和权限均以 PostgreSQL 及宿主授权服务为权威源，本切片没有增加缓存或陈旧窗口。
- i18n：Portal、Vben、插件运行时消息和财务 API 文档均完成中英文治理；仓库既有 6 个宿主缺键与本切片无关。
- 开发工具与跨平台：没有修改根`Makefile`、`make.cmd`、根`hack`、CI 或治理脚本；新增 E2E 资源完全位于插件目录。Windows/Linux amd64 交叉构建均已通过。
