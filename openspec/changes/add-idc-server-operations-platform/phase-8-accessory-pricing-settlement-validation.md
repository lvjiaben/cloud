# 第八阶段服务器附属能力价格与结算验证记录

## 验证范围

本记录只覆盖`8.7.b.1`和`8.7.b.2`。对象权益、独立到期、自动续费、删除停止续费、客户与后台动作入口、确认交互、专用权限、真实前端和浏览器回归仍分别属于`8.7.b.3`、`8.7.b.4`和`8.7.c`，本轮不把这些内容视为完成。

## 已实现内容

- 商家可以按币种发布快照、备份和流量价格。快照与备份支持天、月、年周期，流量按`GB`一次收费；数据库和服务端同时限制周期及数量范围。
- 商家发布的价格就是客户最终看到并支付的含税价。系统从含税总额反算未税金额和税额，结账时不再额外加税；报价保存价格规则、税务规则、服务版本、客户版本和上游能力目录证据。
- 每台服务器的免费份数只统计当前仍存在的同类对象，并把正在执行或等待付款的创建请求计入占用，避免并发请求重复获得免费额度。
- 报价最长有效十五分钟，并且不得晚于资源拥有方目录的过期时间。报价过期、客户版本变化、服务版本变化或能力证据失效后必须重新报价。
- 免费创建直接形成可执行的本地业务操作，不创建订单、账单或虚假结算记录。
- 付费创建进入普通订单、应收账单、支付与本地`financially_settled`链路。结清前不创建资源拥有方写任务；结清后由履约消费者一次性把业务操作推进到可执行状态。
- 同一个幂等键只恢复同一报价或结账结果；相同报价不能生成第二个附属操作。结算事件重复消费只核对既有零服务器履约收据，不重复创建资源任务。
- 附属类型的中英文快照名称由插件数据库字典提供，生产`Go`代码没有硬编码中文。接口文档英文源文本和`zh-CN`翻译资源已同步。

## 边界与安全检查

- 本轮没有调用真实智简魔方写接口，数据库回归只使用测试替身验证任务创建与收敛。
- 本轮没有修改`web-antd`、`web-customer`或任何官网源码。
- 附属结算不创建服务器库存预留或服务器履约单元，只写数量为零的财务交付收据；普通服务器购买和续费链路保持原语义。
- 报价和结账始终从当前登录客户对应的客户主体与服务器归属校验，不接受浏览器提交价格、税额、客户版本或服务版本。
- 缓存无影响：权威价格、免费额度、订单、账单和结算状态均直接读取数据库或本地不可变快照，没有新增缓存。
- 开发工具跨平台无代码影响：本轮没有修改`Makefile`、`make.cmd`或`hack/`。Windows 当前没有 GNU `make`，`make lint`会落到尚未实现`lint`子命令的`make.cmd`；已执行 Makefile 背后的同一条`linactl lint.go`并通过，未修改工具入口绕过。

## 生成器事故修复
