# 第九阶段安全组关系适配器验证记录

## 完成范围

本记录对应子任务`9.4.d`，只闭环`idc-zjmfcloud`把安全组绑定到当前实例和从当前实例解绑的适配器契约。安全组目录、创建、规则管理、共享引用影响预览、客户自助、后台动作入口和资源拥有方业务编排尚未完成，父任务`9.4`继续保持未完成。

旧魔方财务连接器证明绑定使用`POST /security_groups/:id/links`并提交`cloud + type=1`，安全组候选从实例详情的`user_id/type`派生并通过`GET /security_groups?list_type=all&user=:user_id&type=:type`读取。已安装`3.9.14 beta`公开前端证明解绑使用`DELETE /clouds/:id/security_groups`。这些证据不能证明通用成功标记等价于任务受理，因此同步结果必须额外回读实例状态。

## 实现边界

- `server.security-group`声明为`conditional`，只公开`action=attach/detach`和条件使用的`security_group_ref`。绑定只接受两个字段，解绑只接受`action`；未知字段、非法编号、批量和`force`在认证前拒绝。
- 绑定前固定读取一次`GET /clouds/:resource_ref`，要求实例具有有效上游`user_id`、`type`且当前`security=0`；随后固定读取一次该用户及实例类型的安全组全集，候选数最多 10,000，要求目标编号唯一且类型一致。任何已有绑定都必须先显式解绑；目标缺失、重复、类型不符或响应畸形都不发送写请求。
- 解绑前固定读取一次实例详情并要求当前`security`为正整数；未绑定实例不会发送写请求。适配器不接受调用方提交待解绑组编号，避免陈旧编号越过当前关系事实。
- 绑定只发送一次`POST /security_groups/:security_group_ref/links`，表单固定为`cloud=:resource_ref&type=1`；解绑只发送一次`DELETE /clouds/:resource_ref/security_groups`，不发送请求体参数。
- 写响应携带真实`taskid/task_id`时返回`accepted`。没有任务号的 2xx 普通成功或空响应、`401`及传输歧义都只读回查一次当前实例；仅当`security`精确等于绑定目标或解绑后的`0`时返回`succeeded`，否则返回不可重试的结果未知。明确的`400/403/404/405`保持确定失败，不用旧状态覆盖上游拒绝。
- 每个调用最多一次写入。写`401`只失效旧令牌，回读可以安全刷新令牌但不得重放写入；任何响应秘密字段都会随原始响应清理，不进入标准化结果、日志或证据。
- 删除用户级共享安全组、删除规则、规则编辑和批量操作可能影响多个实例，本切片明确不开放，也不以通用能力参数伪装支持。

## 测试覆盖

受控 TLS 假服务覆盖绑定与解绑的精确方法、路径、查询和表单，验证写前实例/安全组读取次数、任务号受理和同步结果回读。失败路径覆盖未知动作、缺少或多余字段、`force`、已经绑定目标、试图隐式替换其他绑定、未绑定解绑、目标缺失、重复和类型不符；覆盖普通成功但目标未达成时保持未知、写`401`只写一次并以新令牌安全回读、明确`400`拒绝不回读旧状态。测试全部自包含、可乱序运行，未访问生产 Provider。

## 规则域结论

- 架构与插件：实现闭环在源码 Provider 适配器，只消费`resourcecap`既有公开契约；没有宿主修改、新抽象或服务定位。
- 性能：绑定固定两次写前读取、一次写入，以及无任务号时一次回读；解绑固定一次写前读取、一次写入，以及无任务号时一次回读。调用次数不随安全组数量增长，候选数组有 10,000 硬上限，不存在逐项远程`N+1`。
- 数据权限：本切片没有新增公开 HTTP 入口。`ResourceRef`仍必须由资源拥有方按本地资源、渠道和资源池映射后传入；客户/后台权限和数据范围入口尚未实现，不能因适配器支持而绕过拥有方授权。
- API、数据库、缓存、前端、E2E、开发工具与运行时`i18n`：无影响。没有路由、DTO、SQL、缓存、页面、运行时文案、脚本或工具变化；中英文技术`README`同步维护。
- 安全：没有共享对象删除、规则删除、批量或强制路径；歧义写绝不重放，只有任务号或精确目标状态回读可收敛。
