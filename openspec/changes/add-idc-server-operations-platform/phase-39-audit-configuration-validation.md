# 审计调用修复与自动化配置入口验证

## 反馈与根因

用户反馈多个接口报审计错误，并找不到服务器供应商接口。按已有活跃变更处理。本轮只修改业务插件及测试、验证记录，未修改宿主。

- 多个业务调用缺少审计要求的前态快照，事务因此回滚。创建动作记录不存在前态，更新动作读取实际旧数据。
- 部分调用把发布、提交等领域状态写入审计结果，违反审计的四类结果约束。领域状态保留在业务数据及快照中，审计结果使用合法值；外部调用的失败与结果未知继续区分。
- 批量到期提醒的通知与审计缺少共同事务，已补齐。信用还款幂等回放复用原审计，不重复用变更后的前态写同一事件。
- 服务器配置已经合并到系统配置中心，并非独立侧栏入口。真实中文路径为“系统设置 → 系统配置 → 自动化接口 → 进入配置 → 服务器接口 → 新增接口”。商品交付绑定仍在商品编辑中设置。

- `TC048b`：真实商品附加商品保存成功，数据库版本递增、不可变审计入库；第二次更新关系成功，旧版本请求被拒绝且不覆盖关系、不重复增加审计。固件随机隔离并自行清理。
- `catalog_product_addons_postgres_test.go`验证审计失败整体回滚、成功前后快照、版本冲突及跨租户目标拒绝。
- 定向真实数据库回归通过，覆盖配置修订、财务命令、信用命令及还款重放、财务操作、审计生命周期、营销券批次和新人限制、服务器附加商品链路与流量包、服务商配置和供应商绑定。

## 任务级审查

使用`lina-review`限定本轮审计调用、测试与配置入口核实。保持公共审计严格校验，没有绕过权限、完整性或事务失败关闭。未新增运行期依赖、公开接口或数据库迁移，未引入逐行远程调用。附加商品目标增加租户约束，既有操作权限保持不变。

触发`E2E`质量审查：配置入口与原保存报错分别有真实页面路径和数据库结果断言；旧版本失败及审计失败回滚分别由页面测试和数据库测试覆盖。截图已查看，中文文案可读；新增接口等待进入动画结束后截图，其他产品接口等待真实列表响应并断言成功，测试固件退出前等待代理请求结束。

当前定向验证未发现阻塞问题。全量数据库并发测试曾出现共享内存耗尽和不相关旧固件失败，不能视为全量测试通过；本轮采用串行定向回归。未使用真实供应商凭据创建第三方资源，不宣称外部供应商联调完成。

宿主基线对比共`3489`个文件，变化为`0`，证据为`temp/20261015/audit-host-check.json`。本轮未提交、推送或归档。
