## 三轮同类问题复审

### 第一轮：信息架构、文案与普通用户流程

- 逐项检查管理端菜单、客户侧菜单、工作台职责、系统配置入口、按钮和状态名称。
- 移除客户管理页重复的大标题说明块；隐藏运营工作台和空目录；修正财务、批量操作及工单设置中的可见英文和内部枚举。
- 系统配置保留各业务插件自己的权限与数据所有权，只在一个页面内完成分类和抽屉装配，没有把秘密或业务写操作迁入宿主。

### 第二轮：视觉、表格高度与大数据量

- 真实浏览器测得供应商容量表格容器为 296 像素、表体 252 像素，五行均为 44 像素；上游渠道健康表格容器为 389 像素、表体 335 像素，前十行均为 78 像素。
- 财务工作台在“账本流水”“调账复核”“账单”之间连续切换四轮，三个页签可见表格高度始终为 419 像素，文档滚动高度始终为 808 像素，没有增长。
- 通知公告表格高度为 480 像素；新增抽屉宽 860 像素、无可见遮罩、保存按钮可见；工单工作台卡片内容区内边距为 0。
- 管理端与客户侧开关的滑块及`::before`伪元素圆角均为 9999 像素，不再出现空白方块。

### 第三轮：重启、真实页面与数据治理

- 客户侧栏宽度为 204 像素，五个分组全部展开，折叠箭头数量为零且不存在横向溢出。
- 系统配置在当前页面打开大抽屉，自动化接口只提供“服务器接口”和“其他产品接口”两个分类，不再出现两个同义菜单。
- 分析页显示真实待办和资金聚合；工作台只显示八个快捷入口。空数据仍使用真实空态，不伪造外部成功。
- 在当前 PostgreSQL 对八个变更 SQL 文件连续执行两轮事务验证，全部通过；动态插件在真实进程重启后保持安装启用，`TC019`两项真实 Chromium 用例通过。
