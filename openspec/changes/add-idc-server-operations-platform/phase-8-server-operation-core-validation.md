# 服务器操作核心收敛验证记录

## 本次完成范围

- `core`新增普通服务器操作执行明细，只保存动作参数、秘密不透明引用、资源任务引用和脱敏证据，不保存密码、控制台票据或重装凭据明文。
- 同一服务在`ready/pending/running/result_unknown`期间只能存在一个活动操作；相同幂等请求返回原操作，改变动作或参数不能借重试创建第二个任务。
- 权益`active/grace`共用已确认的运行状态矩阵：运行中允许关机、重启、改密、控制台和重装；已关机允许开机、改密和重装；暂停、终止中、未知或其他过渡态拒绝。
- 主节点每十秒有界领取最多二十项工作，通过冻结的`core → resource`契约创建或查询任务；资源明确成功、失败、结果未知和人工接管分别投影到业务操作、运行状态和 Provider 任务状态。
- 结果未知只继续读取原资源任务，不能创建新的 Provider 写请求。开关机或重装的真实运行结果无法确认时运行状态进入`unknown`；重启、改密和控制台不使用“仍在运行”冒充动作成功。
- `resource`向`core`返回的控制台结果只能是带到期时间的`consoleTicket`短期句柄，重装结果只能是`generatedCredential`一次性句柄；其他动作不得夹带秘密输出。

## 验证结果

- `core`契约、状态矩阵和托管作业单元测试连续二十轮通过。
- `resource`普通操作资源源单元测试连续二十轮通过。
- 隔离 PostgreSQL 中迁移重复执行通过；新增约束、部分唯一索引、不可变意图触发器和双语业务操作字典生效。
- `core`创建、相同请求重放、冲突操作拒绝、资源同步成功和三维状态收敛在随机隔离 schema 连续十轮通过；在修复数据库时间微秒精度比较后，同链路另有连续二十轮通过记录。
- `resource`任务创建、陈旧能力后精确重放、改变意图冲突、任务完成读取以及控制台短期秘密输出投影在随机隔离 schema 连续十轮通过。

## 未完成边界

- 客户和员工 HTTP 接口、动作专用权限、确认/二次确认、商家高风险重新登录策略、页面、短期票据领取、一次性凭据揭示和完整浏览器 E2E 仍在`8.5/8.6/8.10`父任务内，不能据此勾选父任务。
- 换`IP`和变配的商家发布规则、免费/收费分流、权威报价及结清仍未进入本次核心免费操作切片。
- 未对任何现有魔方用户或实例发送写请求；可信 HTTPS 和专用隔离对象就绪前，生产写验证继续阻断。
