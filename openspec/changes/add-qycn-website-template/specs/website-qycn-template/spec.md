## Purpose

提供参照群英官网视觉的独立可安装官网模板，通过现有公开接口展示平台品牌、商品及资讯，在缺少业务能力时提供清楚标识的静态内容，兼顾移动端访问与独立构建交付。

## ADDED Requirements

### Requirement: 官网结构与响应式交互

模板 MUST 提供轮播、产品分类、服务优势、节点展示、资讯、注册入口及页脚，并提供产品、数据中心、服务方案、内容与关于联系页面。导航、轮播和分类在桌面、键盘及移动端可操作。

#### Scenario: 浏览官网

- **WHEN** 访客打开首页并切换轮播、分类和导航
- **THEN** 对应内容正确切换，链接进入实际页面，窄屏不出现横向溢出

#### Scenario: 默认菜单和自动轮播

- **WHEN** 公开品牌未配置导航，或访客打开首页后将鼠标停在横幅上
- **THEN** 模板保留产品及其他默认入口，产品子项来自目录接口且不受返回顺序影响；首页每`6.5`秒循环切换，不显示播放或暂停按钮，减少动态效果时不使用过渡动画

#### Scenario: 小屏桌面英文导航

- **WHEN** 访客在手机或小屏桌面使用英文菜单
- **THEN** 导航按可用宽度折叠，分类、登录和注册入口可见且页面没有横向溢出

#### Scenario: 手机访问客户中心

- **WHEN** 手机访客展开主菜单
- **THEN** 登录、注册和控制台入口可见并指向配置的客户中心，关闭菜单后恢复折叠状态

### Requirement: 公开数据与静态内容的边界

模板 MUST 接入公开品牌配置、导航、商品目录及内容接口，分页筛选由服务端处理；真实商品配置、购物车、核价及订单确认位于官网；认证和账单付款进入已配置客户中心。真实产品分类与商品不得用静态卡片代替；未提供的非交易内容采用标识为示例的静态展示，不伪造购买或提交结果。

#### Scenario: 读取真实数据

- **WHEN** 公开接口成功返回品牌、导航、商品及内容
- **THEN** 页面显示这些数据并保留配置导航，商品链接携带真实公开标识，详情显示对应内容

#### Scenario: 公开接口失败

- **WHEN** 商品或内容接口失败
- **THEN** 对应栏目显示可重试错误，不以假商品或假资讯冒充成功结果

#### Scenario: 浏览静态服务

- **WHEN** 访客进入未对接的服务或节点展示
- **THEN** 可浏览示例说明，操作仅进入真实咨询入口或本地说明，不创建订单

#### Scenario: 通过本地预览下载公开文件

- **WHEN** 公开下载返回文件名或范围响应
- **THEN** 预览代理保留文件名和范围语义，不转发访客的认证头或会话

#### Scenario: 下载停滞或响应失败

- **WHEN** 票据请求成功后文件响应失败、断流或持续没有数据
- **THEN** 页面保留文章及可重试错误，不能保存错误响应；浏览器与预览代理只按空闲时间取消，持续传输不受固定总时限限制

#### Scenario: 匿名文件读取

- **WHEN** 浏览器已有同源会话且访客发起公开下载
- **THEN** 文件请求不携带会话、不跟随重定向，拒绝非字符串或路径形式的伪造票据，传输中禁止重复提交

### Requirement: 独立动态插件交付

模板 MUST 通过现有官网扩展点和公开资源协议交付，声明的页面均可访问，自带构建依赖及动态桥源码，在仓库外可生成正式`WASM`。公共资料和独立设置采用现有官网配置。

#### Scenario: 独立构建

- **WHEN** 在仓库外安装锁定依赖并执行打包
- **THEN** 生成包含页面资源和合法模板声明的`WASM`，无需宿主源码

#### Scenario: 重建已有产物

- **WHEN** 生成目录仍有已删除的旧资源，或清单声明未实现的页面
- **THEN** 重建移除旧资源，未实现的声明使构建失败

### Requirement: 双语与可配置品牌

模板 MUST 提供中文和英文切换，跨页保留语言并按对应语言选择公开双语字段。Logo、网站名称、公司名称、网站备案号及公安备案号 MUST 使用统一官网公共配置；合作伙伴 MUST 由模板独立配置维护，空配置不展示虚构品牌。

#### Scenario: 品牌加载首屏

- **WHEN** 页面刷新且品牌接口尚未返回
- **THEN** 静态 HTML 与运行页面都不展示示例 Logo、公司或网站名称，取得配置后再渲染实际品牌

#### Scenario: 修改公共资料

- **WHEN** 管理员保存 Logo、网站名称、公司和备案资料
- **THEN** 官网使用保存后的资料，版权公司与网站名称分别读取，安全展示备案链接

#### Scenario: 切换英文

- **WHEN** 访客选择 English 并切换页面
- **THEN** 导航、按钮、状态、静态介绍与商品双语字段使用英文，刷新保留选择

### Requirement: 官网购买闭环

模板 MUST 以已发布购买配置和账户交易接口完成开通选购，不读取其他插件私有状态；服务端核价与订单为唯一交易依据，重复提交使用同一幂等键。认证桥 MUST 校验配置来源、窗口来源及随机 nonce，凭据不得进入 URL 或持久化到前端存储。

#### Scenario: 购买已发布商品

- **WHEN** 客户从产品分类选择商品并填写配置
- **THEN** 在官网取得服务端配置和报价，加购前完成登录并恢复选配，再加入账户购物车核价确认订单，账单付款进入客户中心

#### Scenario: 同页直接选配和自动报价

- **WHEN** 客户打开商品或修改选项
- **THEN** 选项和价格汇总同时展示，默认配置及有效修改自动从服务端核价；留空的可选数字采用套餐默认，旧请求不能覆盖新配置报价，登录状态检测不得阻塞公开报价，成功后可直接加入购物车并去结算

#### Scenario: 选配响应速度

- **WHEN** 客户修改有效配置并等待报价
- **THEN** 实际验收环境修改本地配置后在一秒内显示正确价格并恢复加购；前端并行请求评估和报价，同值输入与失焦不重复核价；只有评估有效且报价对应规范化后的配置时才展示价格与允许加购，服务端调整配置时重新取得对应报价

#### Scenario: 选配或报价失败

- **WHEN** 配置或报价接口失败、超时或必填项缺失
- **THEN** 页面提供可见的配置提示或重试入口，不保留可提交的旧价格，也不永久停留于加载状态

#### Scenario: 购物车过期或身份改变

- **WHEN** 购物车版本冲突、报价过期或账户切换
- **THEN** 页面清除失效报价并重新取得当前身份数据，不复用前一账户的购物车或订单

#### Scenario: 选配页真实分类与商品
- **WHEN** 客户进入选配页或切换左侧分类
- **THEN** 侧栏通过公开目录接口展示真实分类和对应商品，支持分页、选中态及中英文；手机端移到表单上方，无横向溢出
- **AND** 慢目录或目录失败不阻塞表单与核价，提供重试和空结果提示

#### Scenario: 手机返回顶部与底部购买操作不重叠
- **WHEN** 客户在窄屏选配页底部点击返回顶部，或设备安全区改变底部购买栏高度
- **THEN** 返回顶部按钮保持在购买栏上方并正常滚动，不能误发加购请求或改变购物车，购买按钮仍可正常加购

#### Scenario: 未登录加购

- **WHEN** 未登录用户点击加入购物车或会话过期
- **THEN** 写入购物车前进入受信任客户认证，保留配置、币种和周期；回跳恢复但不自动提交，失败取消不能丢配置或重复加购

#### Scenario: 购物车参考布局与修改

- **WHEN** 客户查看购物车或修改数量与配置
- **THEN** 展示商品配置卡、周期、数量、编辑删除、服务端小计和固定底部结算栏；数量与配置通过拥有方原子更新，验证当前客户及购物车/条目双版本，并使旧报价失效；重新核价成功才能下单
- **AND** 配置价格选择与周期通过有界批量投影返回，金额不得前端推算，失效商品、报价失败、身份切换和手机布局均可恢复操作
