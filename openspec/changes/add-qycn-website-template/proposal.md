# 群英风格独立官网插件

## Why

用户要求参照`https://www.qycn.com/index.html`新建独立官网插件，已有功能对接项目数据，尚无能力的部分采用静态示例内容。

## What Changes

- 新增`website-qycn`托管动态插件，复现参考站的轮播、产品分类、服务优势、节点展示、资讯和页脚布局，并适配移动端。
- 接入公开品牌、导航、商品目录与内容接口；商品配置、购物车与订单确认留在官网，登录注册与付款进入客户中心。
- 节点及企业介绍保留静态示例；产品分类和商品来自接口，合作伙伴由模板配置维护。
- 提供独立打包、预览、自动化验证和双语开发说明。

## Capabilities

### New Capabilities

- `website-qycn-template`：群英风格官网展示、真实公开数据接入与独立交付。

### Modified Capabilities

官网公共配置增加 ICP 与公安备案号及查询链接，公开品牌补齐公司名称和备案投影；加购校验接受无配置项商品的空数组。

## Impact

主要代码位于`apps/lina-plugins/website-qycn/`，公共配置扩展位于`idc-portal`，空配置加购校验位于`idc-core`，记录限于本变更及官网视觉偏好主题；不修改宿主。插件为中英文、平台级、无私有数据表的独立动态模板。公开接口按页限量查询，无逐商品补价请求。
