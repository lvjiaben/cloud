# 设计

## Context

现有`website-html`已经提供独立动态模板桥、公开资源打包和无框架页面范例。官网配置由`idc-portal`拥有，商品及内容由`idc-core`公开接口提供。本次采用用户最新指定的参考站视觉，不改变其他官网模板。

## Goals / Non-Goals

交付可独立构建的中英文官网插件，覆盖参考站首页栏目与可访问的二级页面。官网承接配置、购物车、核价和订单确认，复用拥有方接口且不新增数据库表；不改宿主，不自动切换当前展示模板。

## Decisions

- 使用原生模块化`HTML/CSS/JavaScript`多页应用，所有资源随插件打包，避免为展示站复制大型应用依赖。页面生成脚本只负责公共文档壳和路由产物，运行时不依赖源码仓库。
- 复用`website-html`的标准库动态描述桥和公开打包协议，插件标识独立。展示数据走匿名接口，购买使用现有公开与账户契约，客户中心地址来自可信网关注入。
- 中英文、平台级托管动态插件；语言通过 URL 和本地偏好保持，后端双语投影按当前语言展示，不建私有数据表。
- 品牌、Logo、公司名、联系方式及 ICP/公安备案采用公共配置；合作伙伴和中英文首页标题归当前模板配置，空配置不伪造。导航采用公开配置；存在已保存导航时严格遵循其层级和顺序，包括空数组。独立预览无配置时使用样板导航。
- 商品列表按游标分页，分类和名称筛选传服务端；不逐项补查报价。分类和商品全部由公开目录提供；真实商品在官网配置并加入购物车，登录与付款进入客户中心。接口故障显示重试，不能伪装成真实数据。
- 参考站栏目顺序、蓝色强调、矩形卡片与深色服务区保持一致；装饰图形本地维护，品牌和实际联系方式可替换。节点规模与未对接服务使用明确的示例说明。
- 自动化使用插件本地`Playwright`固件和页面对象，保持仓库外可执行，按`lina-e2e`编号管理。

## Risks / Trade-offs

- 静态发布不具备服务端实时内容渲染：输出每页标题、描述和可抓取基础内容；不宣称`SSR`。
- 参考站含特定品牌与运营承诺：使用当前平台品牌并明确示例数据，不复制第三方联系方式或备案资质。
- 真实接口可能不可用：栏目分别失败和重试，静态页面仍可访问；不影响当前运行实例。

## Migration Plan

安装依赖、构建和打包后，管理员可按现有插件安装流程上传`website-qycn.wasm`，在官网配置中选择。回退时选择原模板，不删除已有配置。

## 购买与认证边界

客户中心登录桥通过受信任来源、窗口及随机 nonce 返回会话，凭据只在页面内存保存。一次性交接使用 HttpOnly 句柄；公开内容和下载保持匿名。报价由服务端生成，账号变化使旧报价失效；订单重试复用报价对应的幂等键，过期报价要求重新核价。无额外配置项商品允许空 values 数组，必填配置仍由拥有方按版本验证。

## 购物车参考反馈设计（2026-10-23）

官网展示适配沿用群英导航与小白云购物车参考，以商品配置卡、固定底部结算栏、结算详情呈现现有整车购买流程。新增接口归`idc-core`交易拥有方，`PUT account/commerce/cart-items/{cartItemNo}`验证客户归属和购物车/条目双版本；可只改数量，也可通过现有公开配置解析器替换完整配置，原子写入并清除最新报价。重复同值且版本匹配时不写入；陈旧请求失败，旧报价不得下单。无新数据库表或运行期依赖。

购物车配置展示通过拥有方的一次集合查询，将已持久化价格选择与计费周期投影至至多100项，每项至多128个价格选择；不解析插件，不循环补查。浏览器草稿补充非价格配置展示及编辑恢复，不成为金额依据。优惠使用现有账户资产/领取/报价规则，不新增叠加规则；保持整车结算。

官网加购前认证并在本会话保存选配，登录回跳不自动提交。写入重试保留原预期版本避免重复追加；订单重试继续使用相同报价幂等键。支付候选只读取既有账户余额与渠道接口；选择通过查询参数带入账单，客户中心仅预选当前允许方式并再次要求确认。缺失支付插件时降级至账单选择，不构造支付成功。没有改变宿主、权限归属、账单或支付真相；不执行真实订单与付款验收。
