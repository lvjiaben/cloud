# 货币配置验收与范围审查

## 实现边界

本次只审查`idc-core`货币配置及系统配置、商品价格候选、协助下单和网页/API新报价联动。魔方源码仅作流程参考，未迁移其业务规则。工作区其他变更不纳入本次完成结论。

管理入口为“系统设置 → 系统配置 → 支付与货币 → 货币配置”。默认人民币，支持多币种独立定价和结算，不自动换汇。配置不提供删除，停用保留历史；商品该币种价格和支付渠道支持仍需分别配置。

## 根因及修正

原系统缺少货币管理，协助下单只取商户默认币种。新增插件表及管理接口，保留原有商品和账务币种，并给新报价绑定启用状态校验。

真实页面验收发现并修复两处问题：客户端模块顶层计算接口地址引发循环初始化错误；新增货币审计传空快照导致保存失败。接口地址改为请求时计算，审计使用有效空对象且失败时事务回滚。

## 审查结论

使用`lina-review`限定范围审查，涉及行为、权限和界面变化，已触发`E2E`质量审查。币种管理授权先于数据访问，无逐行查询；写入串行商户锁和版本检查；配置、默认值及审计同事务；读启用状态不缓存。网页与开放API分别绑定货币准入；自动续费及历史支付保留原规则。

未发现本次货币能力的阻塞问题。该结论不代表整个后台已完成成品验收：客户详情的订单/账单直达、订单异常到开通处理入口等已发现衔接问题仍需后续闭环。公开商品目录仍可包含历史定价币种，停用币种的新报价会被权威校验拒绝。

宿主源码未修改。宿主哈希基线检测到测试运行器更新了忽略产物`hack/tests/playwright-report/index.html`与`hack/tests/temp/storage-state/admin.json`，没有宿主源码变化；后续测试使用行输出，将截图和运行报告写入`temp/`。
