## Context

货币属于单商户全局配置，不属于客户或组织数据。默认人民币，支持多个币种，不自动换汇。

## Goals / Non-Goals

统一管理和新报价校验，不重算历史交易、不引入汇率、不改宿主。

## Decisions

插件自有配置表以币种代码唯一，保留停用和逻辑删除记录，删除仅移除配置并阻止新交易；默认值继续由商户资料持有。写操作串行锁商户，乐观版本保护每行，事务内写审计。升级初始化保留现有商品与交易币种。管理接口仅允许直接员工、指定权限及全商户数据范围；公开候选只展示启用币种，不含客户或账务数据。读取有固定300条上限和编号分页，无逐行查询，不缓存货币启用状态。后台用标准表格和小弹窗，移除商品定价和支付方式快捷入口；接口及文案维护双语。

## Risks / Trade-offs

停用只阻止新报价，历史订单及资金仍按原币种处理；支付方式只支持部分币种，不能把货币启用误认为支付通道已经可用。

## Migration Plan

幂等新增配置表并从既有商品、账单、账户及默认币种初始化；可重复执行不改现有配置。
