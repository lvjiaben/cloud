# 安装准备设计

## Context

宿主边界禁止修改。业务插件必须在启动时收到安装级独立密钥；以前这些材料存在开发临时目录，首次拉取并不存在。

## Decisions

- 工具归属`idc-compliance/hack/tools/installation`，使用标准库跨平台操作，调用既有公开命令。
- 默认私有目录为已忽略的`.site-runtime/installation`，生成独立随机`JWT`与`IDC`密钥。合规实例认证复用网关已有公开生成工具。
- 首次创建必须排他写入，已有文件严格校验并复用。损坏、公开权限、符号链接与不完整网关文件拒绝覆盖。
- 子进程环境保留显式部署输入；默认值只用于缺失项，不把秘密输出到日志或写入源码配置。
- 工具只准备与转发操作，不修改宿主领域数据、插件状态或供应商凭据。插件安装回归使用隔离数据库。

## Risks

私有目录丢失会使旧加密资料不可恢复，因此说明要求长期挂载并备份。`Windows`文件访问控制由部署者限制账户权限；默认入口不依赖平台专属命令。

## Validation

覆盖首次生成、重启复用、不同安装独立、损坏不覆盖、显式环境保留、私有文件与部分安装拒绝；隔离数据库启动后安装启用动态插件，记录实际错误并修复。
