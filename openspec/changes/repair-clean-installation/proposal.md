# 首次安装可启动

## Why

空白隔离库的宿主及全部插件迁移通过，但首次运行缺少安装实例安全材料，业务路由注册立即退出。开发环境依靠未纳入交付的临时文件，拉取源码无法复现可用环境。

## What Changes

- 插件提供跨平台安装准备入口，生成、校验并持久保存实例密钥，启动时复用。
- 通过宿主已有命令与环境变量启动、构建和初始化；不修改宿主，不禁用安全校验。
- 提供完整官方源码插件来源配置与首次安装说明，并隔离验证运行时插件安装。

## Capabilities

### New Capabilities

- `installation-preparation`：首次安装安全材料与可重复启动。

### Modified Capabilities

无。

## Impact

变更限定于插件自有工具、文档与交付回归。数据库初始化仍要求明确确认，不自动重建数据库，不安装生产账号或调用第三方供应商。
