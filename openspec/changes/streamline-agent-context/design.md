## Context

大型偏好混合通用沟通习惯、业务冻结结论和旧流程命令。OpenSpec大变更必须保留真实状态，不能通过删除历史或自动归档解决读取成本。

## Decisions

- 两层入口：AGENTS与短偏好作为默认上下文，领域导航、主题正文和相关规范按任务加载。
- 原偏好按已有标题拆成主题原文；只重定位Markdown相对链接。迁移清单保存来源哈希，恢复后逐字节对比，保留所有业务条款。历史流程条款由当前入口与OpenSpec规则明确替代，默认检索不把旧流程作为当前门禁。
- 技能只负责编排，命令提示只路由到技能；领域门禁留在规则。当前任务正文和验证仍覆盖内容时允许复用；正文丢失、内容变化或范围扩大后重读/补验证。
- Go标准库工具直接读取磁盘，无缓存索引和额外安装。限定规范目录、拒绝路径越界及符号链接逸出，locate排除归档、证据与运行目录；read显式读取完整章节、任务或条目，超过12 KiB拒绝，不静默截断。
- 不改现有业务变更的design/tasks/specs正文与状态，不自动同步基线或归档。本次新建独立治理记录。
- 后续一致性优化在旧偏好主题前添加适用说明，原始正文作为完整后缀保留；迁移哈希继续代表迁移时快照，不改写历史证据。通用编码技能只对真实业务歧义提问，设计技能遵循既有设计系统，输出采用简明结论与关键依据。大文件继续使用现有有界工具和章节定位，不为缩减上下文删除历史或新建重复索引。
- 纯交流不进入修改门禁；需要仓库事实时定向查证。修改前在现有工具提供`status [仓库相对路径]`，内部读取Git的NUL分隔完整状态，默认只输出计数、目录分组和活跃变更名称，指定路径只补充范围总数与最多12条文件，不重复全局清单。目录和变更各限12条，所有省略显式计数；重命名匹配新旧路径，未跟踪文件与生成产物保留在计数中。使用Go标准库与Git，不新增依赖或修改忽略配置。

## Risks / Trade-offs

### 2026-10-22 质量回归修正

既有治理验证证明了原文迁移、输出边界和工具行为，却未证明实际任务交付质量。真实会话出现“测试通过后仍有表单初值和提交错误”“删除能力后启动注册仍沿用旧数量”等遗漏；这些证据说明验收缺口，不能据此断言模型能力或配置下降。

保留按需定位与有效证据复用，在`context-loading.md`集中规定完整目标、证据充分性、因果依赖与完成判断。短入口只声明质量优先并链接权威规则，技能在实际分诊、实施、审查节点引用这些判断；不恢复全量加载，不增加机械文件数量或调用预算。旧任务勾选和未变化的单个文件不足以复用运行证据，需考虑并行修改、配置、数据与实际运行版本。

本次四对话继续执行由用户明确授权，按已确认目标分工，主协调持有规则和共享运行协调职责。治理校验只证明文档结构与一致性；效果证据来自各对话恢复目标、发现并修复具体遗漏和验证当前结果，不能把发出继续指令当成完成。

本轮继续将长期优化落实为`handoff`与`order`入口。交接只输出完整选定任务和最小定位信息，不自动创建或发送会话；验收按当前任务收敛。订单诊断工具归属`idc-core/hack/tools/order-diagnose`，使用Go标准库从本机既有员工API读取，不读取私有表。核心仅在资源拥有的履约详情通过权限与数据范围核验后，以自有任务表的租户和履约唯一键补充一次白名单执行投影；资源详情仍独立授权。最多三条履约及三条资源详情属于固定小常量，整个命令最多八次GET，不用于订单列表逐行装配。无数据库迁移、运行期依赖注入或宿主修改；旧运行版本缺少执行投影时显式报证据不完整，需要更新后端后才能诊断完整链路。

导航可能不能覆盖新业务词；允许rg查找与扩大相关范围，正文始终优先。历史流程原文仍可显式审计，但不得覆盖当前治理规则。read大小限制是默认输出保护，不代表业务条款可略读；超过限制用其他文件工具拆成完整相关逻辑单元。

## Validation

逐字节恢复原偏好、检查新入口与链接、严格校验OpenSpec、技能格式验证、工具自包含单元测试与交叉编译、真实关键词检索检查输出边界。无需业务E2E，因为没有运行期业务/UI变化。

后续增加`.agents/tools/workflow`，由已有上下文入口路由`audit`和`check`，不修改根`hack/`。会话体检只流式扫描显式日志，分开已记录用量、文本、图片及未知序列化输出，读取热点采用有界启发式。范围验证不采用全局Git改动，按显式路径确定包、模块和活跃变更，复用已有命令并串行保存完整日志；独立Go工具运行文件级测试及`go vet`。模块依赖文件变化检查整个模块，无法覆盖的前端行为、SQL等类别明确列出并非零退出，不推断业务验收通过，不缓存外部状态。相同检查在一次计划内去重；已有仍有效的跨次证据继续按上下文规则人工复用，不以不完整文件指纹自动跳过领域门禁。
